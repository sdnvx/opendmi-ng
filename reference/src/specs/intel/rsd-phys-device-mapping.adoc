= Intel RSD Physical Device Mapping Information (Type 200)
:sectnums:
:sectlinks:

Source: Intel(R) RSD Firmware Extension Specification Software v2.3.2 (document 337201-003US), section 3.11.

Declares the relationship between physical devices and their SMBIOS
representation, allowing to link structures to physical locations of the
devices in the system.

Each structure describes devices of one type only. There may be several
structures describing devices of the same type, if they do not fit into a
single structure.

[#intel-rsd-phys-device-types, reftext=Physical device types]
== Intel RSD Physical Device Mapping -- Device types

.Intel RSD Physical Device Mapping: Physical device type field
[width=100%, cols="1,1,4"]
|===
| Hex Value | Dec Value | Meaning

| `0x00` | `0` | Undefined or invalid
| `0x01` | `1` | Processor (type 4)
| `0x02` | `2` | PCIe system slot (type 9)
| `0x03` | `3` | Memory device (type 17)
|===

Other values are undefined or invalid.
