= Intel RSD TPM Information (Type 195)
:sectnums:
:sectlinks:

Source: Intel(R) RSD Firmware Extension Specification Software v2.3.2 (document 337201-003US), section 3.6.

Declares a Trusted Platform Module (TPM) configuration the system can be set
to. The structure is present only if the system has a TPM, even a disabled
one, and the system has a structure for every TPM version it can work with.

.Intel RSD TPM Information structure
