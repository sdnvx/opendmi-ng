= Intel ASF Information (Type 129)
:sectnums:
:sectlinks:

Source: reverse engineered from the dumps of the data corpus.

Names the Alert Standard Format (ASF) support of the platform. The structure
is found on Intel platforms of Acer, Dell, Framework, Lenovo, Samsung and
Toshiba, with the strings of the Intel reference code, e.g. `Intel_ASF` and
`Intel_ASF_001`, of Dell, e.g. `Dell_ASF_001`, or of Insyde, e.g.
`Insyde_ASF_001`. The meaning of the fields other than the strings is not
established.

The structure is told by the bytes at offset `0x04`, `01 01`, since other
vendors give type 129 to structures of their own, e.g. Gigabyte, whose
structures begin with zeroes there. The number of the second string is not
checked: the structures whose strings are the same are written back with a
single one, to which both fields refer.
