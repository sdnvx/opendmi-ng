= Intel RSD TXT Information (Type 196)
:sectnums:
:sectlinks:

Source: Intel(R) RSD Firmware Extension Specification Software v2.3.2 (document 337201-003US), section 3.7.

Declares the state of Intel Trusted Execution Technology (TXT). The structure
is present only if the system supports TXT, even when it is disabled.
