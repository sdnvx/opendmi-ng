= Intel vPro Information (Type 131)
:sectnums:
:sectlinks:

Source: Intel AMT Implementation and Reference Guide, "vPro Verification
Table Parameter Definitions"; MeshAgent, `modules/smbios.js`; and the dumps
of the data corpus, whose versions match the ones of Intel firmware version
information (type 221).

Intel calls the structure the vPro verification table. It describes the parts
of the platform Intel vPro technology relies on: the capabilities of the
processor, of the Management Engine firmware, of the TPM and of the BIOS, the
versions of the firmware and of its BIOS extension (MEBx), and the PCI
functions of the chipset and of the network controller the Management Engine
uses. The structure is found on Intel platforms whether they are of vPro or
not.

The guide gives the offsets from a point 8 bytes before the one of this
chapter, i.e. its `0x0C` is `0x04` here.

The structure is told by the `vPro` signature at offset `0x38`, since some
vendors give type 131 to structures of their own in the same table, e.g.
Lenovo ThinkVantage Technologies enablement. PCI functions are given as their
device and function numbers, `(device << 3) | function`, followed by their
bus.

== Older Layout

The guide gives the capabilities of the memory controller hub (MCH) from
`0x08` to `0x0F`, where the newer firmware puts the version of the BIOS
extension, and firmware of both kinds is found in the data corpus, e.g. the
one of HP EliteBook 6930p holds the hub. The hub is found at 0:0.0, so its
device and function and its bus are zero, while its device ID is not, which
tells the layout: a version of the BIOS extension is either given in full, or
not at all.

.Memory controller hub capabilities
[width=100%, cols="1,2,1,4"]
|===
| Offset | Name | Length | Description

| `0x08`
| MCH Device and Function
| `BYTE`
| PCI device and function of the hub

| `0x09`
| MCH Bus
| `BYTE`
| PCI bus of the hub

| `0x0A`
| MCH Device ID
| `WORD`
| PCI device ID of the hub, e.g. `0x2A40` of Intel GM45

| `0x0C`
| MCH Capabilities
| `DWORD`
| Bit 0: the chipset supports VT-d, bit 1: VT-d is enabled, bit 2: the chipset supports TXT, bit 3: TXT is enabled
|===
