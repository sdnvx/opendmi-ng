= Dell Token References, Type 1 (Type 220)
:sectnums:
:sectlinks:

Source: reverse engineered from the dumps of the data corpus.

Lists tokens, most of which the calling interface (type 218) or the indexed I/O
access (type 212) of the same table defines, which the structures of a table
group by the device they belong to, e.g. `0xF100` and `0xF102`, `0xF110` and
`0xF112` in `dell/g15-5510.bin`, or `0xF420`, `0xF410`, `0xF430` and `0xF440` in
`dell/precision-490.bin`. The tokens are SMI ones, which are named in no public
source, and the meaning of the groups is not established.
