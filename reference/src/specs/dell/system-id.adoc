= Dell System ID Record (Type 255)
:sectnums:
:sectlinks:

Source: reverse engineered from the dumps of the data corpus.

Holds the system ID of the platform in hexadecimal digits, e.g. `0A64` in
`dell/g15-5510.bin`, which the revisions and IDs (type 208) and the OEM
strings (type 11, key `1`) hold too, along with an identifier beginning with
`_SID`, whose meaning is not established.
