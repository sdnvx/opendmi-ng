= Dell Hotkeys (Type 178)
:sectnums:
:sectlinks:

Source: the Dell WMI driver of Linux, `dell-wmi-base.c`, and the dumps of the data corpus.

Maps the scan codes of the hotkeys of a laptop to their functions, which the
Dell WMI driver of Linux reads. Mappings run to the end of the structure,
which carries no number of them of its own. Key code `0xFFFF` is found for the
keys of no known function, which the driver takes for an unknown key, while
key code `0x00FF` stands for a function of its own, the third programmable
key. The structures of the data corpus refer to one string of spaces, which no
field refers to.

.Mapping
[width=100%, cols="1,2,1,4"]
|===
| Offset | Name | Length | Description

| `0x00`
| Scan Code

| Scan code of the key, as the firmware reports it in the WMI events of the hotkeys

| `0x02`
| Key Code
| `WORD`
| Function of the key, as the Dell WMI driver numbers the functions
|===
