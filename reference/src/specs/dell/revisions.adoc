= Dell Revisions and IDs (Type 208)
:sectnums:
:sectlinks:

Source: Dell `libsmbios`, `doc/smbios23.xml`.

The source gives the structure a length of `0x0C`, while the firmware of Dell
systems writes structures of other lengths too: shorter ones end after the
system ID extension, at `0x0A`, and have no dates, and longer ones carry bytes
past the first power-on date which no source describes.
