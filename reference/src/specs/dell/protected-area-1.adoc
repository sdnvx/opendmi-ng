= Dell Protected Area Type 1 (Type 214)
:sectnums:
:sectlinks:

Source: Dell `libsmbios`, `src/include/smbios_c/obj/token.h`.

Describes a protected value, such as a password, which is stored in CMOS and
accessed through the indexed I/O ports, and its checksum.
