= Dell Token References, Type 2 (Type 221)
:sectnums:
:sectlinks:

Source: reverse engineered from the dumps of the data corpus.

Lists tokens, most of which the calling interface (type 218) or the indexed I/O
access (type 212) of the same table defines, e.g. `0xF600` and `0xF601` in
`dell/g15-5510.bin`, following two values whose meaning is not established. The
structures are 19 bytes long and carry no strings, which tells them from the
Intel firmware version information some systems, e.g. XPS 13 9350, keep at type
221.
