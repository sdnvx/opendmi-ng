:sectnums:

Source: reverse engineered from the dumps of the data corpus.

Lists tokens the calling interface (type 218) or the indexed I/O access (type
212) defines, e.g. `0xF600` and `0xF601` in `dell/g15-5510.bin`, following two
values whose meaning is not established.
