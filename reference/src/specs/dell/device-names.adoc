= Dell Device Names (Type 225)
:sectnums:
:sectlinks:

Source: reverse engineered from the dumps of the data corpus.

Gives the devices of a kind the names the management controller (iDRAC) of
a PowerEdge server knows them by, its fully qualified device descriptors
(FQDD), e.g. `CPU.Socket.1` and `CPU.Socket.2` to the processors (type 4) of
handles `0x0400` and `0x0401`, or `DIMM.Socket.A1` to the memory device
(type 17) of handle `0x1100` in `dell/poweredge-r640.bin`. The structures are
found on PowerEdge servers of the 13th and 14th generations, one for the
processors and one for the memory devices.
