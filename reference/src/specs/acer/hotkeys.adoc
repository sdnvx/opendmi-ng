= Acer Hotkey Functions (Type 170)
:sectnums:
:sectlinks:

Source: the Acer WMI driver of Linux, `acer-wmi.c`, dmidecode, `dmioem.c`, and the dumps of the data corpus.

Tells the functions of the hotkeys of a laptop, which the Acer WMI driver of
Linux reads. Some laptops of other brands, e.g. Fujitsu-Siemens, Medion,
Lenovo and eMachines, are said to carry it too.

The Acer WMI driver reads the structure up to the number of the key of the
communication function, at `0x0E`. In the data corpus, that byte begins a list
of 4-byte hotkeys, which runs to the end of the structure: the number of a key,
a byte of `1` or `2`, the same for all the hotkeys of a structure, and the
function of the key, as bits of the bitmap of its button group: the key of the
communication function has all the bits of the communication bitmap, e.g. those
of WiFi and Bluetooth. The high bits of the key number tell the group: `0x0_`
communication, `0x4_` media, `0x6_` display and `0x8_` others, and the functions
of the keys of the media and display groups add up to their bitmaps.

Structures of `0x0F` bytes end with the number of the key of the communication
function, and hold no hotkeys.
