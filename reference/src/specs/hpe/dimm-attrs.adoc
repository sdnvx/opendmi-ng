= HP/HPE DIMM Attributes Record (Type 232)
:sectnums:
:sectlinks:

Source: dmidecode, `dmioem.c`. No dumps of the data corpus hold the structure.

Tells what the memory device structure (type 17) of a DIMM socket does not:
whether the module is an HPE one, and the voltages it runs at. There is a
record for each socket. The structure is decoded from Gen9 onwards, and the
shortest structures end after the configured voltage, at `0x0E`.

| 2.0+

| `ENUM`
