= HP/HPE DIMM Vendor Information (Type 237)
:sectnums:
:sectlinks:

Source: dmidecode, `dmioem.c`. No dumps of the data corpus hold the structure.

Tells the actual manufacturer of the module of a memory device (type 17),
whose standard fields hold the ones of HPE. The structure is decoded from Gen9
onwards.
