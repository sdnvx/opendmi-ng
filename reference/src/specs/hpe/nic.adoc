= HP/HPE BIOS NIC PCI and MAC Information (Type 209, 221)
:sectnums:
:sectlinks:

Source: dmidecode, `dmioem.c`, and the dumps of the data corpus.

Lists the network ports the firmware boots from: over PXE with type 209, and
over iSCSI with type 221. Ports run to the end of the structure, which carries
no number of them of its own. A port is disabled if its bus and device are
zero, and not installed if they have all bits set.

Type 221 is deprecated from Gen8 onwards. What the newer servers give it to,
if anything, is not established, and OpenDMI decodes no structure of that type
on them.
