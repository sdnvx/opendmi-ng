= HP/HPE Trusted Module Status (Type 224)
:sectnums:
:sectlinks:

Source: dmidecode, `dmioem.c`, and the dumps of the data corpus.

Tells whether a trusted module (TPM or TCM) is present and enabled, and what
kind of module it is. The older servers hold the status only.

.HP/HPE Trusted Module Status structure
[width=100%, cols="1,1,2,1,1,4"]
|===
| Offset | Version | Name | Length | Value | Description

| `0x00`
| 2.0+
| Type
| `BYTE`
| `224`
| HP/HPE Trusted Module Status indicator

| `0x01`
| 2.0+
| Length
| `BYTE`
| Varies
| Length of the structure

| `0x02`
| 2.0+
| Handle
| `WORD`
| Varies
| 

| `0x04`
| 2.0+
| Status
| `BYTE`
| `BITFIELD`
| Bits 0-1: presence, bit 2: option ROMs are measured, bit 3: hidden

| `0x05`
| 2.0+
| Extended Status
| `BYTE`
| `BITFIELD`
| Bits 0-1: disable reason, meaningful for a disabled module only; bits 2-5: error condition, meaningful for a module disabled for an error only

| `0x06`
| 2.0+
| Module Type
| `BYTE`
| `BITFIELD`
| Bits 0-3: type, bit 4: standard algorithms supported, bit 5: Chinese algorithms supported

| `0x07`
| 2.0+
| Module Attributes
| `BYTE`
| `BITFIELD`
| Bits 0-1: mounting, bits 2-3: FIPS certification

| `0x08`
| 2.0+
| Version Handle
| `WORD`
| `HANDLE`
| Handle of the version indicator (type 216) of the firmware of the module

| `0x0A`
| 2.0+
| Chip Identifier
| `WORD`
| `ENUM`
| The low byte tells the chip, the high byte is reserved
