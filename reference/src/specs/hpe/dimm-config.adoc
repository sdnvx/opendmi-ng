= HP/HPE DIMM Current Configuration Record (Type 244)
:sectnums:
:sectlinks:

Source: dmidecode, `dmioem.c`. No dumps of the data corpus hold the structure.

Describes a memory region configured on a module of a memory device (type 17),
e.g. of a persistent memory one, and the interleave set it belongs to. There
is a record for each region. dmidecode says the number of the regions of
a module is given by the DIMM attributes record (type 232), whose layout it
leaves reserved where the number would be, so the number is not known from
the data. The shortest structures end
after the interleave set index, at `0x14`.
