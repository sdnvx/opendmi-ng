= HP/HPE Extension Board Inventory Record (Type 245)
:sectnums:
:sectlinks:

Source: dmidecode, `dmioem.c`. No dumps of the data corpus hold the structure.

Describes an extension board installed in the server, e.g. a PCIe riser, as
ML, DL and Alletra servers do from Gen11 onwards. The board type selects the
layout of the rest of the structure, and the structures of other board types
are not decoded.

.HP/HPE Extension Board Inventory Record structure

|===

| HP/HPE Extension Board Inventory Record indicator

| `0x01`
| 2.0+
