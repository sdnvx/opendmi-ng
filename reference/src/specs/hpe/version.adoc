= HP/HPE Version Indicator Record (Type 216)
:sectnums:
:sectlinks:

Source: dmidecode, `dmioem.c`. No dumps of the data corpus hold the structure.

Tells the version of a firmware component of the server, e.g. of a CPLD or of
a power management controller, which type 193 does not scale to. There is a
record for each component. The structure is decoded from Gen8 onwards.

The version data is laid out as its format tells. Format 5 is laid out
differently on Gen9 servers, where it is the one of format 4, and on Gen10 and
Gen10 Plus servers, where it takes the low nibbles of bytes 1, 3, 5 and 6.
Words are held low byte first.

.Data format
[width=100%, cols="1,4"]
|===
| Value | Version

| `0`
| No version data

| `1`
| `0x`byte 1 bits 0-6, followed by ` B.0x`byte 0 bits 0-6 if bit 7 of byte 0 is set

| `2`
| Byte 0 bits 4-7 `.` byte 0 bits 0-3

| `3`
| Reserved

| `4`
| Byte 0 bits 4-7 `.` byte 0 bits 0-3 `.` byte 1 bits 0-6

| `5`
| Depends on the generation, see above

| `6`
| Byte 1 `.` byte 0

| `7`
| `v`byte 0`.`byte 1 `(`byte 2`/`byte 3`/`word 4`)`

| `8`
| Word 4 `.` word 0

| `9`
| Byte 0 `.` byte 1 `.` word 2

| `10`
| Byte 0 `.` byte 1 `.` byte 2 `Build` byte 3

| `11`
| Word 2 `.` word 0, then double word 4

| `12`
| Word 0 `.` word 2 `.` word 4 `.` word 6

| `13`
| Byte 0

| `14`
| Byte 0 `.` byte 1 `.` byte 2 `.` word 3

| `15`
| Word 0 `.` word 2 `.` word 4 `.` word 6 `(`byte 8`/`byte 9`/`word 10`)`

| `16`
| Characters of bytes 0 to 3 `.` byte 4 and byte 5

| `17`
| Double word 0 in hexadecimal

| `18`
| Byte 0 `.` byte 1 of two digits

| `19`
| `0x`byte 0 `.0x`byte 1 `.0x`byte 2

| `20`
| Byte 0 `.` byte 1 `.` byte 2 `.` byte 3
|===
