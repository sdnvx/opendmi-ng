= HP/HPE Reserved Memory Location (Type 229)
:sectnums:
:sectlinks:

Source: dmidecode, `dmioem.c`, and the dumps of the data corpus.

Tells where the memory regions the firmware reserves at boot are, which it
reports to the operating system as reserved, e.g. the one the storage
controller and iLO exchange the temperatures of the drives in. Regions run to
the end of the structure, which carries no number of them of its own, and a
table may hold several structures.

.Region
[width=100%, cols="1,2,1,4"]
|===

| `QWORD`
