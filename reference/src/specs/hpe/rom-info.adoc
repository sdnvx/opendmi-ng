= HP/HPE Other ROM Information (Type 193)
:sectnums:
:sectlinks:

Source: dmidecode, `dmioem.c`, and the dumps of the data corpus.

Describes the redundant system ROM and the OEM ROM image of the server.
dmidecode decodes the structure from Gen9 onwards, while the older servers of
the data corpus carry the same layout.

.HP/HPE Other ROM Information structure
[width=100%, cols="1,1,2,1,1,4"]
|===
| Offset | Version | Name | Length | Value | Description

| `0x00`
| 2.0+
| Type
| `BYTE`
| `193`
| HP/HPE Other ROM Information indicator

| `0x01`
| 2.0+
| Length
| `BYTE`
| Varies
| Length of the structure

| `0x02`
| 2.0+
| Handle
| `WORD`
| Varies
| 

| `0x04`
| 2.0+
| ROM Flags
| `BYTE`
| `BITFIELD`
| Bit 0 tells that a redundant ROM is installed

| `0x05`
| 2.0+
| Redundant ROM Version
| `BYTE`
| `STRING`
| Version of the redundant ROM, which is its release date. Reserved from Gen12 onwards

| `0x06`
| 2.0+
| Boot Block Version
| `BYTE`
| `STRING`
| Version whose meaning is not documented, reserved from Gen9 onwards. Its dates are earlier than the ones of the ROM, which suggests the boot block

| `0x07`
| 2.0+
| OEM ROM File Name
| `BYTE`
| `STRING`
| File name of the OEM ROM image. Firmware which has no image leaves the string out or fills it with blanks

| `0x08`
| 2.0+
| OEM ROM Build Date
| `BYTE`
| `STRING`
| Build date of the OEM ROM image, meaningful when the file name is

| `0x09`
| 2.0+
| Unknown
| `BYTE`
| `STRING`
| String whose meaning is not established, e.g. `2.9` on a G6 server. dmidecode does not decode it
|===

The version of the redundant ROM is shown when the redundant ROM is installed,
up to Gen11. The file name and the build date of the OEM ROM image are shown
when the file name is neither empty nor begins with two blanks, which is the
check dmidecode makes.
