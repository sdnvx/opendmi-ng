= HP/HPE Processor Specific Information (Type 197)
:sectnums:
:sectlinks:

Source: dmidecode, `dmioem.c`, and the dumps of the data corpus.

Supplements the processor information (type 4) of each processor socket or
slot with the numbers the server tells its processors by. The structure is
ignored for the empty sockets. It has grown with the generations of the
servers, and its fields past the physical socket are absent from the older
ones.
