== HP/HPE-specific structures

HP and HPE servers add structures of their own, some of which have changed
their layouts or have been deprecated over the generations of the servers:
up to G7, the generations are named `G1` to `G7`, and `Gen8` onwards. The
generation is told from the product name of the system information (type 1).
Type 219 and type 221 are taken on these servers by structures of their own,
and the Intel reference code structures of these types are not decoded there.

== Intel RSD structures

The structures of Intel Rack Scale Design (RSD) describe the devices of a
system to the management software of the rack, which reads them from the
management controller the firmware passes the table on to. The specification
reserves types 190 to 209 for them, of which it defines types 190 and 192 to
200. Memory is described by the standard memory structures (types 17 to 20),
which type 197 extends.
