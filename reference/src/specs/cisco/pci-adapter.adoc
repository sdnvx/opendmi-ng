= Cisco PCI Adapter Information (Type 202)
:sectnums:
:sectlinks:

Source: reverse engineered from the dumps of the data corpus.

Describes an adapter of a Cisco UCS server: its PCI identifiers and class,
its model, the slot it is installed in, and the version of its firmware.
There is a structure for each adapter, including the ones on board, e.g. the
modular LAN on motherboard (`SlotID:MLOM`), the modular RAID controller
(`SlotID:MRAID`) and the LAN on motherboard (`SlotID:L`).

The identifiers are held in the big-endian byte order, unlike the other
fields of SMBIOS, and match the PCI ID database and the models the structures
name, e.g. `1137:0042` of subsystem `1137:0217` for Cisco UCS VIC 1455,
`8086:1521` for Intel I350, `1000:0014` of subsystem `1137:020E` for the Cisco
12G modular RAID controller, and `8086:1563` for Intel X550. The class code
is laid out as the configuration space of the function holds it.
