= Sun Memory Device Extended Information (Type 145)
:sectnums:
:sectlinks:

Source: illumos, `usr/src/uts/common/sys/smbios_impl.h`.

Extends the memory device information (type 17) with the DRAM channel and
chip selects of the memory device.

.Sun Memory Device Extended Information structure
[width=100%, cols="1,1,2,1,1,4"]
|===
| Offset | Version | Name | Length | Value | Description

| `0x00`
| 2.0+
| Type
| `BYTE`
| `145`
| Sun Memory Device Extended Information indicator

| `0x01`
| 2.0+
| Length
| `BYTE`
| Varies
| Length of the structure

| `0x02`
| 2.0+
| Handle
| `WORD`
| Varies
|

| `0x04`
| 2.0+
| Memory Device Handle
| `WORD`
| `HANDLE`
| Memory device structure (type 17) being extended

| `0x06`
| 2.0+
| DRAM Channel
| `BYTE`
| `NUMBER`
|

| `0x07`
| 2.0+
| Number of Chip Selects
| `BYTE`
| `NUMBER`
| Number of chip selects (n)

| `0x08`
| 2.0+
| Chip Selects
| n BYTEs
| Varies
| Chip selects, a `BYTE` each
|===
