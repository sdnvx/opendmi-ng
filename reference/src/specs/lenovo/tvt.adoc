= Lenovo ThinkVantage Technologies Enablement (Type 131)
:sectnums:
:sectlinks:

Source: dmidecode, `dmioem.c`, and the dumps of the data corpus.

Tells which ThinkVantage Technologies the platform enables, of which only the
diagnostics are known. The structure is told by its length and by its first
string, `TVT-Enablement`, since Intel vPro information takes type 131 in the
same table.
