= Lenovo OEM Data (Type 140)
:sectnums:
:sectlinks:

Source: dmidecode, `dmioem.c`, the README files of the firmware updates of Lenovo, and the dumps of the data corpus.

Holds one OEM structure of a Lenovo system, told by its number and revision.
OEM structures 0 to 9 are found in the data corpus, and only structure 7, the
embedded controller program, is decoded. Structure 9 refers to two strings
too, e.g. `1.32`, whose meaning is not established.

.ThinkPad embedded controller program (OEM structure 7, revision 1)
[width=100%, cols="1,2,1,4"]
|===
| Offset | Name | Length | Description

| `0x0D`

| `STRING`

| `0x0E`

| `STRING`
