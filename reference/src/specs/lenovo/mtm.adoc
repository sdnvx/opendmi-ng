= Lenovo Machine Type Model (Type 200)
:sectnums:
:sectlinks:

Source: reverse engineered from the dumps of the data corpus.

Tells the brand of an IdeaPad or a ThinkBook, `IdeaPad` for both, and its full
machine type model, e.g. `20VE00U9RU`, of which the system information (type
1) holds only the machine type, e.g. `20VE`.
