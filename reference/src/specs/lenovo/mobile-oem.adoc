= Lenovo Mobile PC OEM Data (Type 135)
:sectnums:
:sectlinks:

Source: Compal hel81 Service Manual Software Specification, dmidecode, `dmioem.c`, and the dumps of the data corpus.

Holds one OEM structure of a Lenovo laptop, told by its number and revision.
The service manuals name the type "Bulk for Lenovo Mobile PC Unique OEM Data".
OEM structures 0, 1, 2 and 4 are found in the data corpus too, and only
structures 2 and 3 are decoded.
