= Apple Processor Bus Speed Information (Type 132)
:sectnums:
:sectlinks:

Source: the `AppleSmBios.h` header of OpenCore, `Include/Apple/IndustryStandard`.

Tells the speed of the bus of the processor, e.g. `4800` for the QuickPath
Interconnect of 4.8 GT/s in `apple/imac11-3.bin`. OpenCore sets it to four
times the external clock of the processor.
