= Apple Processor Type Information (Type 131)
:sectnums:
:sectlinks:

Source: the `AppleSmBios.h` header of OpenCore, `Include/Apple/IndustryStandard`.

Tells the type of the processor, by which macOS names it, e.g. `0x0701` for
the first generation of Intel Core i7 in `apple/imac11-3.bin`. The Intel
reference code gives type 131 to the Intel vPro information too.

.Apple Processor Type Information structure
[width=100%, cols="1,1,2,1,1,4"]
|===
| Offset | Version | Name | Length | Value | Description

| `0x00`
| 2.0+
| Type
| `BYTE`
| `131`
| Apple Processor Type Information indicator

| `0x01`
| 2.0+
| Length
| `BYTE`
| Varies
| Length of the structure

| `0x02`
| 2.0+
| Handle
| `WORD`
| Varies
| 

| `0x04`
| 2.0+
| Processor Type
| `WORD`
| Varies
| Class of the processor in the high byte, see <<apple-processor-classes>>, and its generation within the class in the low byte

| `0x06`
| 2.0+
| Reserved
| 2 `BYTE`
| `0`
| On newer firmware
|===
