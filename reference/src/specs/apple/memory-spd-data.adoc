= Apple Memory SPD Data (Type 130)
:sectnums:
:sectlinks:

Source: the `AppleSmBios.h` header of OpenCore, `Include/Apple/IndustryStandard`.

Holds the serial presence detect (SPD) data of a memory module, or a part of
it, e.g. the first 176 bytes of the SPD data of the DDR3 modules of
`apple/imac11-3.bin`. The firmware adds a structure for each memory module.
The Intel reference code gives type 130 to the Intel Active Management
Technology information too.
