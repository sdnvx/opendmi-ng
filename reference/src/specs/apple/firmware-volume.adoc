= Apple Firmware Volume Information (Type 128)
:sectnums:
:sectlinks:

Source: the `AppleSmBios.h` header of OpenCore, `Include/Apple/IndustryStandard`.

Tells the features of the firmware, which macOS and its boot loader read,
and the layout of its flash memory. The features are 64 bits wide: the
structure holds their low 32 bits, and newer firmware their high 32 bits as
the extended features. `apple/imac11-3.bin` carries the structure of 88 bytes,
without the extended features.

[#apple-firmware-features, reftext=Firmware Features]
== Apple Firmware Volume Information -- Firmware Features

.Apple Firmware Volume Information: Firmware Features
[width=100%, cols="1,6"]
|===
| Bit | Meaning

| 0 | Supports booting legacy operating systems (CSM)
| 1 | Supports booting from optical drives
| 2 | Supports target disk mode
| 4 | Supports network boot
| 5 | Supports the recovery embedded into the firmware (SlingShot)
| 8 | Supports wireless networks in the firmware
| 10 | Bit 0 of the platform security policy
| 11 | Bit 1 of the platform security policy
| 12 | Firmware is locked
| 14 | Supports USB 2.0 in the firmware
| 17 | USB ports are not substituted with others by macOS
| 19 | Supports APFS
| 20 | Supports APFS, unused by the known Macs
| 22 | Supports Apple tamper resistant boot X
| 24 | Supports the platform security policy
| 25 | Supports the extended features
| 28 | Memory map is not adjusted by the boot loader on hibernation wake
| 29 | Supports UEFI Windows boot
| 31 | Memory map is not adjusted by the boot loader for the boot script
| 35 | Supports the large BaseSystem, which macOS 12 requires
|===

The other bits are of no known meaning.
