== Name

dmi_mgmt_device_type, dmi_mgmt_device_type_name - types of management devices

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/mgmt-device.h>

typedef enum dmi_mgmt_device_type {
    DMI_MGMT_DEVICE_TYPE_UNSPEC          = 0x00,
    DMI_MGMT_DEVICE_TYPE_OTHER           = 0x01,
    DMI_MGMT_DEVICE_TYPE_UNKNOWN         = 0x02,
    DMI_MGMT_DEVICE_TYPE_NATIONAL_LM75   = 0x03,
    DMI_MGMT_DEVICE_TYPE_NATIONAL_LM78   = 0x04,
    DMI_MGMT_DEVICE_TYPE_NATIONAL_LM79   = 0x05,
    DMI_MGMT_DEVICE_TYPE_NATIONAL_LM80   = 0x06,
    DMI_MGMT_DEVICE_TYPE_NATIONAL_LM81   = 0x07,
    DMI_MGMT_DEVICE_TYPE_ANALOG_ADM9240  = 0x08,
    DMI_MGMT_DEVICE_TYPE_DALLAS_DS1780   = 0x09,
    DMI_MGMT_DEVICE_TYPE_MAXIM_1617      = 0x0A,
    DMI_MGMT_DEVICE_TYPE_GENESYS_GL518SM = 0x0B,
    DMI_MGMT_DEVICE_TYPE_WINBOND_W83781D = 0x0C,
    DMI_MGMT_DEVICE_TYPE_HOLTEK_HT82H791 = 0x0D,
} dmi_mgmt_device_type_t;

const char *dmi_mgmt_device_type_name(dmi_mgmt_device_type_t value);
----

== Description

The `dmi_mgmt_device_type_t` enumeration tells the model of a management
device, and is the type of the `type` field of `dmi_mgmt_device_t`.

The `dmi_mgmt_device_type_name` function returns the printable name of a value,
as the command line tool shows it. The name is translated to the locale set
with `dmi_set_locale`, when the library is built with ICU4C support and has a
translation of it.

=== Values

`DMI_MGMT_DEVICE_TYPE_UNSPEC`::
Unspecified.

`DMI_MGMT_DEVICE_TYPE_OTHER`::
Other device.

`DMI_MGMT_DEVICE_TYPE_UNKNOWN`::
Unknown device.

`DMI_MGMT_DEVICE_TYPE_NATIONAL_LM75`::
National Semiconductor LM75.

`DMI_MGMT_DEVICE_TYPE_NATIONAL_LM78`::
National Semiconductor LM78.

`DMI_MGMT_DEVICE_TYPE_NATIONAL_LM79`::
National Semiconductor LM79.

`DMI_MGMT_DEVICE_TYPE_NATIONAL_LM80`::
National Semiconductor LM80.

`DMI_MGMT_DEVICE_TYPE_NATIONAL_LM81`::
National Semiconductor LM81.

`DMI_MGMT_DEVICE_TYPE_ANALOG_ADM9240`::
Analog Devices ADM9240.

`DMI_MGMT_DEVICE_TYPE_DALLAS_DS1780`::
Dallas Semiconductor DS1780.

`DMI_MGMT_DEVICE_TYPE_MAXIM_1617`::
Maxim 1617.

`DMI_MGMT_DEVICE_TYPE_GENESYS_GL518SM`::
Genesys GL518SM.

`DMI_MGMT_DEVICE_TYPE_WINBOND_W83781D`::
Winbond W83781D.

`DMI_MGMT_DEVICE_TYPE_HOLTEK_HT82H791`::
Holtek HT82H791.

== Return value

`dmi_mgmt_device_type_name` returns the name of the value, or `nullptr` if the
value has no name. The name is a static string, which must not be modified or
freed.

== Errors

None.

== See also

`dmi_mgmt_device`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.3 or newer.
