== Name

dmi_apple_platform_feature_bit, dmi_apple_platform_feature_bit_name - Apple platform features

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/apple/platform-feature.h>

typedef enum dmi_apple_platform_feature_bit {
    DMI_APPLE_PLATFORM_FEATURE_SOLDERED_MEMORY = 1,
    DMI_APPLE_PLATFORM_FEATURE_HEADLESS_GPU    = 2,
    DMI_APPLE_PLATFORM_FEATURE_HOST_PM         = 3,
    DMI_APPLE_PLATFORM_FEATURE_POWER_CHIME     = 4
} dmi_apple_platform_feature_bit_t;

const char *dmi_apple_platform_feature_bit_name(dmi_apple_platform_feature_bit_t value);
----

== Description

The `dmi_apple_platform_feature_bit_t` enumeration names the bits of the
`features` field of `dmi_apple_platform_feature_t`, by their numbers. Bit 0
is of no known meaning, and is named `Unknown bit 0`, the way OpenCore names
it.

The `dmi_apple_platform_feature_bit_name` function returns the name of a value, as the command line
tool shows it.

=== Values

`DMI_APPLE_PLATFORM_FEATURE_SOLDERED_MEMORY`::
System memory is soldered, and cannot be replaced.

`DMI_APPLE_PLATFORM_FEATURE_HEADLESS_GPU`::
Headless GPU, of no display connectors, is present.

`DMI_APPLE_PLATFORM_FEATURE_HOST_PM`::
Supports host power management.

`DMI_APPLE_PLATFORM_FEATURE_POWER_CHIME`::
Supports the chime at boot.

== Return value

`dmi_apple_platform_feature_bit_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_apple_platform_feature`(3)

== Standards

Not part of the SMBIOS specification. Defined by the firmware of Macs, and
laid out as the `AppleSmBios.h` header of OpenCore describes it.
