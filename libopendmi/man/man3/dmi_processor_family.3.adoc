== Description

The `dmi_processor_family_t` enumeration tells the family of a processor, and
is the type of the `family` field of `dmi_processor_t`.

Values up to 0xFD are carried by the one-byte family field of the structure.
Values of 0x100 and above only fit the two-byte family field added in
SMBIOS 2.6, and the one-byte field holds `DMI_PROCESSOR_FAMILY_EXTENDED`
instead. Values missing from the enumeration are not assigned by the
specification; 0xFFFE and 0xFFFF are reserved.

The `dmi_processor_family_name` function returns the name of a value, as the
command line tool shows it.

== Return value

`dmi_processor_family_name` returns the name of the value, or `nullptr` if the
value has no name. The name is translated to the current locale when the
library is built with localization support and has a translation for it, and
is in English otherwise. The string is owned by the library and must not be
modified or freed.

None.
