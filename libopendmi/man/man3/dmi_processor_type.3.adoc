== Name

dmi_processor_type, dmi_processor_type_name - processor types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/processor.h>

typedef enum dmi_processor_type {
    DMI_PROCESSOR_TYPE_UNSPEC  = 0x00,
    DMI_PROCESSOR_TYPE_OTHER   = 0x01,
    DMI_PROCESSOR_TYPE_UNKNOWN = 0x02,
    DMI_PROCESSOR_TYPE_CENTRAL = 0x03,
    DMI_PROCESSOR_TYPE_MATH    = 0x04,
    DMI_PROCESSOR_TYPE_DSP     = 0x05,
    DMI_PROCESSOR_TYPE_VIDEO   = 0x06
} dmi_processor_type_t;

const char *dmi_processor_type_name(dmi_processor_type_t value);
----

== Description

The `dmi_processor_type_t` enumeration tells the role of a processor, and is
the type of the `type` field of `dmi_processor_t`.

The `dmi_processor_type_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_PROCESSOR_TYPE_UNSPEC`::
Unspecified.

`DMI_PROCESSOR_TYPE_OTHER`::
Other.

`DMI_PROCESSOR_TYPE_UNKNOWN`::
Unknown.

`DMI_PROCESSOR_TYPE_CENTRAL`::
Central processor.

`DMI_PROCESSOR_TYPE_MATH`::
Math processor.

`DMI_PROCESSOR_TYPE_DSP`::
DSP processor.

`DMI_PROCESSOR_TYPE_VIDEO`::
Video processor.

== Return value

`dmi_processor_type_name` returns the name of the value, or `nullptr` if the
value has no name. The name is translated to the current locale when the
library is built with localization support and has a translation for it, and
is in English otherwise. The string is owned by the library and must not be
modified or freed.

== Errors

None.

== See also

`dmi_processor`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.0 or newer.
