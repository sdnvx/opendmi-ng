== Name

dmi_encoder_put_at - encode a value and write it at a given offset.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/encoder.h>

dmi_encoder_put_at(encoder, offset, type, value)
----

== Description

The `dmi_encoder_put_at` macro converts `value` into `type` in SMBIOS wire
format (little-endian) using `dmi_encode` and writes `sizeof(type)` bytes at
`offset` from the beginning of the structure. The cursor is not moved.

=== Parameters

`encoder`::
Encoder to write to.

`offset`::
Byte offset from the beginning of the structure.

`type`::
Wire-format type to write (e.g. `dmi_word_t`, `dmi_dword_t`).

`value`::
Value to write.

== Return value

`true` on success, `false` if the bytes do not fit into the range.

== Errors

`DMI_ERROR_OUT_OF_MEMORY`::
Buffer of the writer cannot grow.

`dmi_encoder_put_bytes_at`(3),
