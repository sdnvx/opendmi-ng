== Name

dmi_intel_me_error, dmi_intel_me_error_name - Intel Management Engine firmware error codes

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/intel/mei.h>

typedef enum dmi_intel_me_error {
    DMI_INTEL_ME_ERROR_NONE          = 0x00,
    DMI_INTEL_ME_ERROR_UNCATEGORIZED = 0x01,
    DMI_INTEL_ME_ERROR_IMAGE         = 0x03,
    DMI_INTEL_ME_ERROR_DEBUG         = 0x04,
    DMI_INTEL_ME_ERROR_UNSPEC        = 0xFF
} dmi_intel_me_error_t;

const char *dmi_intel_me_error_name(dmi_intel_me_error_t value);
----

== Description

The `dmi_intel_me_error_t` enumeration tells the error code of the Intel
Management Engine firmware, as bits 12 to 15 of the first firmware status
register (HFSTS1) of the first interface tell it, and is the type of the
`error_code` field of `dmi_intel_mei_t`. The values are the ones coreboot
names. Other values may be found in the data, and are kept as they are.

The `dmi_intel_me_error_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_INTEL_ME_ERROR_NONE`::
No error.

`DMI_INTEL_ME_ERROR_UNCATEGORIZED`::
Failure of no particular category.

`DMI_INTEL_ME_ERROR_IMAGE`::
Failure of the image of the firmware, e.g. a corrupted one.

`DMI_INTEL_ME_ERROR_DEBUG`::
Debug failure.

`DMI_INTEL_ME_ERROR_UNSPEC`::
Error code is unknown, since the first interface is absent or not reported.

== Return value

`dmi_intel_me_error_name` returns the name of the value, translated to the
language of the current locale when a translation is available, or `nullptr`
if the value has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_intel_mei`(3)

== Standards

Not part of the SMBIOS specification. Defined by the Intel reference code,
which gives the structures type 219 by default. The layouts of the firmware
status registers are the ones of the Intel Management Engine, as coreboot
describes them.
