== Name

dmi_system_log_access_method, dmi_system_log_access_method_name - system event
log access methods

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/system-event-log.h>

typedef enum dmi_system_log_access_method {
    DMI_SYSTEM_LOG_ACCESS_METHOD_INDEXED_IO_8BIT_1_1 = 0x00,
    DMI_SYSTEM_LOG_ACCESS_METHOD_INDEXED_IO_8BIT_2_1 = 0x01,
    DMI_SYSTEM_LOG_ACCESS_METHOD_INDEXED_IO_16BIT    = 0x02,
    DMI_SYSTEM_LOG_ACCESS_METHOD_MMAP_32BIT_ADDR     = 0x03,
    DMI_SYSTEM_LOG_ACCESS_METHOD_DATA_FUNCTIONS      = 0x04,
    DMI_SYSTEM_LOG_ACCESS_METHOD_OEM_START           = 0x80,
    DMI_SYSTEM_LOG_ACCESS_METHOD_OEM_END             = 0xFF,
} dmi_system_log_access_method_t;

const char *dmi_system_log_access_method_name(
        dmi_system_log_access_method_t value);
----

== Description

The `dmi_system_log_access_method_t` enumeration tells how software reaches
the area of the system event log, and how the access method address is to be
read. It is the type of the `access_method` field of
`dmi_system_event_log_t`. Values 0x05 to 0x7F are reserved by the
specification, and values 0x80 to 0xFF are specific to the firmware vendor or
the OEM.

The `dmi_system_log_access_method_name` function returns the printable name of
a value, as the command line tool shows it. The name is translated to the
locale set with `dmi_set_locale`, when the library is built with ICU4C support
and has a translation of it.

=== Values

`DMI_SYSTEM_LOG_ACCESS_METHOD_INDEXED_IO_8BIT_1_1`::
Indexed I/O with one 8-bit index port and one 8-bit data port, given by the
`access_ports` field of the event log. Up to 256 bytes of the log can be
reached.

`DMI_SYSTEM_LOG_ACCESS_METHOD_INDEXED_IO_8BIT_2_1`::
Indexed I/O with two 8-bit index ports, which take the low and the high
byte of the offset, and one 8-bit data port.

`DMI_SYSTEM_LOG_ACCESS_METHOD_INDEXED_IO_16BIT`::
Indexed I/O with one 16-bit index port and one 8-bit data port.

`DMI_SYSTEM_LOG_ACCESS_METHOD_MMAP_32BIT_ADDR`::
Memory-mapped log area, at the 32-bit physical address held by the
`access_address` field of the event log.

`DMI_SYSTEM_LOG_ACCESS_METHOD_DATA_FUNCTIONS`::
Log reached through the general-purpose non-volatile data functions of the
firmware, with the handle held by the `access_gpnv_handle` field of the
event log.

`DMI_SYSTEM_LOG_ACCESS_METHOD_OEM_START`::
First value of the firmware vendor or OEM-specific range.

`DMI_SYSTEM_LOG_ACCESS_METHOD_OEM_END`::
Last value of the firmware vendor or OEM-specific range.

== Return value

`dmi_system_log_access_method_name` returns the name of the value, or `nullptr`
if the value has no name. The name is a static string, which must not be
modified or freed.

== Errors

None.

`dmi_system_event_log`(3), `dmi_system_log_io_ports`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.0 or newer.
