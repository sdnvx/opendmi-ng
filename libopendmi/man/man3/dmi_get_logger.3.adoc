== Name

dmi_get_logger - get the logging handler of an OpenDMI context.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/context.h>

dmi_log_t *dmi_get_logger(const dmi_context_t *context);
----

== Description

The `dmi_get_logger` function returns the handler the messages of the
context are written to, which has been set with `dmi_set_logger`(3).

=== Parameters

`context`::
Context to query.

== Return value

Returns the logging handler, or `nullptr` if the context has none or
`context` is `nullptr`.

== Errors

None.

== See also

`dmi_set_logger`(3),
`dmi_log`(3)
