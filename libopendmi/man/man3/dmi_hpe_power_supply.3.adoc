== Name

dmi_hpe_power_supply - HP/HPE power supply information structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/power-supply.h>

typedef struct dmi_hpe_power_supply {
    dmi_handle_t power_supply_handle;
    const char *manufacturer;
    const char *revision;
    dmi_hpe_fru_access_t fru_access;
    uint8_t i2c_bus;
    uint8_t i2c_address;
} dmi_hpe_power_supply_t;
----

== Description

The `dmi_hpe_power_supply_t` structure holds the decoded HP/HPE power supply
information, which supplements the system power supply information (type 39)
with the actual manufacturer of the power supply and the way its FRU is
accessed.

The structure is returned by `dmi_entity_info`(3) for the structures decoded
by `dmi_hpe_power_supply_spec`, of type `DMI_TYPE(hpe_power_supply)`, declared
in `<opendmi/module/hpe.h>`, once the HPE extension module (`dmi_hpe_module`)
is enabled, which it is for HP and HPE servers. It lives as long as the
context it has been decoded in.

=== Fields

`power_supply_handle`::
Handle of the system power supply structure (type 39).

`manufacturer`::
Actual manufacturer.

`revision`::
Revision.

`fru_access`::
Method the FRU is accessed by, see `dmi_hpe_fru_access`(3).

`i2c_bus`::
I2C bus, or I2C segment with iLO. Set to `UINT8_MAX` when not available.

`i2c_address`::
I2C address, shifted left by one bit. Set to `UINT8_MAX` when not available.

== See also

`dmi_entity_info`(3),
`dmi_hpe_fru_access`(3),
`dmi_power_supply`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
