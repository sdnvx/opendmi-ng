== Name

dmi_encoder_tell - get the current position of an encoder.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/encoder.h>

size_t dmi_encoder_tell(const dmi_encoder_t *encoder);
----

== Description

The `dmi_encoder_tell` function returns the position of the next byte to
write, counted from the beginning of the structure the way the specification
counts it, so that it is the offset the field written next takes.

=== Parameters

`encoder`::
Encoder to query.

== Return value

Position of the next byte to write.
