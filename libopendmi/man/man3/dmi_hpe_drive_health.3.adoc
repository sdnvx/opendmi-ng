== Name

dmi_hpe_drive_health, dmi_hpe_drive_health_name - HP/HPE drive health statuses

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/drive.h>

typedef enum dmi_hpe_drive_health {
    DMI_HPE_DRIVE_HEALTH_OK       = 0x00,
    DMI_HPE_DRIVE_HEALTH_WARNING  = 0x01,
    DMI_HPE_DRIVE_HEALTH_CRITICAL = 0x02,
    DMI_HPE_DRIVE_HEALTH_UNKNOWN  = 0xFF
} dmi_hpe_drive_health_t;

const char *dmi_hpe_drive_health_name(dmi_hpe_drive_health_t value);
----

== Description

The `dmi_hpe_drive_health_t` enumeration tells the health status of a drive,
and is the type of the `health` field of `dmi_hpe_drive_t`.

The `dmi_hpe_drive_health_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_HPE_DRIVE_HEALTH_OK`::
OK.

`DMI_HPE_DRIVE_HEALTH_WARNING`::
Warning.

`DMI_HPE_DRIVE_HEALTH_CRITICAL`::
Critical.

`DMI_HPE_DRIVE_HEALTH_UNKNOWN`::
Unknown.

== Return value

`dmi_hpe_drive_health_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_drive`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
