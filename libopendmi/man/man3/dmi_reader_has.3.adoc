== Name

dmi_reader_has - check whether a reader holds at least the given number of bytes.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/reader.h>

bool dmi_reader_has(const dmi_reader_t *reader, size_t length);
----

== Description

The `dmi_reader_has` function checks whether at least `length` bytes remain
from the current position, which is how a decoder tells a field the data
carries in full from one it ends in the middle of.

=== Parameters

`reader`::
Reader to check.

`length`::
Number of bytes.

== Return value

`true` if at least `length` bytes remain from the current position, `false`
otherwise.
