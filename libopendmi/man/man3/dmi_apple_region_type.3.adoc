== Name

dmi_apple_region_type, dmi_apple_region_type_name - Types of the regions of the flash memory of Apple firmware

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/apple/firmware-volume.h>

typedef enum dmi_apple_region_type {
    DMI_APPLE_REGION_TYPE_UNUSED    = 0,
    DMI_APPLE_REGION_TYPE_RECOVERY  = 1,
    DMI_APPLE_REGION_TYPE_MAIN      = 2,
    DMI_APPLE_REGION_TYPE_NVRAM     = 3,
    DMI_APPLE_REGION_TYPE_CONFIG    = 4,
    DMI_APPLE_REGION_TYPE_DIAGVAULT = 5
} dmi_apple_region_type_t;

const char *dmi_apple_region_type_name(dmi_apple_region_type_t value);
----

== Description

The `dmi_apple_region_type_t` enumeration tells the type of a region of the
flash memory of the firmware, and is the type of the `type` field of
`dmi_apple_flash_region_t`.

The `dmi_apple_region_type_name` function returns the name of a value, as the command line
tool shows it.

=== Values

`DMI_APPLE_REGION_TYPE_UNUSED`::
Entry is not used.

`DMI_APPLE_REGION_TYPE_RECOVERY`::
Recovery firmware.

`DMI_APPLE_REGION_TYPE_MAIN`::
Main firmware.

`DMI_APPLE_REGION_TYPE_NVRAM`::
Non-volatile variables.

`DMI_APPLE_REGION_TYPE_CONFIG`::
Configuration.

`DMI_APPLE_REGION_TYPE_DIAGVAULT`::
Diagnostics vault.

== Return value

`dmi_apple_region_type_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_apple_flash_region`(3)

== Standards

Not part of the SMBIOS specification. Defined by the firmware of Macs, and
laid out as the `AppleSmBios.h` header of OpenCore describes it.
