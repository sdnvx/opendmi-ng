== Name

dmi_mgmt_nhi_device_type, dmi_mgmt_nhi_device_type_name - network host
interface device types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/mgmt-controller.h>

typedef enum dmi_mgmt_nhi_device_type {
    DMI_MGMT_NHI_DEVICE_TYPE_USB       = 0x02,
    DMI_MGMT_NHI_DEVICE_TYPE_PCI       = 0x03,
    DMI_MGMT_NHI_DEVICE_TYPE_USB_V2    = 0x04,
    DMI_MGMT_NHI_DEVICE_TYPE_PCI_V2    = 0x05,
    DMI_MGMT_NHI_DEVICE_TYPE_OEM_START = 0x80,
    DMI_MGMT_NHI_DEVICE_TYPE_OEM_END   = 0xFF
} dmi_mgmt_nhi_device_type_t;

const char *dmi_mgmt_nhi_device_type_name(dmi_mgmt_nhi_device_type_t value);
----

== Description

The `dmi_mgmt_nhi_device_type_t` enumeration tells the type of the device
through which the host reaches the management controller over a network host
interface, and is the type of the `device_type` field of `dmi_mgmt_nhi_t`. The
values from 0x80 to 0xFF are OEM-defined, and the other values the enumeration
does not name are reserved.

The `dmi_mgmt_nhi_device_type_name` function returns the printable name of a
value, as the command line tool shows it. The name is translated to the locale
set with `dmi_set_locale`, when the library is built with ICU4C support and has
a translation of it.

=== Values

`DMI_MGMT_NHI_DEVICE_TYPE_USB`::
USB network interface, see `dmi_mgmt_nhi_usb`(3).

`DMI_MGMT_NHI_DEVICE_TYPE_PCI`::
PCI or PCIe network interface, see `dmi_mgmt_nhi_pci`(3).

`DMI_MGMT_NHI_DEVICE_TYPE_USB_V2`::
USB network interface, second version of the descriptor, see
`dmi_mgmt_nhi_usb_v2`(3).

`DMI_MGMT_NHI_DEVICE_TYPE_PCI_V2`::
PCI or PCIe network interface, second version of the descriptor, see
`dmi_mgmt_nhi_pci_v2`(3).

`DMI_MGMT_NHI_DEVICE_TYPE_OEM_START`::
First OEM-defined device type, see `dmi_mgmt_nhi_oem`(3).

`DMI_MGMT_NHI_DEVICE_TYPE_OEM_END`::
Last OEM-defined device type.

== Return value

`dmi_mgmt_nhi_device_type_name` returns the name of the value, or `nullptr` if
the value has no name. The name is a static string, which must not be modified
or freed.

== Errors

None.

== See also

`dmi_mgmt_nhi`(3), `dmi_mgmt_nhi_format`(3)

== Standards

DMTF Redfish Host Interface Specification (DSP0270), which defines this data of
the management controller host interface structure (type 42) of the DMTF SMBIOS
Specification (DSP0134).
