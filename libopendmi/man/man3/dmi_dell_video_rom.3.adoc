== Name

dmi_dell_video_rom - Dell video BIOS information structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/dell/video-rom.h>

typedef struct dmi_dell_video_rom {
    const char *vendor;
    const char *version;
    uint8_t unknown_1;
    uint16_t unknown_2;
} dmi_dell_video_rom_t;
----

== Description

The `dmi_dell_video_rom_t` structure holds the decoded Dell video BIOS
information (type 216), which tells the vendor and the version of the video
BIOS.

The structure is returned by `dmi_entity_info`(3) for the structures decoded
by `dmi_dell_video_rom_spec`, of type `DMI_TYPE(dell_video_rom)`, declared in
`<opendmi/module/dell.h>`, once the Dell extension module (`dmi_dell_module`)
is enabled. It lives as long as the context it has been decoded in.

The layout is reverse engineered from the dumps of the data corpus, since no
public source describes the structure, and the members whose meaning is not
established are named after their position.

=== Fields

`vendor`::
Vendor of the video BIOS, as the firmware writes it, which may be quoted.

`version`::
Version of the video BIOS, as the firmware writes it, which may be quoted.

`unknown_1`::
Value whose meaning is not established, `1` in all known data.

`unknown_2`::
Value whose meaning is not established.

== See also

`dmi_entity_info`(3)

== Standards

Not part of the SMBIOS specification. Defined by Dell firmware, and reverse
engineered from the data corpus.
