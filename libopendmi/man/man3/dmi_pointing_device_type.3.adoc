== Name

dmi_pointing_device_type, dmi_pointing_device_type_name - pointing device types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/pointing-device.h>

typedef enum dmi_pointing_device_type {
    DMI_POINTING_DEVICE_TYPE_UNSPEC         = 0x00,
    DMI_POINTING_DEVICE_TYPE_OTHER          = 0x01,
    DMI_POINTING_DEVICE_TYPE_UNKNOWN        = 0x02,
    DMI_POINTING_DEVICE_TYPE_MOUSE          = 0x03,
    DMI_POINTING_DEVICE_TYPE_TRACK_BALL     = 0x04,
    DMI_POINTING_DEVICE_TYPE_TRACK_POINT    = 0x05,
    DMI_POINTING_DEVICE_TYPE_GLIDE_POINT    = 0x06,
    DMI_POINTING_DEVICE_TYPE_TOUCH_PAD      = 0x07,
    DMI_POINTING_DEVICE_TYPE_TOUCH_SCREEN   = 0x08,
    DMI_POINTING_DEVICE_TYPE_OPTICAL_SENSOR = 0x09,
} dmi_pointing_device_type_t;

const char *dmi_pointing_device_type_name(dmi_pointing_device_type_t value);
----

== Description

The `dmi_pointing_device_type_t` enumeration tells the kind of a built-in
pointing device, and is the type of the `type` field of
`dmi_pointing_device_t`.

The `dmi_pointing_device_type_name` function returns the printable name of a
value, as the command line tool shows it. The name is translated to the locale
set with `dmi_set_locale`, when the library is built with ICU4C support and
has a translation of it.

=== Values

`DMI_POINTING_DEVICE_TYPE_UNSPEC`::
Unspecified.

`DMI_POINTING_DEVICE_TYPE_OTHER`::
Other type.

`DMI_POINTING_DEVICE_TYPE_UNKNOWN`::
Unknown type.

`DMI_POINTING_DEVICE_TYPE_MOUSE`::
Mouse.

`DMI_POINTING_DEVICE_TYPE_TRACK_BALL`::
Track ball.

`DMI_POINTING_DEVICE_TYPE_TRACK_POINT`::
Track point.

`DMI_POINTING_DEVICE_TYPE_GLIDE_POINT`::
Glide point.

`DMI_POINTING_DEVICE_TYPE_TOUCH_PAD`::
Touch pad.

`DMI_POINTING_DEVICE_TYPE_TOUCH_SCREEN`::
Touch screen.

`DMI_POINTING_DEVICE_TYPE_OPTICAL_SENSOR`::
Optical sensor.

== Return value

`dmi_pointing_device_type_name` returns the name of the value, or `nullptr` if
the value has no name. The name is a static string, which must not be modified
or freed.

== Errors

None.

== See also

`dmi_pointing_device`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.1 or newer.
