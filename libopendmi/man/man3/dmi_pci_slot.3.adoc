== Name

dmi_pci_slot - PCI slot number

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/common.h>

typedef uint16_t dmi_pci_slot_t;
----

== Description

The `dmi_pci_slot_t` type holds the identifier of a PCI slot, which matches the
slot identifier of the system slot structures (type 9) describing it.

The type is shared by several structures: it is the type of the `pci_slot_id`
field of `dmi_intel_rsd_pcie_t`, the `pci_slot_id` field of
`dmi_intel_rsd_network_card_t`, the `pci_slot_id` field of
`dmi_intel_rsd_fpga_t`, and the `pci_slot_id` field of
`dmi_intel_rsd_cabled_pcie_t`.

== See also

`dmi_intel_rsd_pcie`(3), `dmi_intel_rsd_network_card`(3),
`dmi_intel_rsd_fpga`(3), `dmi_intel_rsd_cabled_pcie`(3), `dmi_pci_addr`(3)

== Standards

Not part of the SMBIOS specification. Used by the structures defined by Intel
Rack Scale Design firmware.
