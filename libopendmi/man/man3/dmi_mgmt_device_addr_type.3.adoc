== Name

dmi_mgmt_device_addr_type, dmi_mgmt_device_addr_type_name - address types of
management devices

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/mgmt-device.h>

typedef enum dmi_mgmt_device_addr_type {
    DMI_MGMT_DEVICE_ADDR_TYPE_UNSPEC  = 0x00,
    DMI_MGMT_DEVICE_ADDR_TYPE_OTHER   = 0x01,
    DMI_MGMT_DEVICE_ADDR_TYPE_UNKNOWN = 0x02,
    DMI_MGMT_DEVICE_ADDR_TYPE_PORT    = 0x03,
    DMI_MGMT_DEVICE_ADDR_TYPE_MEMORY  = 0x04,
    DMI_MGMT_DEVICE_ADDR_TYPE_SMBUS   = 0x05,
} dmi_mgmt_device_addr_type_t;

const char *dmi_mgmt_device_addr_type_name(dmi_mgmt_device_addr_type_t value);
----

== Description

The `dmi_mgmt_device_addr_type_t` enumeration tells how a management device is
accessed, and so how its address is to be read. It is the type of the
`address_type` field of `dmi_mgmt_device_t`.

The `dmi_mgmt_device_addr_type_name` function returns the printable name of a
value, as the command line tool shows it. The name is translated to the locale
set with `dmi_set_locale`, when the library is built with ICU4C support and has
a translation of it.

=== Values

`DMI_MGMT_DEVICE_ADDR_TYPE_UNSPEC`::
Unspecified.

`DMI_MGMT_DEVICE_ADDR_TYPE_OTHER`::
Other address type.

`DMI_MGMT_DEVICE_ADDR_TYPE_UNKNOWN`::
Unknown address type.

`DMI_MGMT_DEVICE_ADDR_TYPE_PORT`::
I/O port address.

`DMI_MGMT_DEVICE_ADDR_TYPE_MEMORY`::
Memory address.

`DMI_MGMT_DEVICE_ADDR_TYPE_SMBUS`::
SMBus address.

== Return value

`dmi_mgmt_device_addr_type_name` returns the name of the value, or `nullptr` if
the value has no name. The name is a static string, which must not be modified
or freed.

== Errors

None.

== See also

`dmi_mgmt_device`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.3 or newer.
