== Name

dmi_hpe_interleave_health, dmi_hpe_interleave_health_name - HP/HPE interleave set health statuses

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/dimm-config.h>

typedef enum dmi_hpe_interleave_health {
    DMI_HPE_INTERLEAVE_HEALTH_HEALTHY      = 0x00,
    DMI_HPE_INTERLEAVE_HEALTH_DIMM_MISSING = 0x01,
    DMI_HPE_INTERLEAVE_HEALTH_INACTIVE     = 0x02,
    DMI_HPE_INTERLEAVE_HEALTH_SPA_MISSING  = 0x03,
    DMI_HPE_INTERLEAVE_HEALTH_NEW_GOAL     = 0x04,
    DMI_HPE_INTERLEAVE_HEALTH_LOCKED       = 0x05,
    DMI_HPE_INTERLEAVE_HEALTH_UNSPEC       = 0xFF
} dmi_hpe_interleave_health_t;

const char *dmi_hpe_interleave_health_name(dmi_hpe_interleave_health_t value);
----

== Description

The `dmi_hpe_interleave_health_t` enumeration tells the health of an
interleave set of memory regions, and is the type of the `interleave_health`
field of `dmi_hpe_dimm_config_t`.

The `dmi_hpe_interleave_health_name` function returns the name of a value, as
the command line tool shows it.

=== Values

`DMI_HPE_INTERLEAVE_HEALTH_HEALTHY`::
Healthy.

`DMI_HPE_INTERLEAVE_HEALTH_DIMM_MISSING`::
DIMM missing.

`DMI_HPE_INTERLEAVE_HEALTH_INACTIVE`::
Configuration inactive.

`DMI_HPE_INTERLEAVE_HEALTH_SPA_MISSING`::
SPA missing.

`DMI_HPE_INTERLEAVE_HEALTH_NEW_GOAL`::
New goal.

`DMI_HPE_INTERLEAVE_HEALTH_LOCKED`::
Locked.

`DMI_HPE_INTERLEAVE_HEALTH_UNSPEC`::
Not specified.

== Return value

`dmi_hpe_interleave_health_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_dimm_config`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
