== Name

dmi_decoder_skip - step over bytes of a structure without reading them.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/decoder.h>

bool dmi_decoder_skip(dmi_decoder_t *decoder, size_t length);
----

== Description

The `dmi_decoder_skip` function moves the cursor forward by `length` bytes,
which is what the fields of a structure the framework does not decode are
stepped over with.

=== Parameters

`decoder`::
Decoder to advance.

`length`::
Number of the bytes to skip.

== Return value

`true` on success, `false` if there are not enough bytes remaining.

== Errors

None.

== See also

`dmi_decoder_remaining`(3),
`dmi_reader_skip`(3),
`dmi_reader_skip_ex`(3)
