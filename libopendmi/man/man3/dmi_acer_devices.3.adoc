== Name

dmi_acer_devices - Acer device list structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/acer/devices.h>

typedef struct dmi_acer_devices {
    size_t device_count;
    dmi_acer_device_t *devices;
} dmi_acer_devices_t;
----

== Description

The `dmi_acer_devices_t` structure holds the decoded Acer device list (type
171), which lists the devices of a laptop by their PCI or USB vendor and
device IDs, e.g. the graphics, the webcam, the audio and the wireless network
adapter.

The structure is returned by `dmi_entity_info`(3) for the structures decoded
by `dmi_acer_devices_spec`, of type `DMI_TYPE(ACER_DEVICES)`, declared in
`<opendmi/module/acer.h>`, once the Acer extension module (`dmi_acer_module`)
is enabled. It lives as long as the context it has been decoded in.

The layout is reverse engineered from the dumps of the data corpus, since no
public source describes the structure, and the members whose meaning is not
established are named after their position.

=== Fields

`device_count`::
Number of the devices.

`devices`::
Devices, see `dmi_acer_device`(3). May be `nullptr` when `device_count` is 0.

== See also

`dmi_entity_info`(3),
`dmi_acer_device`(3)

== Standards

Not part of the SMBIOS specification. Defined by Acer firmware, and reverse
engineered from the data corpus.
