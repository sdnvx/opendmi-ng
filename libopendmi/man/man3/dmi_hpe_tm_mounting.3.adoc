== Name

dmi_hpe_tm_mounting, dmi_hpe_tm_mounting_name - HP/HPE trusted module mountings

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/trusted-module.h>

typedef enum dmi_hpe_tm_mounting {
    DMI_HPE_TM_MOUNTING_UNSPEC   = 0x00,
    DMI_HPE_TM_MOUNTING_OPTIONAL = 0x01,
    DMI_HPE_TM_MOUNTING_STANDARD = 0x02,
    DMI_HPE_TM_MOUNTING_SOLDERED = 0x03
} dmi_hpe_tm_mounting_t;

const char *dmi_hpe_tm_mounting_name(dmi_hpe_tm_mounting_t value);
----

== Description

The `dmi_hpe_tm_mounting_t` enumeration tells how a trusted module is mounted,
and is the type of the `mounting` field of `dmi_hpe_trusted_module_t`.

The `dmi_hpe_tm_mounting_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_HPE_TM_MOUNTING_UNSPEC`::
Not specified.

`DMI_HPE_TM_MOUNTING_OPTIONAL`::
Pluggable and optional.

`DMI_HPE_TM_MOUNTING_STANDARD`::
Pluggable but standard.

`DMI_HPE_TM_MOUNTING_SOLDERED`::
Soldered down on the system board.

== Return value

`dmi_hpe_tm_mounting_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_trusted_module`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
