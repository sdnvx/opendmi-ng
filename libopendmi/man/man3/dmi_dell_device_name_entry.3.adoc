== Name

dmi_dell_device_name_entry - Name of a device

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/dell/device-names.h>

typedef struct dmi_dell_device_name_entry {
    const char *fqdd;
    dmi_handle_t handle;
    uint8_t unknown;
} dmi_dell_device_name_entry_t;
----

== Description

The `dmi_dell_device_name_entry_t` structure gives a device the name the
management controller (iDRAC) knows it by, and is the type of the elements of
the `devices` array of `dmi_dell_device_names_t`.

=== Fields

`fqdd`::
Fully qualified device descriptor (FQDD) of the device, e.g. `CPU.Socket.1`
or `DIMM.Socket.A1`.

`handle`::
Handle of the structure describing the device, of a processor (type 4) or of
a memory device (type 17) in all known data, which the `link.wrong-type` lint
rule checks it against.

`unknown`::
Value whose meaning is not established, `0` in all known data.

== See also

`dmi_dell_device_names`(3)

== Standards

Not part of the SMBIOS specification. Defined by Dell firmware, and reverse
engineered from the data corpus.
