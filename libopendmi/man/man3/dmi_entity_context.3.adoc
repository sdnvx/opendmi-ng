== Name

dmi_entity_context - get the OpenDMI context a structure belongs to.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity.h>

dmi_context_t *dmi_entity_context(const dmi_entity_t *entity);
----

== Description

The `dmi_entity_context` function returns the context a structure belongs
to, which holds the data the structure has been decoded from.

Code which is given a structure alone, such as a handler of an extension
module, reaches the context through it to raise errors, see
`dmi_error_raise`(3), and to write messages, see `dmi_log`(3).

=== Parameters

`entity`::
Structure to query.

== Return value

Returns the context, or `nullptr` if `entity` is `nullptr`.

== Errors

None.

== See also

`dmi_entity_create`(3),
`dmi_error_raise`(3),
`dmi_log`(3)
