== Name

dmi_intel_rsd_storage_proto, dmi_intel_rsd_storage_proto_name - Intel RSD
storage protocol types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/intel-rsd/storage-device.h>

typedef enum dmi_intel_rsd_storage_proto {
    DMI_INTEL_RSD_STORAGE_PROTO_UNKNOWN = 0x00,
    DMI_INTEL_RSD_STORAGE_PROTO_IDE     = 0x01,
    DMI_INTEL_RSD_STORAGE_PROTO_AHCI    = 0x02,
    DMI_INTEL_RSD_STORAGE_PROTO_NVME    = 0x03,
    DMI_INTEL_RSD_STORAGE_PROTO_USB     = 0x04
} dmi_intel_rsd_storage_proto_t;

const char *dmi_intel_rsd_storage_proto_name(
        dmi_intel_rsd_storage_proto_t value);
----

== Description

The `dmi_intel_rsd_storage_proto_t` enumeration tells the protocol a storage
device is accessed with, and is the type of the `protocol` field of
`dmi_intel_rsd_storage_device_t`.

The `dmi_intel_rsd_storage_proto_name` function returns the name of a value,
as the command line tool shows it.

=== Values

`DMI_INTEL_RSD_STORAGE_PROTO_UNKNOWN`::
Unknown.

`DMI_INTEL_RSD_STORAGE_PROTO_IDE`::
IDE.

`DMI_INTEL_RSD_STORAGE_PROTO_AHCI`::
AHCI.

`DMI_INTEL_RSD_STORAGE_PROTO_NVME`::
NVM Express.

`DMI_INTEL_RSD_STORAGE_PROTO_USB`::
USB.

== Return value

`dmi_intel_rsd_storage_proto_name` returns the name of the value, translated to
the language of the current locale when a translation is available, or
`nullptr` if the value has no name. The returned string must not be modified or
freed.

== Errors

None.

== See also

`dmi_intel_rsd_storage_device`(3), `dmi_intel_rsd_storage_connector`(3),
`dmi_intel_rsd_storage_device_type`(3)

== Standards

Not part of the SMBIOS specification. Defined by Intel Rack Scale Design (RSD)
firmware.
