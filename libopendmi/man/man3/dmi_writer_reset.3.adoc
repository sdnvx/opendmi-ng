== Name

dmi_writer_reset - reposition a writer cursor to the beginning of its range.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/writer.h>

void dmi_writer_reset(dmi_writer_t *writer);
----

== Description

The `dmi_writer_reset` function repositions the writer cursor to the
beginning of its range, so that the data is written again from there.

The data written already is kept until it is written over, the way the data
of a buffer is kept until it is.

=== Parameters

`writer`::
Writer to reset.
