== Name

dmi_reader_get_string - read and decode an SMBIOS string reference from the reader at the current position.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/reader.h>

dmi_reader_get_string(reader, pvalue)
----

== Description

The `dmi_reader_get_string` macro reads a `dmi_string_t` index from the reader
and resolves it to a string pointer via `dmi_entity_string`. The reader cursor
is advanced.

=== Parameters

`reader`::
Reader to read from.

`pvalue`::
Pointer to a variable that receives the resolved string.

== Return value

Returns `true` on success, `false` if there are not enough bytes remaining.
