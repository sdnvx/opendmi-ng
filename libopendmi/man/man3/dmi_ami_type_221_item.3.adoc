== Name

dmi_ami_type_221_item - item of AMI type 221 structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/ami/type-221.h>

typedef struct dmi_ami_type_221_item {
    const char *name;
    const char *string;
    uint8_t unknown_1;
    uint16_t unknown_2;
    uint16_t unknown_3;
} dmi_ami_type_221_item_t;
----

== Description

The `dmi_ami_type_221_item_t` structure describes one item of the AMI structure
of type 221, and is the type of the elements of the `items` array of
`dmi_ami_type_221_t`. The meaning of the numeric fields is not publicly
documented; their values are the ones the structure carries.

=== Fields

`name`::
Name of the item. `nullptr` when the item has none.

`string`::
String value of the item. `nullptr` when the item has none.

`unknown_1`::
First number of the item, one byte. `UINT8_MAX` means unspecified.

`unknown_2`::
Second number of the item, 16 bits. `UINT16_MAX` means unspecified.

`unknown_3`::
Third number of the item, 16 bits. `UINT16_MAX` means unspecified.

== See also

`dmi_ami_type_221`(3)

== Standards

Not part of the SMBIOS specification. Defined by AMI firmware.
