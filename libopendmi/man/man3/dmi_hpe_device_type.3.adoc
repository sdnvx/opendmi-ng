== Name

dmi_hpe_device_type, dmi_hpe_device_type_name - HP/HPE correlated device types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/device-correlation.h>

typedef enum dmi_hpe_device_type {
    DMI_HPE_DEVICE_TYPE_UNKNOWN         = 0x00,
    DMI_HPE_DEVICE_TYPE_FLEXIBLE_LOM    = 0x03,
    DMI_HPE_DEVICE_TYPE_EMBEDDED_LOM    = 0x04,
    DMI_HPE_DEVICE_TYPE_SLOT_NIC        = 0x05,
    DMI_HPE_DEVICE_TYPE_STORAGE         = 0x06,
    DMI_HPE_DEVICE_TYPE_SMART_ARRAY     = 0x07,
    DMI_HPE_DEVICE_TYPE_USB_DISK        = 0x08,
    DMI_HPE_DEVICE_TYPE_OTHER_PCI       = 0x09,
    DMI_HPE_DEVICE_TYPE_RAM_DISK        = 0x0A,
    DMI_HPE_DEVICE_TYPE_FIRMWARE_VOLUME = 0x0B,
    DMI_HPE_DEVICE_TYPE_UEFI_SHELL      = 0x0C,
    DMI_HPE_DEVICE_TYPE_USB_BOOT        = 0x0D,
    DMI_HPE_DEVICE_TYPE_DYNAMIC_ARRAY   = 0x0E,
    DMI_HPE_DEVICE_TYPE_FILE            = 0x0F,
    DMI_HPE_DEVICE_TYPE_NVME            = 0x10,
    DMI_HPE_DEVICE_TYPE_NVDIMM          = 0x11,
    DMI_HPE_DEVICE_TYPE_EMBEDDED_GPU    = 0x12
} dmi_hpe_device_type_t;

const char *dmi_hpe_device_type_name(dmi_hpe_device_type_t value);
----

== Description

The `dmi_hpe_device_type_t` enumeration tells the type of a device, as UEFI
boot entries name it, and is the type of the `device_type` field of
`dmi_hpe_device_correlation_t`. Other values may be found in the data, and are
kept as they are.

The `dmi_hpe_device_type_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_HPE_DEVICE_TYPE_UNKNOWN`::
Unknown.

`DMI_HPE_DEVICE_TYPE_FLEXIBLE_LOM`::
Flexible LOM.

`DMI_HPE_DEVICE_TYPE_EMBEDDED_LOM`::
Embedded LOM.

`DMI_HPE_DEVICE_TYPE_SLOT_NIC`::
NIC in a slot.

`DMI_HPE_DEVICE_TYPE_STORAGE`::
Storage controller.

`DMI_HPE_DEVICE_TYPE_SMART_ARRAY`::
Smart Array storage controller.

`DMI_HPE_DEVICE_TYPE_USB_DISK`::
USB hard disk.

`DMI_HPE_DEVICE_TYPE_OTHER_PCI`::
Other PCI device.

`DMI_HPE_DEVICE_TYPE_RAM_DISK`::
RAM disk.

`DMI_HPE_DEVICE_TYPE_FIRMWARE_VOLUME`::
Firmware volume.

`DMI_HPE_DEVICE_TYPE_UEFI_SHELL`::
UEFI shell.

`DMI_HPE_DEVICE_TYPE_USB_BOOT`::
Generic UEFI USB boot entry.

`DMI_HPE_DEVICE_TYPE_DYNAMIC_ARRAY`::
Dynamic Smart Array controller.

`DMI_HPE_DEVICE_TYPE_FILE`::
File.

`DMI_HPE_DEVICE_TYPE_NVME`::
NVMe hard drive.

`DMI_HPE_DEVICE_TYPE_NVDIMM`::
NVDIMM.

`DMI_HPE_DEVICE_TYPE_EMBEDDED_GPU`::
Embedded GPU.

== Return value

`dmi_hpe_device_type_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_device_correlation`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
