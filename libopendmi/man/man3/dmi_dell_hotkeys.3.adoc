== Name

dmi_dell_hotkeys - Dell hotkeys structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/dell/hotkeys.h>

typedef struct dmi_dell_hotkeys {
    size_t hotkey_count;
    dmi_dell_hotkey_entry_t *hotkeys;
} dmi_dell_hotkeys_t;
----

== Description

The `dmi_dell_hotkeys_t` structure holds the decoded Dell hotkeys (type 178),
which map the scan codes of the hotkeys of a laptop to their functions, which
the Dell WMI driver reads.

The structure is returned by `dmi_entity_info`(3) for the structures decoded
by `dmi_dell_hotkeys_spec`, of type `DMI_TYPE(dell_hotkeys)`, declared in
`<opendmi/module/dell.h>`, once the Dell extension module (`dmi_dell_module`)
is enabled. It lives as long as the context it has been decoded in.

Mappings run to the end of the structure, which carries no number of them of
its own.

=== Fields

`hotkey_count`::
Number of the hotkeys.

`hotkeys`::
Hotkeys, see `dmi_dell_hotkey_entry`(3). May be `nullptr` when `hotkey_count`
is 0.

== See also

`dmi_entity_info`(3),
`dmi_dell_hotkey_entry`(3)

== Standards

Not part of the SMBIOS specification. Defined by Dell firmware, as the Dell
WMI driver of Linux and dmidecode describe it.
