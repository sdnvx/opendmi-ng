== Name

dmi_hpe_usb_sharing, dmi_hpe_usb_sharing_name - HP/HPE USB management port sharing

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/usb-port.h>

typedef enum dmi_hpe_usb_sharing {
    DMI_HPE_USB_SHARING_NONE      = 0x00,
    DMI_HPE_USB_SHARING_SWITCH    = 0x01,
    DMI_HPE_USB_SHARING_AUTOMATIC = 0x02
} dmi_hpe_usb_sharing_t;

const char *dmi_hpe_usb_sharing_name(dmi_hpe_usb_sharing_t value);
----

== Description

The `dmi_hpe_usb_sharing_t` enumeration tells whether a USB port is shared
with the management controller, and how, and is the type of the `sharing`
field of `dmi_hpe_usb_port_t`.

The `dmi_hpe_usb_sharing_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_HPE_USB_SHARING_NONE`::
Not shared.

`DMI_HPE_USB_SHARING_SWITCH`::
Shared with a physical switch.

`DMI_HPE_USB_SHARING_AUTOMATIC`::
Shared with automatic control.

== Return value

`dmi_hpe_usb_sharing_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_usb_port`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
