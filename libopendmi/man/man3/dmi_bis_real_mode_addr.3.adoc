== Name

dmi_bis_real_mode_addr - real mode address

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/bis-entry-point.h>

typedef struct dmi_bis_real_mode_addr {
    uint16_t segment;
    uint16_t offset;
} dmi_bis_real_mode_addr_t;
----

== Description

The `dmi_bis_real_mode_addr_t` structure holds a real mode (16:16)
address, made of a segment and an offset: the linear address is
`segment` * 16 + `offset`. It is the type of the `entry_point_16` field of
`dmi_bis_entry_point_t`.

=== Fields

`segment`::
Segment of the address.

`offset`::
Offset of the address within the segment.

== See also

`dmi_bis_entry_point`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.3 or newer.
