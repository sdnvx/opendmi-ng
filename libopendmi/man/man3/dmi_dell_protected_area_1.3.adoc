== Name

dmi_dell_protected_area_1 - Dell protected area type 1 structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/dell/protected-area-1.h>

typedef struct dmi_dell_protected_area_1 {
    uint16_t token_id;
    uint8_t value_length;
    dmi_dell_value_format_t value_format;
    uint16_t validation_key;
    uint16_t index_port;
    uint16_t data_port;
    dmi_dell_check_type_t check_type;
    uint8_t value_start;
    uint8_t check_index;
} dmi_dell_protected_area_1_t;
----

== Description

The `dmi_dell_protected_area_1_t` structure holds the decoded Dell protected
area type 1 structure (type 213): where a protected value, such as a password,
is kept in CMOS, how it is encoded, and where its checksum is. The CMOS
locations are accessed through the indexed I/O ports the structure gives.

The structure is returned by `dmi_entity_info`(3) for the structures of type
`DMI_TYPE(dell_protected_area_1)`, declared in `<opendmi/module/dell.h>`, and
lives as long as the context it has been decoded in.

=== Fields

`token_id`::
Identifier of the token of the protected value.

`value_length`::
Length of the protected value.

`value_format`::
How the protected value is encoded.

`validation_key`::
Validation key of the protected value, as the structure carries it.

`index_port`::
Address of the I/O port written to select a CMOS location.

`data_port`::
Address of the I/O port through which the selected CMOS location is read and
written.

`check_type`::
How the checksum of the protected value is computed.

`value_start`::
CMOS index of the protected value.

`check_index`::
CMOS index of the checksum of the protected value.

== Examples

[source, c]
----
dmi_registry_t              *registry = dmi_get_registry(context);
dmi_entity_t                *entity   = dmi_registry_lookup_first(registry,
                                            DMI_TYPE(dell_protected_area_1),
                                            true);
dmi_dell_protected_area_1_t *area     = dmi_entity_info(entity,
                                            DMI_TYPE(dell_protected_area_1));

if (area != nullptr) {
    printf("Token 0x%04x: %u bytes at CMOS index 0x%02x\n", area->token_id,
           area->value_length, area->value_start);
}
----

== Standards

Not part of the SMBIOS specification. Defined by Dell firmware, see the Dell
Protected Area Type 1 (Type 213) chapter of the reference manual.
