== Name

dmi_dell_check_type, dmi_dell_check_type_name - Dell CMOS checksum types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/dell/common.h>

typedef enum dmi_dell_check_type {
    DMI_DELL_CHECK_TYPE_WORD_CHECKSUM   = 0x00,
    DMI_DELL_CHECK_TYPE_BYTE_CHECKSUM   = 0x01,
    DMI_DELL_CHECK_TYPE_WORD_CRC        = 0x02,
    DMI_DELL_CHECK_TYPE_WORD_CHECKSUM_N = 0x03,
} dmi_dell_check_type_t;

const char *dmi_dell_check_type_name(dmi_dell_check_type_t value);
----

== Description

The `dmi_dell_check_type_t` enumeration tells how the checksum of a range of
CMOS locations is computed. It is the type of the `check_type` field of
`dmi_dell_indexed_io_t`, `dmi_dell_protected_area_1_t` and
`dmi_dell_protected_area_2_t`, and of the `range_check_type` field of
`dmi_dell_protected_area_2_t`.

The `dmi_dell_check_type_name` function returns the printable name of a value,
as the command line tool shows it. The name is translated to the locale set
with `dmi_set_locale`, when the library is built with ICU4C support and has a
translation of it.

=== Values

`DMI_DELL_CHECK_TYPE_WORD_CHECKSUM`::
Running sum of the checked locations, kept in a 16-bit word.

`DMI_DELL_CHECK_TYPE_BYTE_CHECKSUM`::
Running sum of the checked locations, kept in a byte.

`DMI_DELL_CHECK_TYPE_WORD_CRC`::
CRC of the checked locations, kept in a 16-bit word.

`DMI_DELL_CHECK_TYPE_WORD_CHECKSUM_N`::
Running sum of the checked locations, negated (`~sum + 1`), kept in a 16-bit
word.

== Return value

`dmi_dell_check_type_name` returns the name of the value, or `nullptr` if the
value has no name. The name is a static string, which must not be modified or
freed.

== Errors

None.

== See also

`dmi_dell_indexed_io`(3), `dmi_dell_protected_area_1`(3),
`dmi_dell_protected_area_2`(3)

== Standards

Not part of the SMBIOS specification. Defined by Dell firmware, see the Dell
Indexed IO (Type 212) chapter of the reference manual.
