== Name

dmi_buffer_clear - drop the data of a buffer, keeping its memory.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/buffer.h>

void dmi_buffer_clear(dmi_buffer_t *buffer);
----

== Description

The `dmi_buffer_clear` function drops the data of the buffer, keeping the
memory it holds for the data written next, so that a buffer filled again and
again allocates once.

Everything referring to the data of the buffer, such as the binary members
of the structures decoded from it, refers to data which has been dropped
afterwards.

=== Parameters

`buffer`::
Buffer to clear.
