== Name

dmi_system_wakeup_type, dmi_system_wakeup_type_name - system wake-up types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/system.h>

typedef enum dmi_system_wakeup_type {
    DMI_SYSTEM_WAKEUP_TYPE_RESERVED      = 0x00,
    DMI_SYSTEM_WAKEUP_TYPE_OTHER         = 0x01,
    DMI_SYSTEM_WAKEUP_TYPE_UNKNOWN       = 0x02,
    DMI_SYSTEM_WAKEUP_TYPE_APM_TIMER     = 0x03,
    DMI_SYSTEM_WAKEUP_TYPE_MODEM_RING    = 0x04,
    DMI_SYSTEM_WAKEUP_TYPE_LAN_REMOTE    = 0x05,
    DMI_SYSTEM_WAKEUP_TYPE_POWER_SWITCH  = 0x06,
    DMI_SYSTEM_WAKEUP_TYPE_PCI_PME       = 0x07,
    DMI_SYSTEM_WAKEUP_TYPE_POWER_RESTORE = 0x08,
} dmi_system_wakeup_type_t;

const char *dmi_system_wakeup_type_name(dmi_system_wakeup_type_t value);
----

== Description

The `dmi_system_wakeup_type_t` enumeration tells which event powered a system
up, and is the type of the `wakeup_type` field of `dmi_system_t`.

The `dmi_system_wakeup_type_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_SYSTEM_WAKEUP_TYPE_RESERVED`::
Reserved; also the value of data older than SMBIOS 2.1, which does not carry
the field.

`DMI_SYSTEM_WAKEUP_TYPE_OTHER`::
Other.

`DMI_SYSTEM_WAKEUP_TYPE_UNKNOWN`::
Unknown.

`DMI_SYSTEM_WAKEUP_TYPE_APM_TIMER`::
APM timer.

`DMI_SYSTEM_WAKEUP_TYPE_MODEM_RING`::
Ring of a modem.

`DMI_SYSTEM_WAKEUP_TYPE_LAN_REMOTE`::
Remote wake-up over the local network.

`DMI_SYSTEM_WAKEUP_TYPE_POWER_SWITCH`::
Power switch.

`DMI_SYSTEM_WAKEUP_TYPE_PCI_PME`::
PCI power management event (PME#).

`DMI_SYSTEM_WAKEUP_TYPE_POWER_RESTORE`::
Return of AC power.

== Return value

`dmi_system_wakeup_type_name` returns the name of the value, or `nullptr` if
the value has no name. The name is in English, or translated to the locale set
with `dmi_set_locale` when the library is built with localization support and
has a translation of it. The string must not be modified or freed; a translated
one stays valid until the locale is changed.

== Errors

None.

== See also

`dmi_system`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.1 or newer.
