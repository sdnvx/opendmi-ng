== Description

The `dmi_hpe_firmware_type_t` enumeration tells the firmware component a
version indicator describes, and is the type of the `firmware_type` field of
`dmi_hpe_version_t`. Other values may be found in the data, and are kept as
they are.

The `dmi_hpe_firmware_type_name` function returns the name of a value, as the
command line tool shows it.

== Return value

`dmi_hpe_firmware_type_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_version`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
