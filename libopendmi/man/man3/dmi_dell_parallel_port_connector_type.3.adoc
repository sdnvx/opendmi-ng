== Name

dmi_dell_parallel_port_connector_type_name - Dell parallel port connector types

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/entity/dell/parallel-port.h>

typedef enum dmi_dell_parallel_port_connector_type {
    DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_UNSPEC      = 0x00,
    DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_OTHER       = 0x01,
    DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_UNKNOWN     = 0x02,
    DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_DB_25_F     = 0x03,
    DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_DB_25_M     = 0x04,
    DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_CN_36       = 0x05,
    DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_HPCN_36     = 0x06,
    DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_PROPRIETARY = 0x07,
    DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_CN_14       = 0xA0,
    DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_DB_36_F     = 0xA1,
    DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_HPCN_20     = 0xA2,
} dmi_dell_parallel_port_connector_type_t;

const char *dmi_dell_parallel_port_connector_type_name(
        dmi_dell_parallel_port_connector_type_t value);
----

== Description

The `dmi_dell_parallel_port_connector_type_t` enumeration tells the connector
of a Dell parallel port, and is the type of the `connector` field of
`dmi_dell_parallel_port_t`.

The `dmi_dell_parallel_port_connector_type_name` function returns the name of a
value, as the command line tool shows it. The name is in English, or in the
language of the locale the library is set to when it has a translation of the
name.

=== Values

`DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_UNSPEC`::
Unspecified. The firmware does not define the value 0.

`DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_OTHER`::
Other connector.

`DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_UNKNOWN`::
Unknown connector.

`DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_DB_25_F`::
DB-25 female receptacle (IEEE 1284-A).

`DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_DB_25_M`::
DB-25 male plug (IEEE 1284-A).

`DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_CN_36`::
Centronics receptacle (IEEE 1284-B).

`DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_HPCN_36`::
Mini-Centronics receptacle (IEEE 1284-C).

`DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_PROPRIETARY`::
Proprietary connector.

`DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_CN_14`::
Centronics-14.

`DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_DB_36_F`::
DB-36 female.

`DMI_DELL_PARALLEL_PORT_CONNECTOR_TYPE_HPCN_20`::
Mini-Centronics-20.

== Return value

`dmi_dell_parallel_port_connector_type_name` returns the name of the value, a
constant string which must not be modified or freed, or `nullptr` if the value
has no name, e.g. a value out of the range of the enumeration.

== Errors

None.

== See also

`dmi_dell_parallel_port`(3), `dmi_dell_parallel_port_connector_pinout`(3)

== Standards

Not part of the SMBIOS specification. Defined by Dell firmware, see the Dell
Parallel Port (Type 209) chapter of the reference manual.
