== Name

dmi_encoder_put_uuid - encode a UUID and write it at the current position.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/encoder.h>

dmi_encoder_put_uuid(encoder, value)
----

== Description

The `dmi_encoder_put_uuid` macro converts `value` from the RFC 4122
representation into SMBIOS byte order using `dmi_uuid_encode` and writes 16
bytes. The cursor is advanced.

=== Parameters

`encoder`::
Encoder to write to.

`value`::
`dmi_uuid_t` to write.

== Return value

`true` on success, `false` if the buffer cannot grow.
