== Name

dmi_hpe_reserved_memory - HP/HPE reserved memory location structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/reserved-memory.h>

typedef struct dmi_hpe_reserved_memory {
    size_t entry_count;
    dmi_hpe_reserved_memory_entry_t *entries;
} dmi_hpe_reserved_memory_t;
----

== Description

The `dmi_hpe_reserved_memory_t` structure holds the decoded HP/HPE reserved
memory location, which tells where the memory regions the firmware reserves at
boot are, e.g. the one the storage controller and iLO exchange the
temperatures of the drives in.

The structure is returned by `dmi_entity_info`(3) for the structures decoded
by `dmi_hpe_reserved_memory_spec`, of type `DMI_TYPE(hpe_reserved_memory)`,
declared in `<opendmi/module/hpe.h>`, once the HPE extension module
(`dmi_hpe_module`) is enabled, which it is for HP and HPE servers. It lives as
long as the context it has been decoded in.

Regions run to the end of the structure, which carries no number of them of
its own.

=== Fields

`entry_count`::
Number of regions.

`entries`::
Regions, see `dmi_hpe_reserved_memory_entry`(3). May be `nullptr` when
`entry_count` is 0.

== See also

`dmi_entity_info`(3),
`dmi_hpe_reserved_memory_entry`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
