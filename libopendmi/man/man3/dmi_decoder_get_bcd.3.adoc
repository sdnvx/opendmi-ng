== Name

dmi_decoder_get_bcd - read and decode a binary-coded decimal of a structure at the current position.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/decoder.h>

dmi_decoder_get_bcd(decoder, type, pvalue)
----

== Description

The `dmi_decoder_get_bcd` macro reads `sizeof(type)` bytes of the structure,
decodes the value from BCD encoding using `dmi_decode_bcd`, and stores the
result in the variable pointed to by `pvalue`. The cursor is advanced.

=== Parameters

`decoder`::
Decoder to read from.

`type`::
Wire-format type to read (e.g. `dmi_byte_t`).

`pvalue`::
Pointer to the variable that receives the decoded value.

== Return value

`true` on success, `false` if there are not enough bytes remaining.
