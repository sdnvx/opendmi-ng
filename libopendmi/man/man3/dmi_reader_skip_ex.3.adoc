== Name

dmi_reader_skip_ex - advance the reader cursor from a mark.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/reader.h>

bool dmi_reader_skip_ex(
        dmi_reader_t      *reader,
        dmi_reader_mark_t  from,
        size_t             length);
----

== Description

The `dmi_reader_skip_ex` function places the reader cursor `length` bytes past
the position of `from`, a mark taken earlier with `dmi_reader_mark`(3).

Records of a declared length are stepped over by that length rather than by the
number of bytes read from them, which is what this expresses: the beginning of
the record is marked, the fields the record is known to hold are read, and the
cursor is then placed at the next record. A record longer than the fields the
decoder knows is handled without arithmetic, and adding a field to the decoder
does not change how the next record is found.

Counting from the current position rather than from a mark is
`dmi_reader_skip`(3), and coming back to a mark without advancing is
`dmi_reader_rewind`(3).

=== Parameters

`reader`::
Reader to advance.

`from`::
Mark to count `length` from, taken from the same reader with
`dmi_reader_mark`(3).

`length`::
Number of bytes to advance by.

== Return value

Returns `true` on success, `false` if `reader` is `nullptr`, if the resulting
position is beyond the end of the entity body, or if `from` was taken from a
reader reading another entity.

== Examples

[source, c]
----
// Descriptors are two bytes long, and longer ones are allowed for future
// extensions, so the next one is found by the declared length
for (size_t i = 0; i < descriptor_count; i++) {
    dmi_reader_mark_t start = dmi_reader_mark(reader);

    bool status =
        dmi_reader_has(reader, descriptor_length) and
        dmi_reader_get(reader, dmi_byte_t, &descriptor->type) and
        dmi_reader_get(reader, dmi_byte_t, &descriptor->data_format) and
        dmi_reader_skip_ex(reader, start, descriptor_length);

    if (not status)
        return dmi_entity_incomplete(entity);
}
----
