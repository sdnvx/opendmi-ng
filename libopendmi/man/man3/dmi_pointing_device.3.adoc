== Name

dmi_pointing_device - built-in pointing device structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/pointing-device.h>

typedef struct dmi_pointing_device {
    dmi_pointing_device_type_t type;
    dmi_pointing_device_iface_t interface;
    unsigned short button_count;
} dmi_pointing_device_t;
----

== Description

The `dmi_pointing_device_t` structure holds the decoded built-in pointing
device structure (type 21) of SMBIOS: the type, interface and number of
buttons of the pointing device built into the system, such as the touch pad of
a laptop. The structure being present does not mean that the device is in use.

The structure is returned by `dmi_entity_info`(3) for the structures of type
`DMI_TYPE(pointing_device)`, and lives as long as the context it has been
decoded in.

=== Fields

`type`::
Type of the pointing device, see `dmi_pointing_device_type`(3).

`interface`::
Interface the pointing device is connected through, see
`dmi_pointing_device_iface`(3).

`button_count`::
Number of buttons of the pointing device, for example 3 for a three-button
mouse.

== Examples

[source, c]
----
dmi_registry_t        *registry = dmi_get_registry(context);
dmi_entity_t          *entity   = dmi_registry_lookup_first(registry,
                                      DMI_TYPE(pointing_device), false);
dmi_pointing_device_t *device   = dmi_entity_info(entity,
                                      DMI_TYPE(pointing_device));

if (device != nullptr)
    printf("%s (%s), %u buttons\n",
           dmi_pointing_device_type_name(device->type),
           dmi_pointing_device_iface_name(device->interface),
           device->button_count);
----
