== Name

dmi_hpe_drive_type, dmi_hpe_drive_type_name - HP/HPE drive types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/drive.h>

typedef enum dmi_hpe_drive_type {
    DMI_HPE_DRIVE_TYPE_UNDETERMINED = 0x00,
    DMI_HPE_DRIVE_TYPE_NVME_SSD     = 0x01,
    DMI_HPE_DRIVE_TYPE_SATA         = 0x02,
    DMI_HPE_DRIVE_TYPE_SAS          = 0x03,
    DMI_HPE_DRIVE_TYPE_SATA_SSD     = 0x04,
    DMI_HPE_DRIVE_TYPE_NVME_VROC    = 0x05
} dmi_hpe_drive_type_t;

const char *dmi_hpe_drive_type_name(dmi_hpe_drive_type_t value);
----

== Description

The `dmi_hpe_drive_type_t` enumeration tells the type of a drive, and is the
type of the `drive_type` field of `dmi_hpe_drive_t`.

The `dmi_hpe_drive_type_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_HPE_DRIVE_TYPE_UNDETERMINED`::
Undetermined.

`DMI_HPE_DRIVE_TYPE_NVME_SSD`::
NVMe SSD.

`DMI_HPE_DRIVE_TYPE_SATA`::
SATA.

`DMI_HPE_DRIVE_TYPE_SAS`::
SAS.

`DMI_HPE_DRIVE_TYPE_SATA_SSD`::
SATA SSD.

`DMI_HPE_DRIVE_TYPE_NVME_VROC`::
NVMe managed by VROC/VMD.

== Return value

`dmi_hpe_drive_type_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_drive`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
