== Name

dmi_memory_array_location, dmi_memory_array_location_name - memory array
locations

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/memory-array.h>

typedef enum dmi_memory_array_location {
    DMI_MEMORY_ARRAY_LOCATION_UNSPEC          = 0x00,
    DMI_MEMORY_ARRAY_LOCATION_OTHER           = 0x01,
    DMI_MEMORY_ARRAY_LOCATION_UNKNOWN         = 0x02,
    DMI_MEMORY_ARRAY_LOCATION_MOTHERBOARD     = 0x03,
    DMI_MEMORY_ARRAY_LOCATION_ISA             = 0x04,
    DMI_MEMORY_ARRAY_LOCATION_EISA            = 0x05,
    DMI_MEMORY_ARRAY_LOCATION_PCI             = 0x06,
    DMI_MEMORY_ARRAY_LOCATION_MCA             = 0x07,
    DMI_MEMORY_ARRAY_LOCATION_PCMCIA          = 0x08,
    DMI_MEMORY_ARRAY_LOCATION_PROPRIETARY     = 0x09,
    DMI_MEMORY_ARRAY_LOCATION_NUBUS           = 0x0A,
    DMI_MEMORY_ARRAY_LOCATION_PC_98_C20       = 0xA0,
    DMI_MEMORY_ARRAY_LOCATION_PC_98_C24       = 0xA1,
    DMI_MEMORY_ARRAY_LOCATION_PC_98_E         = 0xA2,
    DMI_MEMORY_ARRAY_LOCATION_PC_98_LOCAL_BUS = 0xA3,
    DMI_MEMORY_ARRAY_LOCATION_CXL             = 0xA4,
} dmi_memory_array_location_t;

const char *dmi_memory_array_location_name(dmi_memory_array_location_t value);
----

== Description

The `dmi_memory_array_location_t` enumeration tells where a physical memory
array resides, and is the type of the `location` field of `dmi_memory_array_t`.
The values from 0x0B to 0x9F are not assigned by the specification.

The `dmi_memory_array_location_name` function returns the name of a value, as
the command line tool shows it. The name is translated to the locale set with
`dmi_set_locale` if the library is built with ICU4C support and the locale has
a translation of it, and is in English otherwise.

=== Values

`DMI_MEMORY_ARRAY_LOCATION_UNSPEC`::
Unspecified. The specification defines no location of zero.

`DMI_MEMORY_ARRAY_LOCATION_OTHER`::
Other location, which none of the values below names.

`DMI_MEMORY_ARRAY_LOCATION_UNKNOWN`::
Unknown.

`DMI_MEMORY_ARRAY_LOCATION_MOTHERBOARD`::
System board or motherboard.

`DMI_MEMORY_ARRAY_LOCATION_ISA`::
ISA add-on card.

`DMI_MEMORY_ARRAY_LOCATION_EISA`::
EISA add-on card.

`DMI_MEMORY_ARRAY_LOCATION_PCI`::
PCI add-on card.

`DMI_MEMORY_ARRAY_LOCATION_MCA`::
MCA add-on card.

`DMI_MEMORY_ARRAY_LOCATION_PCMCIA`::
PCMCIA add-on card.

`DMI_MEMORY_ARRAY_LOCATION_PROPRIETARY`::
Proprietary add-on card.

`DMI_MEMORY_ARRAY_LOCATION_NUBUS`::
NuBus.

`DMI_MEMORY_ARRAY_LOCATION_PC_98_C20`::
PC-98/C20 add-on card.

`DMI_MEMORY_ARRAY_LOCATION_PC_98_C24`::
PC-98/C24 add-on card.

`DMI_MEMORY_ARRAY_LOCATION_PC_98_E`::
PC-98/E add-on card.

`DMI_MEMORY_ARRAY_LOCATION_PC_98_LOCAL_BUS`::
PC-98/Local bus add-on card.

`DMI_MEMORY_ARRAY_LOCATION_CXL`::
CXL add-on card.

== Return value

`dmi_memory_array_location_name` returns the name of the value, or `nullptr` if
the value has no name, e.g. a value the specification reserves. The string
belongs to the library and must not be modified or freed; a translated name may
become invalid once the locale is changed.

== Errors

None.

== See also

`dmi_memory_array`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.1 or newer.
