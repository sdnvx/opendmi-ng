== Name

dmi_entity_buffer - get the buffer holding the data of a structure.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/entity.h>

const dmi_buffer_t *dmi_entity_buffer(const dmi_entity_t *entity);
----

== Description

The `dmi_entity_buffer` function returns the buffer the data of the
structure is read out of.

The data read is the copy with additional information applied whenever there
is one, and the data of the structure itself otherwise, so the buffer is
paired with `dmi_entity_offset`(3) rather than taken on its own.

=== Parameters

`entity`::
Entity descriptor.

== Return value

Buffer holding the data, or `nullptr` if `entity` is `nullptr`.
