== Name

dmi_stream_rewind - reposition the stream cursor to a mark.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/stream.h>

bool dmi_stream_rewind(dmi_stream_t *stream, dmi_stream_mark_t mark);
----

== Description

The `dmi_stream_rewind` function repositions the stream cursor to a mark taken
earlier with `dmi_stream_mark`(3), so that the data between the mark and the
current position can be read again. It is how a field read as raw bytes is then
read again as the structure it holds.

Unlike `dmi_stream_seek`(3), a mark taken at the end of the entity body is
accepted, since the cursor has already been there.

Coming back to a mark and then advancing by a length is
`dmi_stream_skip_ex`(3).

=== Parameters

`stream`::
Stream to reposition.

`mark`::
Mark taken from the same stream with `dmi_stream_mark`(3).

== Return value

Returns `true` on success, `false` if `stream` is `nullptr` or if `mark` was
taken from a stream reading another entity.

== Examples

[source, c]
----
dmi_stream_mark_t start = dmi_stream_mark(stream);

// Read the interface data as a whole
if (not dmi_stream_decode_bin(stream, length, &info->data))
    return false;

// Then read the same bytes again as the structure they hold
if (info->type == DMI_MGMT_IF_TYPE_NETWORK_HOST_IF) {
    dmi_stream_rewind(stream, start);

    if (not dmi_mgmt_nhi_decode(entity, &info->nhi, length))
        return false;

    dmi_stream_skip_ex(stream, start, length);
}
----
