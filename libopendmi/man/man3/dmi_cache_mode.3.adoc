== Name

dmi_cache_mode, dmi_cache_mode_name - cache operational modes

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/cache.h>

typedef enum dmi_cache_mode {
    DMI_CACHE_MODE_WRITE_THROUGH = 0x00,
    DMI_CACHE_MODE_WRITE_BACK    = 0x01,
    DMI_CACHE_MODE_VARIABLE      = 0x02,
    DMI_CACHE_MODE_UNKNOWN       = 0x03,
} dmi_cache_mode_t;

const char *dmi_cache_mode_name(dmi_cache_mode_t value);
----

== Description

The `dmi_cache_mode_t` enumeration tells how a cache handles writes, and is
the type of the `mode` field of `dmi_cache_t`.

The `dmi_cache_mode_name` function returns the printable name of a value, as
the command line tool shows it. The name is translated to the locale set with
`dmi_set_locale`, when the library is built with ICU4C support and has a
translation of it.

=== Values

`DMI_CACHE_MODE_WRITE_THROUGH`::
Write-through: writes go to memory at once.

`DMI_CACHE_MODE_WRITE_BACK`::
Write-back: writes go to memory when the cache line is evicted.

`DMI_CACHE_MODE_VARIABLE`::
The mode varies with the memory address.

`DMI_CACHE_MODE_UNKNOWN`::
Unknown mode.

== Return value

`dmi_cache_mode_name` returns the name of the value, or `nullptr` if the value
has no name. The name is a static string, which must not be modified or freed.

== Errors

None.

== See also

`dmi_cache`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.0 or newer.
