== Name

dmi_decoder_get_uuid_at - read and decode a UUID of a structure at a given offset.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/decoder.h>

dmi_decoder_get_uuid_at(decoder, offset, pvalue)
----

== Description

The `dmi_decoder_get_uuid_at` macro reads 16 bytes at `offset` from the
beginning of the body of the structure, converts the UUID from SMBIOS byte
order into RFC 4122 representation using `dmi_uuid_decode`, and stores the
result in the variable pointed to by `pvalue`. The cursor is not moved.

=== Parameters

`decoder`::
Decoder to read from.

`offset`::
Byte offset from the beginning of the structure.

`pvalue`::
Pointer to a `dmi_uuid_t` that receives the decoded UUID.

== Return value

`true` on success, `false` if the requested range exceeds the structure
bounds.
