== Name

dmi_decoder_get_uuid - read and decode a UUID of a structure at the current position.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/decoder.h>

dmi_decoder_get_uuid(decoder, pvalue)
----

== Description

The `dmi_decoder_get_uuid` macro reads 16 bytes of the structure, converts
the UUID from SMBIOS byte order into RFC 4122 representation using
`dmi_uuid_decode`, and stores the result in the variable pointed to by
`pvalue`. The cursor is advanced.

=== Parameters

`decoder`::
Decoder to read from.

`pvalue`::
Pointer to a `dmi_uuid_t` that receives the decoded UUID.

== Return value

`true` on success, `false` if there are not enough bytes remaining.
