== Name

dmi_intel_amt - Intel Active Management Technology information structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/intel/amt.h>

typedef struct dmi_intel_amt {
    dmi_binary_t signature;
    bool is_supported;
    bool is_enabled;
    bool is_ider_enabled;
    bool is_sol_enabled;
    bool is_network_enabled;
    uint8_t extended_data;
    dmi_intel_amt_oem_caps_1_t oem_capabilities_1;
    dmi_intel_amt_terminal_t terminal;
    dmi_intel_amt_oem_caps_3_t oem_capabilities_3;
    dmi_intel_amt_oem_caps_4_t oem_capabilities_4;
    bool is_kvm_enabled;
} dmi_intel_amt_t;
----

== Description

The `dmi_intel_amt_t` structure holds the decoded Intel Active Management
Technology (AMT) information, which tells whether the platform supports AMT,
and which of its features are enabled.

The structure is returned by `dmi_entity_info`(3) for the structures decoded
by `dmi_intel_amt_spec`, of type `DMI_TYPE(intel_amt)`, declared in
`<opendmi/module/intel.h>`, once the Intel extension module
(`dmi_intel_module`) is enabled, which is done for any platform with Intel
processors when the context has `DMI_CONTEXT_FLAG_AUTO_MODULES`. It lives as
long as the context it has been decoded in. The structures are told by the
`$AMT` signature at offset 0x04.

The fields are the ones of the AMT information table of the Intel AMT
implementation and reference guide. The data of the corpus agrees with them,
e.g. the features are enabled on the platforms whose Management Engine
firmware is of the corporate SKU, see `dmi_intel_me_sku`(3), while the flags
are not consistent with each other on every platform: some give the network
as enabled while AMT is not supported. The guide gives the values from 2 on
as not applicable, which are taken as set.

=== Fields

`signature`::
Signature of the structure, `$AMT`.

`is_supported`::
Whether the platform supports AMT.

`is_enabled`::
Whether AMT is enabled.

`is_ider_enabled`::
Whether storage redirection is enabled: IDE redirection (IDE-R), or USB
redirection (USB-R) from AMT 11.0 onwards.

`is_sol_enabled`::
Whether Serial over LAN (SOL) is enabled.

`is_network_enabled`::
Whether the network interface of AMT is enabled.

`extended_data`::
Extended data, which Intel leaves to the platform vendor, `0xA5` in all known
data.

`oem_capabilities_1`::
Features of AMT the platform supports, see `dmi_intel_amt_oem_caps_1`(3).

`terminal`::
Terminal emulation of Serial over LAN, from the low nibble of the second byte
of the OEM capabilities, see `dmi_intel_amt_terminal`(3).

`oem_capabilities_3`::
Security capabilities of the platform, see `dmi_intel_amt_oem_caps_3`(3).

`oem_capabilities_4`::
Targets of the remote boot the platform supports, see
`dmi_intel_amt_oem_caps_4`(3).

`is_kvm_enabled`::
Whether keyboard, video and mouse (KVM) redirection is enabled.

information table of the Intel AMT implementation and reference guide.
