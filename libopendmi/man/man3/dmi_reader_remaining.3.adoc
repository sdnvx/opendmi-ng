== Name

dmi_reader_remaining - return the number of unread bytes in a reader.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/reader.h>

size_t dmi_reader_remaining(const dmi_reader_t *reader);
----

== Description

The `dmi_reader_remaining` function returns the number of bytes from the
current cursor position to the end of the range.

=== Parameters

`reader`::
Reader to query.

== Return value

Number of bytes left to read, or zero if `reader` is `nullptr`.
