== Name

dmi_reader_initialize - initialize a reader for reading an entity's body data.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/reader.h>

bool dmi_reader_initialize(dmi_reader_t *reader, const dmi_entity_t *entity);
----

== Description

The `dmi_reader_initialize` function sets up the reader to read the body of
`entity`, positioning the cursor at the beginning of the body (past the SMBIOS
structure header).

=== Parameters

`reader`::
Reader to initialize.

`entity`::
Entity whose body data will be read.

== Return value

Returns `true` on success, `false` if `reader` or `entity` is `nullptr`.
