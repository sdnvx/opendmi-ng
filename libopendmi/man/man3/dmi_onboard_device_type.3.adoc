== Name

dmi_onboard_device_type, dmi_onboard_device_type_name - onboard device types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/onboard-device.h>

typedef enum dmi_onboard_device_type {
    DMI_ONBOARD_DEVICE_TYPE_UNSPEC          = 0x00,
    DMI_ONBOARD_DEVICE_TYPE_OTHER           = 0x01,
    DMI_ONBOARD_DEVICE_TYPE_UNKNOWN         = 0x02,
    DMI_ONBOARD_DEVICE_TYPE_VIDEO           = 0x03,
    DMI_ONBOARD_DEVICE_TYPE_SCSI_CONTROLLER = 0x04,
    DMI_ONBOARD_DEVICE_TYPE_ETHERNET        = 0x05,
    DMI_ONBOARD_DEVICE_TYPE_TOKEN_RING      = 0x06,
    DMI_ONBOARD_DEVICE_TYPE_SOUND           = 0x07,
    DMI_ONBOARD_DEVICE_TYPE_PATA_CONTROLLER = 0x08,
    DMI_ONBOARD_DEVICE_TYPE_SATA_CONTROLLER = 0x09,
    DMI_ONBOARD_DEVICE_TYPE_SAS_CONTROLLER  = 0x0A,
    DMI_ONBOARD_DEVICE_TYPE_WIRELESS_LAN    = 0x0B,
    DMI_ONBOARD_DEVICE_TYPE_BLUETOOTH       = 0x0C,
    DMI_ONBOARD_DEVICE_TYPE_WIRELESS_WAN    = 0x0D,
    DMI_ONBOARD_DEVICE_TYPE_EMM_CONTROLLER  = 0x0E,
    DMI_ONBOARD_DEVICE_TYPE_NVME_CONTROLLER = 0x0F,
    DMI_ONBOARD_DEVICE_TYPE_UFS_CONTROLLER  = 0x10
} dmi_onboard_device_type_t;

const char *dmi_onboard_device_type_name(dmi_onboard_device_type_t value);
----

== Description

The `dmi_onboard_device_type_t` enumeration tells the kind of a device
soldered onto a board of the system. It is the type of the `type` field of
`dmi_onboard_device_instance_t`, and of the one of `dmi_onboard_device_ex_t`.
The values above 0x0A were added for the onboard devices extended information
structure (type 41), and do not fit the obsolete onboard devices information
structure (type 10), which has no newer versions.

The `dmi_onboard_device_type_name` function returns the name of a value, as
the command line tool shows it.

=== Values

`DMI_ONBOARD_DEVICE_TYPE_UNSPEC`::
Unspecified.

`DMI_ONBOARD_DEVICE_TYPE_OTHER`::
Other.

`DMI_ONBOARD_DEVICE_TYPE_UNKNOWN`::
Unknown.

`DMI_ONBOARD_DEVICE_TYPE_VIDEO`::
Video.

`DMI_ONBOARD_DEVICE_TYPE_SCSI_CONTROLLER`::
SCSI Controller.

`DMI_ONBOARD_DEVICE_TYPE_ETHERNET`::
Ethernet.

`DMI_ONBOARD_DEVICE_TYPE_TOKEN_RING`::
Token Ring.

`DMI_ONBOARD_DEVICE_TYPE_SOUND`::
Sound.

`DMI_ONBOARD_DEVICE_TYPE_PATA_CONTROLLER`::
PATA Controller.

`DMI_ONBOARD_DEVICE_TYPE_SATA_CONTROLLER`::
SATA Controller.

`DMI_ONBOARD_DEVICE_TYPE_SAS_CONTROLLER`::
SAS Controller.

`DMI_ONBOARD_DEVICE_TYPE_WIRELESS_LAN`::
Wireless LAN.

`DMI_ONBOARD_DEVICE_TYPE_BLUETOOTH`::
Bluetooth.

`DMI_ONBOARD_DEVICE_TYPE_WIRELESS_WAN`::
Wireless WAN.

`DMI_ONBOARD_DEVICE_TYPE_EMM_CONTROLLER`::
eMMC (embedded multimedia card) controller.

`DMI_ONBOARD_DEVICE_TYPE_NVME_CONTROLLER`::
NVMe controller.

`DMI_ONBOARD_DEVICE_TYPE_UFS_CONTROLLER`::
UFS controller.

== Return value

`dmi_onboard_device_type_name` returns the name of the value, or `nullptr` if
the value has no name. The name is translated to the current locale when the
library is built with localization support and has a translation for it, and
is in English otherwise. The string is owned by the library and must not be
modified or freed.

== Errors

None.
