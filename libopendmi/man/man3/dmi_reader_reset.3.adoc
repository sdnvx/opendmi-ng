== Name

dmi_reader_reset - reset the reader cursor to the beginning.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/reader.h>

void dmi_reader_reset(dmi_reader_t *reader);
----

== Description

The `dmi_reader_reset` function repositions the reader cursor back to the
start of the entity body so that it can be read again from the beginning.

=== Parameters

`reader`::
Reader to reset.
