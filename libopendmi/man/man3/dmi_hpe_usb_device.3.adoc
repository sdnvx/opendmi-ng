== Name

dmi_hpe_usb_device - HP/HPE USB device correlation record structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/usb-device.h>

typedef struct dmi_hpe_usb_device {
    dmi_handle_t port_handle;
    uint16_t vendor_id;
    bool is_sd_card_present;
    uint8_t usb_class;
    uint8_t usb_subclass;
    uint8_t usb_protocol;
    uint16_t product_id;
    uint32_t raw_capacity;
    uint64_t capacity;
    const char *uefi_device_path;
    const char *uefi_device_name;
    const char *device_name;
    const char *location;
} dmi_hpe_usb_device_t;
----

== Description

The `dmi_hpe_usb_device_t` structure holds the decoded HP/HPE USB device
correlation record, which describes a USB device the firmware has found at
boot on a USB port, and the UEFI boot entries naming it. Devices plugged in
later are not described.

The structure is returned by `dmi_entity_info`(3) for the structures decoded
by `dmi_hpe_usb_device_spec`, of type `DMI_TYPE(hpe_usb_device)`, declared in
`<opendmi/module/hpe.h>`, once the HPE extension module (`dmi_hpe_module`) is
enabled, which it is for HP and HPE servers with UEFI firmware from Gen9
onwards. It lives as long as the context it has been decoded in.

=== Fields

`port_handle`::
Handle of the USB port connector correlation record (type 238).

`vendor_id`::
USB vendor ID of the device.

`is_sd_card_present`::
Whether an embedded SD card is present.

`usb_class`::
USB class code of the device.

`usb_subclass`::
USB subclass code of the device, named by `dmi_hpe_usb_storage_subclass`(3)
for the devices of the mass storage class (0x08).

`usb_protocol`::
USB protocol code of the device, named by `dmi_hpe_usb_storage_proto`(3) for
the devices of the mass storage class (0x08), and by `dmi_hpe_usb_hub_proto`(3)
for the hubs (class 0x09).

`product_id`::
USB product ID of the device.

`raw_capacity`::
Capacity of the device in megabytes, zero if not applicable.

`capacity`::
Capacity of the device in bytes, zero if not applicable.

`uefi_device_path`::
UEFI device path.

`uefi_device_name`::
UEFI device structured name.

`device_name`::
Device name.

`location`::
Location of the device.

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
