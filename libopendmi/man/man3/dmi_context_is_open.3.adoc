== Name

dmi_context_is_open - check whether a context is open.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/context.h>

bool dmi_context_is_open(const dmi_context_t *context);
----

== Description

The `dmi_context_is_open` function tells whether a context holds SMBIOS
data: a structure table and the registry of its structures, which
`dmi_open`(3) and `dmi_load`(3) fill the context with, and `dmi_close`(3)
frees.

The function is defined inline in the header, and reads the state of the
context only.

=== Parameters

`context`::
Context in question, which must not be `nullptr`.

== Return value

Returns `true` if the context is open, and `false` otherwise.

== Errors

None.

== See also

`dmi_open`(3),
`dmi_load`(3),
`dmi_close`(3)
