== Name

dmi_hpe_tcontrol - HP/HPE processor TControl information structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/tcontrol.h>

typedef struct dmi_hpe_tcontrol {
    dmi_handle_t processor_handle;
    uint8_t tcontrol;
} dmi_hpe_tcontrol_t;
----

== Description

The `dmi_hpe_tcontrol_t` structure holds the decoded HP/HPE processor TControl
information, which gives the Tcontrol value of a processor: the temperature
the fans begin to spin up at, which Intel programs into each processor.

The structure is returned by `dmi_entity_info`(3) for the structures decoded
by `dmi_hpe_tcontrol_spec`, of type `DMI_TYPE(hpe_tcontrol)`, declared in
`<opendmi/module/hpe.h>`, once the HPE extension module (`dmi_hpe_module`) is
enabled, which it is for HP and HPE servers. It lives as long as the context
it has been decoded in.

=== Fields

`processor_handle`::
Handle of the processor information structure (type 4).

`tcontrol`::
Tcontrol value. Set to zero when not available.

== See also

`dmi_entity_info`(3),
`dmi_processor`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
