== Name

dmi_buffer_is_empty - check whether a buffer holds no data.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/buffer.h>

bool dmi_buffer_is_empty(const dmi_buffer_t *buffer);
----

== Description

The `dmi_buffer_is_empty` function checks whether the buffer holds any data.
A buffer holds no data before anything has been put into it, and after it
has been cleared, whether it keeps the memory it has had or not.

=== Parameters

`buffer`::
Buffer to check.

== Return value

`true` if the buffer holds no data, `false` otherwise.
