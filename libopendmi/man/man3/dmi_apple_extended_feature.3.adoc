== Name

dmi_apple_extended_feature, dmi_apple_extended_feature_name - Apple extended firmware features

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/apple/firmware-volume.h>

typedef enum dmi_apple_extended_feature {
    DMI_APPLE_EXTENDED_FEATURE_LARGE_BASESYSTEM = 3
} dmi_apple_extended_feature_t;

const char *dmi_apple_extended_feature_name(dmi_apple_extended_feature_t value);
----

== Description

The `dmi_apple_extended_feature_t` enumeration names the bits of the
`extended_features` field of `dmi_apple_firmware_volume_t`, which are the
bits 32 to 63 of the features, by their numbers within the field. The bits of
no known meaning are named after the numbers of the features, e.g. `Unknown
bit 32`.

The `dmi_apple_extended_feature_name` function returns the name of a value, as the command line
tool shows it.

=== Values

`DMI_APPLE_EXTENDED_FEATURE_LARGE_BASESYSTEM`::
Supports the large BaseSystem, which macOS 12 requires, bit 35 of the
features.

== Return value

`dmi_apple_extended_feature_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_apple_firmware_volume`(3)

== Standards

Not part of the SMBIOS specification. Defined by the firmware of Macs, and
laid out as the `AppleSmBios.h` header of OpenCore describes it.
