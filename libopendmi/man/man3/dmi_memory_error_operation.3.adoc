== Name

dmi_memory_error_operation, dmi_memory_error_operation_name - memory error
operations

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/memory-error.h>

typedef enum dmi_memory_error_operation {
    DMI_MEMORY_ERROR_OPERATION_UNSPEC        = 0x00,
    DMI_MEMORY_ERROR_OPERATION_OTHER         = 0x01,
    DMI_MEMORY_ERROR_OPERATION_UNKNOWN       = 0x02,
    DMI_MEMORY_ERROR_OPERATION_READ          = 0x03,
    DMI_MEMORY_ERROR_OPERATION_WRITE         = 0x04,
    DMI_MEMORY_ERROR_OPERATION_PARTIAL_WRITE = 0x05,
} dmi_memory_error_operation_t;

const char *dmi_memory_error_operation_name(
        dmi_memory_error_operation_t value);
----

== Description

The `dmi_memory_error_operation_t` enumeration tells the memory access
operation which caused a memory error, and is the type of the `operation` field
of `dmi_memory_error_32_t` and `dmi_memory_error_64_t`.

The `dmi_memory_error_operation_name` function returns the name of a value, as
the command line tool shows it. The name is in English, or in the language of
the locale the library is set to when it has a translation of the name.

=== Values

`DMI_MEMORY_ERROR_OPERATION_UNSPEC`::
Unspecified. The specification does not define the value 0.

`DMI_MEMORY_ERROR_OPERATION_OTHER`::
Other operation.

`DMI_MEMORY_ERROR_OPERATION_UNKNOWN`::
Unknown operation.

`DMI_MEMORY_ERROR_OPERATION_READ`::
Read.

`DMI_MEMORY_ERROR_OPERATION_WRITE`::
Write.

`DMI_MEMORY_ERROR_OPERATION_PARTIAL_WRITE`::
Partial write.

== Return value

`dmi_memory_error_operation_name` returns the name of the value, a constant
string which must not be modified or freed, or `nullptr` if the value has no
name, e.g. a value out of the range of the enumeration.

== Errors

None.

== See also

`dmi_memory_error_32`(3), `dmi_memory_error_64`(3), `dmi_memory_error_type`(3),
`dmi_memory_error_granularity`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.1 or newer.
