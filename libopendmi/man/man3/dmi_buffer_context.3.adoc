== Name

dmi_buffer_context - get the context a buffer belongs to.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/buffer.h>

dmi_context_t *dmi_buffer_context(const dmi_buffer_t *buffer);
----

== Description

The `dmi_buffer_context` function returns the context the buffer belongs to,
so that everything holding a buffer can reach the context without being
handed it separately.

=== Parameters

`buffer`::
Buffer to query.

== Return value

Context of the buffer, or `nullptr` if `buffer` is `nullptr` or belongs to
none.
