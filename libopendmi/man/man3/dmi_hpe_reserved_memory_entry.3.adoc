== Name

dmi_hpe_reserved_memory_entry - HP/HPE reserved memory region structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/reserved-memory.h>

typedef struct dmi_hpe_reserved_memory_entry {
    dmi_binary_t signature_raw;
    char *signature;
    uint64_t address;
    uint32_t raw_size;
    bool is_kilobytes;
    uint64_t size;
} dmi_hpe_reserved_memory_entry_t;
----

== Description

The `dmi_hpe_reserved_memory_entry_t` structure describes a memory region the
firmware reserves, as an element of the `entries` field of
`dmi_hpe_reserved_memory_t`.

=== Fields

`signature_raw`::
Signature, as the structure holds it.

`signature`::
Signature, which tells what the region is for, e.g. `$HDD`, or `nullptr` if it
is not printable. The string belongs to the structure, and is freed along
with it.

`address`::
Physical address.

`raw_size`::
Size in the units `is_kilobytes` tells.

`is_kilobytes`::
Whether the size is in kilobytes rather than in bytes.

`size`::
Size in bytes.

== See also

`dmi_hpe_reserved_memory`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
