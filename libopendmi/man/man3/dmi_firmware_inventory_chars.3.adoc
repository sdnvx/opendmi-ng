== Name

dmi_firmware_inventory_chars - firmware characteristics

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/firmware-inventory.h>

typedef union dmi_firmware_inventory_chars {
    dmi_word_t __value;

    struct {
        dmi_word_t is_updatable       : 1;
        dmi_word_t is_write_protected : 1;
        dmi_word_t __reserved         : 14;
    };
} dmi_firmware_inventory_chars_t;
----

== Description

The `dmi_firmware_inventory_chars_t` union holds the characteristics of a
firmware component, one bit per characteristic, and is the type of the
`characteristics` field of `dmi_firmware_inventory_t`. A bit is 1 if the firmware has
the characteristic. The union gives access to the whole word as well as to the
single bits.

=== Fields

`__value`::
Whole 16-bit word, as the data carries it.

`is_updatable`::
Software can update the firmware.

`is_write_protected`::
The firmware is write-protected.

`__reserved`::
Bits 2 to 15, reserved by the specification.

== See also

`dmi_firmware_inventory`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 3.5 or newer.
