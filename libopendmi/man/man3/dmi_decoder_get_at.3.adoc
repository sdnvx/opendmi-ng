== Name

dmi_decoder_get_at - read and decode a value of a structure at a given offset.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/decoder.h>

dmi_decoder_get_at(decoder, offset, type, pvalue)
----

== Description

The `dmi_decoder_get_at` macro reads `sizeof(type)` bytes at `offset` from
the beginning of the body of the structure, converts the value from SMBIOS
wire format (little-endian) into host byte order using `dmi_decode`, and
stores the result in the variable pointed to by `pvalue`. The cursor is not
moved.

=== Parameters

`decoder`::
Decoder to read from.

`offset`::
Byte offset from the beginning of the structure.

`type`::
Wire-format type to read (e.g. `dmi_word_t`, `dmi_dword_t`).

`pvalue`::
Pointer to the variable that receives the decoded value.

== Return value

`true` on success, `false` if the requested range exceeds the structure
bounds.
