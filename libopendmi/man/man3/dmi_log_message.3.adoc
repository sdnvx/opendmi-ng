== Name

dmi_log_message - write a message to a logging handler.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/log.h>

bool dmi_log_message(
        dmi_log_t       *target,
        dmi_log_level_t  level,
        const char      *format,
        ...);
----

== Description

The `dmi_log_message` function writes a message, formatted the way
`printf`(3) formats its arguments, to the given handler.

Unlike `dmi_log`(3), which writes to the handler of a context, it takes the
handler itself, and checks no logging level: every message is given to the
handler, which drops the ones it has no use for.

=== Parameters

`target`::
Logging handler to write the message to.

`level`::
Level of the message.

`format`::
Format of the message, followed by the values it refers to.

== Return value

Returns `true` if the message has been given to the handler, and `false` if
`target` or its handler function is `nullptr`.

== Errors

None.

== See also

`dmi_log_message_va`(3),
`dmi_log`(3),
