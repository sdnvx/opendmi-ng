== Name

dmi_writer_rewind - reposition a writer cursor to a mark taken earlier.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/writer.h>

bool dmi_writer_rewind(dmi_writer_t *writer, dmi_writer_mark_t mark);
----

== Description

The `dmi_writer_rewind` function repositions the writer cursor to a mark
taken with `dmi_writer_mark`(3), so that the bytes written from there on are
written again.

=== Parameters

`writer`::
Writer to reposition.

`mark`::
Mark taken from the same writer with `dmi_writer_mark`(3).

== Return value

`true` on success, `false` if the mark was taken of another writer, or over
data which has been discarded since.

== Errors

None.

== See also

`dmi_writer_mark`(3),
`dmi_writer_seek`(3),
`dmi_writer_skip_ex`(3)
