== Name

dmi_hpe_proliant_info - HP/HPE ProLiant information structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/proliant-info.h>

typedef struct dmi_hpe_proliant_info {
    uint32_t power_features;
    uint32_t omega_features;
    uint32_t misc_features;
    bool is_icru;
    bool is_uefi;
    bool has_omega_features;
    bool has_misc_features;
} dmi_hpe_proliant_info_t;
----

== Description

The `dmi_hpe_proliant_info_t` structure holds the decoded HP/HPE ProLiant
information, which gives the feature flags of the server the watchdog timer
driver reads.

The structure is returned by `dmi_entity_info`(3) for the structures decoded
by `dmi_hpe_proliant_info_spec`, of type `DMI_TYPE(hpe_proliant_info)`,
declared in `<opendmi/module/hpe.h>`, once the HPE extension module
(`dmi_hpe_module`) is enabled, which it is for HP and HPE servers. It lives as
long as the context it has been decoded in.

HP and HPE servers give type 219 to this structure, and the Intel Management
Engine interface information is not decoded on them, see `dmi_intel_mei`(3).
Features the data ends before are zero.

=== Fields

`power_features`::
Power features, whose meaning is not documented.

`omega_features`::
Omega features, whose meaning is not documented.

`misc_features`::
Miscellaneous features.

`is_icru`::
Whether the integrated CRU (iCRU) is supported, as bit 0 of the miscellaneous
features tells.

`is_uefi`::
Whether the firmware is UEFI one, as bits 10 and 12 of the miscellaneous
features tell, the way dmidecode reads them. The `hpwdt` driver of Linux
reads bits 3 and 10 instead; the meaning of bits 3 and 12 is not
established.

`has_omega_features`::
Whether the structure holds the omega features, which the structures of 8
bytes leave out. The field is not shown then.

`has_misc_features`::
Whether the structure holds the miscellaneous features, which the structures
shorter than 20 bytes leave out. The field, `is_icru` and `is_uefi` are not
shown then.

== See also

`dmi_entity_info`(3),
`dmi_intel_mei`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
