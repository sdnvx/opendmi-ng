== Name

dmi_reader_seek - seek to a byte position within the reader.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/reader.h>

bool dmi_reader_seek(dmi_reader_t *reader, size_t position);
----

== Description

The `dmi_reader_seek` function repositions the reader cursor to `position`
bytes from the beginning of the entity body.

=== Parameters

`reader`::
Reader to reposition.

`position`::
Byte offset from the beginning of the entity body.

== Return value

Returns `true` on success, `false` if `position` is beyond the end of the
reader.
