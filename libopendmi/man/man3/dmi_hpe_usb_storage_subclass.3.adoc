== Name

dmi_hpe_usb_storage_subclass, dmi_hpe_usb_storage_subclass_name - USB mass
storage subclasses

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/usb-device.h>

typedef enum dmi_hpe_usb_storage_subclass {
    DMI_HPE_USB_STORAGE_SUBCLASS_UNREPORTED = 0x00,
    DMI_HPE_USB_STORAGE_SUBCLASS_RBC        = 0x01,
    DMI_HPE_USB_STORAGE_SUBCLASS_ATAPI      = 0x02,
    DMI_HPE_USB_STORAGE_SUBCLASS_QIC_157    = 0x03,
    DMI_HPE_USB_STORAGE_SUBCLASS_UFI        = 0x04,
    DMI_HPE_USB_STORAGE_SUBCLASS_SFF_8070I  = 0x05,
    DMI_HPE_USB_STORAGE_SUBCLASS_SCSI       = 0x06,
    DMI_HPE_USB_STORAGE_SUBCLASS_LSD_FS     = 0x07,
    DMI_HPE_USB_STORAGE_SUBCLASS_IEEE_1667  = 0x08,
    DMI_HPE_USB_STORAGE_SUBCLASS_VENDOR     = 0xFF
} dmi_hpe_usb_storage_subclass_t;

const char *dmi_hpe_usb_storage_subclass_name(
        dmi_hpe_usb_storage_subclass_t value);
----

== Description

The `dmi_hpe_usb_storage_subclass_t` enumeration tells the command set a USB
mass storage device uses, and names the `usb_subclass` field of
`dmi_hpe_usb_device_t` for the devices of the mass storage class (0x08). Values
0x09 to 0xFE are reserved.

The `dmi_hpe_usb_storage_subclass_name` function returns the name of a value, as
the command line tool shows it.

=== Values

`DMI_HPE_USB_STORAGE_SUBCLASS_UNREPORTED`::
SCSI command set not reported.

`DMI_HPE_USB_STORAGE_SUBCLASS_RBC`::
Reduced block commands (RBC).

`DMI_HPE_USB_STORAGE_SUBCLASS_ATAPI`::
ATAPI, as used by MMC-5.

`DMI_HPE_USB_STORAGE_SUBCLASS_QIC_157`::
QIC-157, obsolete.

`DMI_HPE_USB_STORAGE_SUBCLASS_UFI`::
USB floppy interface (UFI).

`DMI_HPE_USB_STORAGE_SUBCLASS_SFF_8070I`::
SFF-8070i, obsolete.

`DMI_HPE_USB_STORAGE_SUBCLASS_SCSI`::
SCSI transparent command set.

`DMI_HPE_USB_STORAGE_SUBCLASS_LSD_FS`::
LSD FS, the lockable storage devices feature specification.

`DMI_HPE_USB_STORAGE_SUBCLASS_IEEE_1667`::
IEEE 1667.

`DMI_HPE_USB_STORAGE_SUBCLASS_VENDOR`::
Vendor-specific.

== Return value

`dmi_hpe_usb_storage_subclass_name` returns the name of the value, translated to
the language of the current locale when a translation is available, or `nullptr`
if the value has no name. Values 0x09 to 0xFE are named "Reserved". The returned
string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_usb_device`(3), `dmi_hpe_usb_storage_proto`(3)

== Standards

The codes are the ones the USB Implementers Forum defines for the class, as
dmidecode names them. The structure is not part of the SMBIOS specification: it
is defined by HP and HPE for their servers, and its layout is the one dmidecode
documents.
