== Name

dmi_hpe_drive_form_factor, dmi_hpe_drive_form_factor_name - HP/HPE drive form factors

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/drive.h>

typedef enum dmi_hpe_drive_form_factor {
    DMI_HPE_DRIVE_FORM_FACTOR_3_5        = 0x02,
    DMI_HPE_DRIVE_FORM_FACTOR_2_5        = 0x03,
    DMI_HPE_DRIVE_FORM_FACTOR_1_8        = 0x04,
    DMI_HPE_DRIVE_FORM_FACTOR_SMALLER    = 0x05,
    DMI_HPE_DRIVE_FORM_FACTOR_MSATA      = 0x06,
    DMI_HPE_DRIVE_FORM_FACTOR_M2         = 0x07,
    DMI_HPE_DRIVE_FORM_FACTOR_MICRO_SSD  = 0x08,
    DMI_HPE_DRIVE_FORM_FACTOR_CFAST      = 0x09,
    DMI_HPE_DRIVE_FORM_FACTOR_EDSFF      = 0x20,
    DMI_HPE_DRIVE_FORM_FACTOR_EDSFF_1U_S = 0x21,
    DMI_HPE_DRIVE_FORM_FACTOR_EDSFF_1U_L = 0x22,
    DMI_HPE_DRIVE_FORM_FACTOR_EDSFF_E3_S = 0x23,
    DMI_HPE_DRIVE_FORM_FACTOR_EDSFF_E3_L = 0x24
} dmi_hpe_drive_form_factor_t;

const char *dmi_hpe_drive_form_factor_name(dmi_hpe_drive_form_factor_t value);
----

== Description

The `dmi_hpe_drive_form_factor_t` enumeration tells the form factor of a drive, and
is the type of the `form_factor` field of `dmi_hpe_drive_t`.

The `dmi_hpe_drive_form_factor_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_HPE_DRIVE_FORM_FACTOR_3_5`::
3.5-inch form factor.

`DMI_HPE_DRIVE_FORM_FACTOR_2_5`::
2.5-inch form factor.

`DMI_HPE_DRIVE_FORM_FACTOR_1_8`::
1.8-inch form factor.

`DMI_HPE_DRIVE_FORM_FACTOR_SMALLER`::
Smaller than 1.8-inch form factor.

`DMI_HPE_DRIVE_FORM_FACTOR_MSATA`::
mSATA.

`DMI_HPE_DRIVE_FORM_FACTOR_M2`::
M.2.

`DMI_HPE_DRIVE_FORM_FACTOR_MICRO_SSD`::
MicroSSD.

`DMI_HPE_DRIVE_FORM_FACTOR_CFAST`::
CFast.

`DMI_HPE_DRIVE_FORM_FACTOR_EDSFF`::
EDSFF of unknown form factor.

`DMI_HPE_DRIVE_FORM_FACTOR_EDSFF_1U_S`::
EDSFF 1U short.

`DMI_HPE_DRIVE_FORM_FACTOR_EDSFF_1U_L`::
EDSFF 1U long.

`DMI_HPE_DRIVE_FORM_FACTOR_EDSFF_E3_S`::
EDSFF E3 short.

`DMI_HPE_DRIVE_FORM_FACTOR_EDSFF_E3_L`::
EDSFF E3 long.

== Return value

`dmi_hpe_drive_form_factor_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_drive`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
