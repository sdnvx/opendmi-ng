== Name

dmi_decoder_entity - get the structure being decoded.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/decoder.h>

dmi_entity_t *dmi_decoder_entity(const dmi_decoder_t *decoder);
----

== Description

The `dmi_decoder_entity` function returns the structure the decoder is
reading, so that a decoding handler reaches it without being handed it
separately.

=== Parameters

`decoder`::
Decoder to query.

== Return value

Structure being decoded, or `nullptr` if `decoder` is `nullptr`.
