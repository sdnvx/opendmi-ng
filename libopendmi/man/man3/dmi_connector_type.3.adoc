== Description

The `dmi_connector_type_t` enumeration tells the physical type of a port
connector, and is the type of the `internal_connector` and `external_connector`
fields of `dmi_port_connector_t`. The specification assigns no values from
`0x24` to `0x9F` and from `0xA5` to `0xFE`.

The `dmi_connector_type_name` function returns the name of a value, as the
command line tool shows it.

== Return value

`dmi_connector_type_name` returns the name of the value, or `nullptr` if the
value has no name. The name is in English, or translated to the locale set with
`dmi_set_locale` when the library is built with localization support and has a
translation of it. The string must not be modified or freed; a translated one
stays valid until the locale is changed.

== Errors

None.
