== Name

dmi_platform_destroy - destroy a platform descriptor.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/platform.h>

void dmi_platform_destroy(dmi_platform_t *platform);
----

== Description

The `dmi_platform_destroy` function destroys a platform along with the
product name and the family code it holds. It does nothing if `platform` is
`nullptr`.

The platform of a context, returned by `dmi_get_platform`(3), belongs to the
context, and is not destroyed by the caller.

=== Parameters

`platform`::
Platform to destroy, or `nullptr`.

== Return value

None.

== Errors

None.

== See also

`dmi_platform_create`(3),
`dmi_platform_clone`(3)
