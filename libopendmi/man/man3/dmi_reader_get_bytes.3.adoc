== Name

dmi_reader_get_bytes - read data from the reader at the current position.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/reader.h>

bool dmi_reader_get_bytes(dmi_reader_t *reader, void *ptr, size_t length);
----

== Description

The `dmi_reader_get_bytes` function copies `length` bytes from the reader into
the buffer pointed to by `ptr` and advances the reader cursor. No byte-order
conversion is performed.

=== Parameters

`reader`::
Reader to read from.

`ptr`::
Buffer that receives the data; must be at least `length` bytes.

`length`::
Number of bytes to read.

== Return value

Returns `true` on success, `false` if there are fewer than `length` bytes
remaining in the reader.
