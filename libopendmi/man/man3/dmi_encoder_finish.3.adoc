== Name

dmi_encoder_finish - complete the formatted area of a structure.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/encoder.h>

bool dmi_encoder_finish(dmi_encoder_t *encoder);
----

== Description

The `dmi_encoder_finish` function completes the formatted area by filling in
the length of the header, which is known once every field has been written.

=== Parameters

`encoder`::
Encoder to complete.

== Return value

`true` on success, `false` otherwise.

== Errors

`DMI_ERROR_INVALID_ARGUMENT`::
Formatted area is longer than a byte can count.
