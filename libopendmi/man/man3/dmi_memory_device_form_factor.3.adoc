== Name

dmi_memory_device_form_factor, dmi_memory_device_form_factor_name - memory device form factors

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/memory-device.h>

typedef enum dmi_memory_device_form_factor {
    DMI_MEMORY_DEVICE_FORM_FACTOR_UNSPEC   = 0x00,
    DMI_MEMORY_DEVICE_FORM_FACTOR_OTHER    = 0x01,
    DMI_MEMORY_DEVICE_FORM_FACTOR_UNKNOWN  = 0x02,
    DMI_MEMORY_DEVICE_FORM_FACTOR_SIMM     = 0x03,
    DMI_MEMORY_DEVICE_FORM_FACTOR_SIP      = 0x04,
    DMI_MEMORY_DEVICE_FORM_FACTOR_CHIP     = 0x05,
    DMI_MEMORY_DEVICE_FORM_FACTOR_DIP      = 0x06,
    DMI_MEMORY_DEVICE_FORM_FACTOR_ZIP      = 0x07,
    DMI_MEMORY_DEVICE_FORM_FACTOR_CARD     = 0x08,
    DMI_MEMORY_DEVICE_FORM_FACTOR_DIMM     = 0x09,
    DMI_MEMORY_DEVICE_FORM_FACTOR_TSOP     = 0x0A,
    DMI_MEMORY_DEVICE_FORM_FACTOR_CHIP_ROW = 0x0B,
    DMI_MEMORY_DEVICE_FORM_FACTOR_RIMM     = 0x0C,
    DMI_MEMORY_DEVICE_FORM_FACTOR_SODIMM   = 0x0D,
    DMI_MEMORY_DEVICE_FORM_FACTOR_SRIMM    = 0x0E,
    DMI_MEMORY_DEVICE_FORM_FACTOR_FBDIMM   = 0x0F,
    DMI_MEMORY_DEVICE_FORM_FACTOR_DIE      = 0x10,
    DMI_MEMORY_DEVICE_FORM_FACTOR_CAMM     = 0x11,
    DMI_MEMORY_DEVICE_FORM_FACTOR_CUDIMM   = 0x12,
    DMI_MEMORY_DEVICE_FORM_FACTOR_CSODIMM  = 0x13
} dmi_memory_device_form_factor_t;

const char *dmi_memory_device_form_factor_name(
        dmi_memory_device_form_factor_t value);
----

== Description

The `dmi_memory_device_form_factor_t` enumeration tells the physical form of a
memory device, and is the type of the `form_factor` field of
`dmi_memory_device_t`.

The `dmi_memory_device_form_factor_name` function returns the name of a value,
as the command line tool shows it.

=== Values

`DMI_MEMORY_DEVICE_FORM_FACTOR_UNSPEC`::
Unspecified.

`DMI_MEMORY_DEVICE_FORM_FACTOR_OTHER`::
Other.

`DMI_MEMORY_DEVICE_FORM_FACTOR_UNKNOWN`::
Unknown.

`DMI_MEMORY_DEVICE_FORM_FACTOR_SIMM`::
SIMM.

`DMI_MEMORY_DEVICE_FORM_FACTOR_SIP`::
SIP.

`DMI_MEMORY_DEVICE_FORM_FACTOR_CHIP`::
Chip.

`DMI_MEMORY_DEVICE_FORM_FACTOR_DIP`::
DIP.

`DMI_MEMORY_DEVICE_FORM_FACTOR_ZIP`::
ZIP.

`DMI_MEMORY_DEVICE_FORM_FACTOR_CARD`::
Proprietary card.

`DMI_MEMORY_DEVICE_FORM_FACTOR_DIMM`::
DIMM.

`DMI_MEMORY_DEVICE_FORM_FACTOR_TSOP`::
TSOP.

`DMI_MEMORY_DEVICE_FORM_FACTOR_CHIP_ROW`::
Row of chips.

`DMI_MEMORY_DEVICE_FORM_FACTOR_RIMM`::
RIMM.

`DMI_MEMORY_DEVICE_FORM_FACTOR_SODIMM`::
SODIMM.

`DMI_MEMORY_DEVICE_FORM_FACTOR_SRIMM`::
SRIMM.

`DMI_MEMORY_DEVICE_FORM_FACTOR_FBDIMM`::
FBDIMM.

`DMI_MEMORY_DEVICE_FORM_FACTOR_DIE`::
Die.

`DMI_MEMORY_DEVICE_FORM_FACTOR_CAMM`::
CAMM.

`DMI_MEMORY_DEVICE_FORM_FACTOR_CUDIMM`::
CUDIMM.

`DMI_MEMORY_DEVICE_FORM_FACTOR_CSODIMM`::
CSODIMM.

== Return value

`dmi_memory_device_form_factor_name` returns the name of the value, or
`nullptr` if the value has no name. The name is translated to the current
locale when the library is built with localization support and has a
translation for it, and is in English otherwise. The string is owned by the
library and must not be modified or freed.

== Errors

None.

== See also

`dmi_memory_device`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.1 or newer.
