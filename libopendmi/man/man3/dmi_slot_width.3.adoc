== Name

dmi_slot_width, dmi_slot_width_name - system slot widths

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/slot.h>

typedef enum dmi_slot_width {
    DMI_SLOT_WIDTH_UNSPEC  = 0x00,
    DMI_SLOT_WIDTH_OTHER   = 0x01,
    DMI_SLOT_WIDTH_UNKNOWN = 0x02,
    DMI_SLOT_WIDTH_8_BIT   = 0x03,
    DMI_SLOT_WIDTH_16_BIT  = 0x04,
    DMI_SLOT_WIDTH_32_BIT  = 0x05,
    DMI_SLOT_WIDTH_64_BIT  = 0x06,
    DMI_SLOT_WIDTH_128_BIT = 0x07,
    DMI_SLOT_WIDTH_1X      = 0x08,
    DMI_SLOT_WIDTH_2X      = 0x09,
    DMI_SLOT_WIDTH_4X      = 0x0A,
    DMI_SLOT_WIDTH_8X      = 0x0B,
    DMI_SLOT_WIDTH_12X     = 0x0C,
    DMI_SLOT_WIDTH_16X     = 0x0D,
    DMI_SLOT_WIDTH_32X     = 0x0E,
} dmi_slot_width_t;

const char *dmi_slot_width_name(dmi_slot_width_t value);
----

== Description

The `dmi_slot_width_t` enumeration tells the width of the data bus of a system
slot: a number of bits for parallel buses such as PCI, a number of lanes for
serial links such as PCI Express. It is the type of the `bus_width`,
`base_bus_width` and `physical_width` fields of `dmi_slot_t`, and of the
`bus_width` field of `dmi_slot_peer_group_t`. For PCI Express, the electrical
width is the widest link the slot supports; the width of the link actually
trained is not recorded in SMBIOS.

The `dmi_slot_width_name` function returns the name of a value, as the command
line tool shows it.

=== Values

`DMI_SLOT_WIDTH_UNSPEC`::
Unspecified.

`DMI_SLOT_WIDTH_OTHER`::
Other.

`DMI_SLOT_WIDTH_UNKNOWN`::
Unknown.

`DMI_SLOT_WIDTH_8_BIT`::
8 bits.

`DMI_SLOT_WIDTH_16_BIT`::
16 bits.

`DMI_SLOT_WIDTH_32_BIT`::
32 bits.

`DMI_SLOT_WIDTH_64_BIT`::
64 bits.

`DMI_SLOT_WIDTH_128_BIT`::
128 bits.

`DMI_SLOT_WIDTH_1X`::
One lane (x1).

`DMI_SLOT_WIDTH_2X`::
Two lanes (x2).

`DMI_SLOT_WIDTH_4X`::
Four lanes (x4).

`DMI_SLOT_WIDTH_8X`::
Eight lanes (x8).

`DMI_SLOT_WIDTH_12X`::
Twelve lanes (x12).

`DMI_SLOT_WIDTH_16X`::
Sixteen lanes (x16).

`DMI_SLOT_WIDTH_32X`::
Thirty-two lanes (x32).

== Return value

`dmi_slot_width_name` returns the name of the value, or `nullptr` if the value
has no name. The name is in English, or translated to the locale set with
`dmi_set_locale` when the library is built with localization support and has a
translation of it. The string must not be modified or freed; a translated one
stays valid until the locale is changed.

== Errors

None.
