== Name

dmi_hpe_usb_storage_proto, dmi_hpe_usb_storage_proto_name - USB mass storage
transport protocols

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/usb-device.h>

typedef enum dmi_hpe_usb_storage_proto {
    DMI_HPE_USB_STORAGE_PROTO_CBI_INT  = 0x00,
    DMI_HPE_USB_STORAGE_PROTO_CBI      = 0x01,
    DMI_HPE_USB_STORAGE_PROTO_OBSOLETE = 0x02,
    DMI_HPE_USB_STORAGE_PROTO_BOT      = 0x50,
    DMI_HPE_USB_STORAGE_PROTO_UAS      = 0x62,
    DMI_HPE_USB_STORAGE_PROTO_VENDOR   = 0xFF
} dmi_hpe_usb_storage_proto_t;

const char *dmi_hpe_usb_storage_proto_name(
        dmi_hpe_usb_storage_proto_t value);
----

== Description

The `dmi_hpe_usb_storage_proto_t` enumeration tells the transport protocol a USB
mass storage device uses, and names the `usb_protocol` field of
`dmi_hpe_usb_device_t` for the devices of the mass storage class (0x08).

The `dmi_hpe_usb_storage_proto_name` function returns the name of a value, as
the command line tool shows it.

=== Values

`DMI_HPE_USB_STORAGE_PROTO_CBI_INT`::
Control/bulk/interrupt (CBI) transport with command completion interrupt.

`DMI_HPE_USB_STORAGE_PROTO_CBI`::
Control/bulk/interrupt (CBI) transport without command completion interrupt.

`DMI_HPE_USB_STORAGE_PROTO_OBSOLETE`::
Obsolete.

`DMI_HPE_USB_STORAGE_PROTO_BOT`::
Bulk-only transport.

`DMI_HPE_USB_STORAGE_PROTO_UAS`::
USB attached SCSI (UAS).

`DMI_HPE_USB_STORAGE_PROTO_VENDOR`::
Vendor-specific.

== Return value

`dmi_hpe_usb_storage_proto_name` returns the name of the value, translated to
the language of the current locale when a translation is available, or `nullptr`
if the value has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_usb_device`(3), `dmi_hpe_usb_storage_subclass`(3)

== Standards

The codes are the ones the USB Implementers Forum defines for the class, as
dmidecode names them. The structure is not part of the SMBIOS specification: it
is defined by HP and HPE for their servers, and its layout is the one dmidecode
documents.
