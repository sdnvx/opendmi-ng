== Name

dmi_intel_me_state, dmi_intel_me_state_name - Intel Management Engine firmware working states

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/intel/mei.h>

typedef enum dmi_intel_me_state {
    DMI_INTEL_ME_STATE_RESET       = 0x00,
    DMI_INTEL_ME_STATE_INIT        = 0x01,
    DMI_INTEL_ME_STATE_RECOVERY    = 0x02,
    DMI_INTEL_ME_STATE_TEST        = 0x03,
    DMI_INTEL_ME_STATE_M3_NO_UMA   = 0x04,
    DMI_INTEL_ME_STATE_NORMAL      = 0x05,
    DMI_INTEL_ME_STATE_WAIT        = 0x06,
    DMI_INTEL_ME_STATE_TRANSITION  = 0x07,
    DMI_INTEL_ME_STATE_INVALID_CPU = 0x08,
    DMI_INTEL_ME_STATE_UNSPEC      = 0xFF
} dmi_intel_me_state_t;

const char *dmi_intel_me_state_name(dmi_intel_me_state_t value);
----

== Description

The `dmi_intel_me_state_t` enumeration tells the working state of the Intel
Management Engine firmware, as bits 0 to 3 of the first firmware status
register (HFSTS1) of the first interface tell it, and is the type of the
`state` field of `dmi_intel_mei_t`. Other values may be found in the data, and
are kept as they are.

The `dmi_intel_me_state_name` function returns the name of a value, as the command line
tool shows it.

=== Values

`DMI_INTEL_ME_STATE_RESET`::
Firmware is being reset.

`DMI_INTEL_ME_STATE_INIT`::
Firmware is initializing.

`DMI_INTEL_ME_STATE_RECOVERY`::
Firmware runs in the recovery mode, e.g. after its image has been found corrupted.

`DMI_INTEL_ME_STATE_TEST`::
Firmware runs its tests.

`DMI_INTEL_ME_STATE_M3_NO_UMA`::
Firmware runs in the M3 power state, without the memory of the host. coreboot
names the value disabled for the 6 series chipsets.

`DMI_INTEL_ME_STATE_NORMAL`::
Firmware runs normally.

`DMI_INTEL_ME_STATE_WAIT`::
Firmware waits for the platform to be disabled.

`DMI_INTEL_ME_STATE_TRANSITION`::
Firmware changes its operation state.

`DMI_INTEL_ME_STATE_INVALID_CPU`::
Processor does not match the firmware.

`DMI_INTEL_ME_STATE_UNSPEC`::
State is unknown, since the first interface is absent or not reported.

== Return value

`dmi_intel_me_state_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_intel_mei`(3)

== Standards

Not part of the SMBIOS specification. Defined by the Intel reference code,
which gives the structures type 219 by default. The layouts of the firmware
status registers are the ones of the Intel Management Engine, as coreboot
describes them.
