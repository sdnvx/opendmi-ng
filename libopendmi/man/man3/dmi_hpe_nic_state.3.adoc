== Name

dmi_hpe_nic_state, dmi_hpe_nic_state_name - HP/HPE network boot port states

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/nic.h>

typedef enum dmi_hpe_nic_state {
    DMI_HPE_NIC_STATE_INSTALLED     = 0x00,
    DMI_HPE_NIC_STATE_DISABLED      = 0x01,
    DMI_HPE_NIC_STATE_NOT_INSTALLED = 0x02
} dmi_hpe_nic_state_t;

const char *dmi_hpe_nic_state_name(dmi_hpe_nic_state_t value);
----

== Description

The `dmi_hpe_nic_state_t` enumeration tells the state of a network port the
firmware boots from, as the PCI bus and device of the port tell it, and is the
type of the `state` field of `dmi_hpe_nic_port_t`.

The `dmi_hpe_nic_state_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_HPE_NIC_STATE_INSTALLED`::
Installed.

`DMI_HPE_NIC_STATE_DISABLED`::
Disabled.

`DMI_HPE_NIC_STATE_NOT_INSTALLED`::
Not installed.

== Return value

`dmi_hpe_nic_state_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_nic_port`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
