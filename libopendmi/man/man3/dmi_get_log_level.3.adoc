== Name

dmi_get_log_level - get the logging level of an OpenDMI context.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/context.h>

dmi_log_level_t dmi_get_log_level(const dmi_context_t *context);
----

== Description

The `dmi_get_log_level` function returns the least severe level of the
messages the context writes to its handler, which has been set with
`dmi_set_log_level`(3).

=== Parameters

`context`::
Context to query.

== Return value

Returns the logging level, or `DMI_LOG_INVALID` if `context` is `nullptr`.

== Errors

None.

== See also

`dmi_set_log_level`(3),
`dmi_log`(3)
