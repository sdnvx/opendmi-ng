== Name

dmi_pci_device_id - PCI device identifier

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/common.h>

typedef uint16_t dmi_pci_device_id_t;
----

== Description

The `dmi_pci_device_id_t` type holds a PCI device identifier, which the vendor
assigns to its devices, as in the device and subsystem identifier registers of
a function.

The type is shared by several structures: it is the type of the `device_id` and
`sub_device_id` fields of `dmi_intel_rsd_pcie_t`, the `device_id` and
`sub_device_id` fields of `dmi_intel_rsd_network_card_t`, and the `device_id`
and `sub_device_id` fields of `dmi_intel_rsd_storage_device_t`.

== See also

`dmi_intel_rsd_pcie`(3), `dmi_intel_rsd_network_card`(3),
`dmi_intel_rsd_storage_device`(3), `dmi_pci_addr`(3)

== Standards

Not part of the SMBIOS specification. Used by the structures defined by Intel
Rack Scale Design firmware.
