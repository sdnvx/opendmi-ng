== Name

dmi_decoder_reader - get the reader of the data of the structure being decoded.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/decoder.h>

dmi_reader_t *dmi_decoder_reader(dmi_decoder_t *decoder);
----

== Description

The `dmi_decoder_reader` function returns the reader the bytes are read
through, which the decoder positions and the decoding handlers move as they
read.

Values are read through the decoder itself; the reader is for what it does
not say, such as marking a record with `dmi_reader_mark`(3) and stepping
over it by its declared length with `dmi_reader_skip_ex`(3).

=== Parameters

`decoder`::
Decoder to query.

== Return value

Reader of the data, or `nullptr` if `decoder` is `nullptr`.

== Errors

None.

== See also

`dmi_reader_mark`(3),
`dmi_reader_skip_ex`(3),
`dmi_reader_tell`(3),
`dmi_encoder_writer`(3)
