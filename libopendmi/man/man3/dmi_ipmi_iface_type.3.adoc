== Name

dmi_ipmi_iface_type, dmi_ipmi_iface_type_name - IPMI BMC interface types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/ipmi-device.h>

typedef enum dmi_ipmi_iface_type {
    DMI_IPMI_IFACE_TYPE_UNKNOWN = 0x00,
    DMI_IPMI_IFACE_TYPE_KCS     = 0x01,
    DMI_IPMI_IFACE_TYPE_SMIC    = 0x02,
    DMI_IPMI_IFACE_TYPE_BT      = 0x03,
    DMI_IPMI_IFACE_TYPE_SSIF    = 0x04,
} dmi_ipmi_iface_type_t;

const char *dmi_ipmi_iface_type_name(dmi_ipmi_iface_type_t value);
----

== Description

The `dmi_ipmi_iface_type_t` enumeration tells the type of the system interface
of an IPMI baseboard management controller (BMC), and is the type of the
`interface_type` field of `dmi_ipmi_device_t`. Values 0x05 to 0xFF are
reserved by the specification.

The `dmi_ipmi_iface_type_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_IPMI_IFACE_TYPE_UNKNOWN`::
Unknown.

`DMI_IPMI_IFACE_TYPE_KCS`::
Keyboard Controller Style (KCS) interface.

`DMI_IPMI_IFACE_TYPE_SMIC`::
Server Management Interface Chip (SMIC) interface.

`DMI_IPMI_IFACE_TYPE_BT`::
Block Transfer (BT) interface.

`DMI_IPMI_IFACE_TYPE_SSIF`::
SMBus System Interface (SSIF).

== Return value

`dmi_ipmi_iface_type_name` returns the name of the value, or `nullptr` if the
value has no name. The name is translated to the language of the current
locale when the library is built with localization support and has a
translation for it, and is in English otherwise. The string is owned by the
library and must not be modified or freed.

== Errors

None.

== See also

`dmi_ipmi_device`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.3 or newer.
