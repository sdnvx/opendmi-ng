== Name

dmi_buffer_destroy - free a buffer along with the data it holds.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/buffer.h>

void dmi_buffer_destroy(dmi_buffer_t *buffer);
----

== Description

The `dmi_buffer_destroy` function frees the buffer and the data it holds.

Everything referring to the data of the buffer, such as the strings and the
binary members of the structures decoded from it, refers to freed memory
afterwards, so a buffer is destroyed once nothing reads it any more. The
buffers of a context are destroyed by `dmi_close`(3).

=== Parameters

`buffer`::
Buffer to destroy, or `nullptr`.

== Errors

None.

`dmi_buffer_create`(3),
