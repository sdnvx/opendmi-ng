== Name

dmi_dell_device_names - Dell device names structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/dell/device-names.h>

typedef struct dmi_dell_device_names {
    uint8_t unknown;
    size_t device_count;
    dmi_dell_device_name_t *devices;
} dmi_dell_device_names_t;
----

== Description

The `dmi_dell_device_names_t` structure holds the decoded Dell device names
(type 225), which give the devices of a kind, e.g. the processors or the
memory devices, the names the management controller (iDRAC) of a PowerEdge
server knows them by, its fully qualified device descriptors (FQDD). The
structures are found on PowerEdge servers of the 13th and 14th generations,
e.g. PowerEdge R630 and R740xd, one for the processors and one for the memory
devices.

The structure is returned by `dmi_entity_info`(3) for the structures decoded
by `dmi_dell_device_names_spec`, of type `DMI_TYPE(dell_device_names)`,
declared in `<opendmi/module/dell.h>`, once the Dell extension module
(`dmi_dell_module`) is enabled. It lives as long as the context it has been
decoded in.

The layout is reverse engineered from the dumps of the data corpus, since no
public source describes the structure, and the members whose meaning is not
established are named after their position.

=== Fields

`unknown`::
Value whose meaning is not established, `1` in all known data.

`device_count`::
Number of elements of `devices`.

`devices`::
Names of the devices, see `dmi_dell_device_name`(3). May be `nullptr` when
`device_count` is 0.

== See also

`dmi_dell_device_name`(3), `dmi_entity_info`(3)

== Standards

Not part of the SMBIOS specification. Defined by Dell firmware, and reverse
engineered from the data corpus.
