== Name

dmi_encoder_writer - get the writer of the data being written.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/encoder.h>

dmi_writer_t *dmi_encoder_writer(dmi_encoder_t *encoder);
----

== Description

The `dmi_encoder_writer` function returns the writer the bytes are written
through, which the encoder positions and the encoding handlers move as they
write.

Values are written through the encoder itself; the writer is for what it
does not say, such as marking a record with `dmi_writer_mark`(3) and padding
it out to its declared length with `dmi_writer_skip_ex`(3).

=== Parameters

`encoder`::
Encoder to query.

== Return value

Writer of the data, or `nullptr` if `encoder` is `nullptr`.

== Errors

None.

== See also

`dmi_writer_mark`(3),
`dmi_writer_skip_ex`(3),
`dmi_writer_tell`(3),
`dmi_decoder_reader`(3)
