== Name

dmi_intel_amt_terminal, dmi_intel_amt_terminal_name - Intel AMT terminal emulations of Serial over LAN

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/intel/amt.h>

typedef enum dmi_intel_amt_terminal {
    DMI_INTEL_AMT_TERMINAL_UNSPEC     = 0x00,
    DMI_INTEL_AMT_TERMINAL_VT52       = 0x01,
    DMI_INTEL_AMT_TERMINAL_VT100_PLUS = 0x02,
    DMI_INTEL_AMT_TERMINAL_VT_UTF8    = 0x03,
    DMI_INTEL_AMT_TERMINAL_PC_ANSI    = 0x04
} dmi_intel_amt_terminal_t;

const char *dmi_intel_amt_terminal_name(dmi_intel_amt_terminal_t value);
----

== Description

The `dmi_intel_amt_terminal_t` enumeration tells the terminal emulation of
Serial over LAN, as the low nibble of the second byte of the OEM capabilities
of Intel AMT information tells it, and is the type of the `terminal` field of
`dmi_intel_amt_t`. Other values are reserved, and are kept as they are.

The `dmi_intel_amt_terminal_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_INTEL_AMT_TERMINAL_UNSPEC`::
Terminal emulation is not given.

`DMI_INTEL_AMT_TERMINAL_VT52`::
VT52.

`DMI_INTEL_AMT_TERMINAL_VT100_PLUS`::
VT100+, which most platforms give.

`DMI_INTEL_AMT_TERMINAL_VT_UTF8`::
VT-UTF8.

`DMI_INTEL_AMT_TERMINAL_PC_ANSI`::
PC-ANSI.

== Return value

`dmi_intel_amt_terminal_name` returns the name of the value, translated to the
language of the current locale when a translation is available, or `nullptr`
if the value has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_intel_amt`(3)

== Standards

Not part of the SMBIOS specification. Defined by Intel, as the AMT
information table of the Intel AMT implementation and reference guide.
