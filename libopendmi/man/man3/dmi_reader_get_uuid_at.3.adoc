== Name

dmi_reader_get_uuid_at - read and decode a UUID from the reader at a given offset.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/reader.h>

dmi_reader_get_uuid_at(reader, offset, pvalue)
----

== Description

The `dmi_reader_get_uuid_at` macro reads 16 bytes at `offset` from the
beginning of the entity body, converts the UUID from SMBIOS byte order into
RFC 4122 representation using `dmi_uuid_decode`, and stores the result in the
variable pointed to by `pvalue`. The reader cursor is not modified.

=== Parameters

`reader`::
Reader to read from.

`offset`::
Byte offset from the beginning of the entity body.

`pvalue`::
Pointer to a variable that receives the decoded UUID.

== Return value

Returns `true` on success, `false` if the requested range exceeds the reader
bounds.
