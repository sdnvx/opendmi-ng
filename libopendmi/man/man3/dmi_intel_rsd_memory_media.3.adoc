== Name

dmi_intel_rsd_memory_media, dmi_intel_rsd_memory_media_name - Intel RSD memory
media types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/intel/rsd-memory-device.h>

typedef enum dmi_intel_rsd_memory_media {
    DMI_INTEL_RSD_MEMORY_MEDIA_DRAM        = 0x00,
    DMI_INTEL_RSD_MEMORY_MEDIA_NAND        = 0x01,
    DMI_INTEL_RSD_MEMORY_MEDIA_PROPRIETARY = 0x03
} dmi_intel_rsd_memory_media_t;

const char *dmi_intel_rsd_memory_media_name(
        dmi_intel_rsd_memory_media_t value);
----

== Description

The `dmi_intel_rsd_memory_media_t` enumeration tells the media a memory module
keeps its data in, and is the type of the `memory_media` field of
`dmi_intel_rsd_memory_device_t`. The specification defines no value 0x02.

The `dmi_intel_rsd_memory_media_name` function returns the name of a value,
as the command line tool shows it.

=== Values

`DMI_INTEL_RSD_MEMORY_MEDIA_DRAM`::
DRAM.

`DMI_INTEL_RSD_MEMORY_MEDIA_NAND`::
NAND flash.

`DMI_INTEL_RSD_MEMORY_MEDIA_PROPRIETARY`::
Media of a proprietary technology.

== Return value

`dmi_intel_rsd_memory_media_name` returns the name of the value, translated to
the language of the current locale when a translation is available, or
`nullptr` if the value has no name. The returned string must not be modified or
freed.

== Errors

None.

== See also

`dmi_intel_rsd_memory_device`(3), `dmi_intel_rsd_memory_type`(3)

== Standards

Not part of the SMBIOS specification. Defined by Intel Rack Scale Design (RSD)
firmware.
