== Name

dmi_slot_length, dmi_slot_length_name - system slot lengths

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/slot.h>

typedef enum dmi_slot_length {
    DMI_SLOT_LENGTH_UNSPEC   = 0x00,
    DMI_SLOT_LENGTH_OTHER    = 0x01,
    DMI_SLOT_LENGTH_UNKNOWN  = 0x02,
    DMI_SLOT_LENGTH_SHORT    = 0x03,
    DMI_SLOT_LENGTH_LONG     = 0x04,
    DMI_SLOT_LENGTH_SFF_8200 = 0x05,
    DMI_SLOT_LENGTH_SFF_8300 = 0x06,
} dmi_slot_length_t;

const char *dmi_slot_length_name(dmi_slot_length_t value);
----

== Description

The `dmi_slot_length_t` enumeration tells the length of a system slot, and is
the type of the `length` field of `dmi_slot_t`.

The `dmi_slot_length_name` function returns the name of a value, as the command
line tool shows it.

=== Values

`DMI_SLOT_LENGTH_UNSPEC`::
Unspecified.

`DMI_SLOT_LENGTH_OTHER`::
Other.

`DMI_SLOT_LENGTH_UNKNOWN`::
Unknown.

`DMI_SLOT_LENGTH_SHORT`::
Short; also used for EDSFF E1.S and E3.S slots.

`DMI_SLOT_LENGTH_LONG`::
Long; also used for EDSFF E1.L and E3.L slots.

`DMI_SLOT_LENGTH_SFF_8200`::
Form factor of a 2.5-inch drive.

`DMI_SLOT_LENGTH_SFF_8300`::
Form factor of a 3.5-inch drive.

== Return value

`dmi_slot_length_name` returns the name of the value, or `nullptr` if the value
has no name. The name is in English, or translated to the locale set with
`dmi_set_locale` when the library is built with localization support and has a
translation of it. The string must not be modified or freed; a translated one
stays valid until the locale is changed.

== Errors

None.

== See also

`dmi_slot`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.0 or newer.
