== Name

dmi_acer_device_entry - Acer device structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/acer/devices.h>

typedef struct dmi_acer_device_entry {
    dmi_acer_device_kind_t kind;
    uint16_t vendor_id;
    uint16_t device_id;
} dmi_acer_device_entry_t;
----

== Description

The `dmi_acer_device_entry_t` structure describes a device of an Acer laptop,
as an element of the `devices` field of `dmi_acer_devices_t`.

=== Fields

`kind`::
Kind of the device, whose meaning is not established, see
`dmi_acer_device_kind`(3).

`vendor_id`::
PCI or USB vendor ID of the device, zero if the device is absent.

`device_id`::
PCI or USB device ID of the device, zero if the device is absent.

== See also

`dmi_acer_devices`(3),
`dmi_acer_device_kind`(3)

== Standards

Not part of the SMBIOS specification. Defined by Acer firmware, and reverse
engineered from the data corpus.
