== Description

The `dmi_processor_upgrade_t` enumeration tells how the processor of a socket
can be upgraded, which is most often the type of the socket, and is the type
of the `upgrade` field of `dmi_processor_t`.

The specification also defines the value 0xFF, which the enumeration does not
name, for the sockets no value fits; the `socket_type` field of
`dmi_processor_t` names the socket then.

The `dmi_processor_upgrade_name` function returns the name of a value, as the
command line tool shows it.

== Return value

`dmi_processor_upgrade_name` returns the name of the value, or `nullptr` if
the value has no name. The name is translated to the current locale when the
library is built with localization support and has a translation for it, and
is in English otherwise. The string is owned by the library and must not be
modified or freed.

== Errors

None.
