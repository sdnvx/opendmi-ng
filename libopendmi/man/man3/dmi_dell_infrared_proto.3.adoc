== Name

dmi_dell_infrared_proto, dmi_dell_infrared_proto_name - Dell infrared port
protocols

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/dell/infrared-port.h>

typedef enum dmi_dell_infrared_proto {
    DMI_DELL_INFRARED_PROTO_UNSPEC  = 0x00,
    DMI_DELL_INFRARED_PROTO_OTHER   = 0x01,
    DMI_DELL_INFRARED_PROTO_UNKNOWN = 0x02,
    DMI_DELL_INFRARED_PROTO_SIR     = 0x03,
    DMI_DELL_INFRARED_PROTO_FIR     = 0x04,
    DMI_DELL_INFRARED_PROTO_MIR     = 0x05,
} dmi_dell_infrared_proto_t;

const char *dmi_dell_infrared_proto_name(dmi_dell_infrared_proto_t value);
----

== Description

The `dmi_dell_infrared_proto_t` enumeration tells the protocol of a Dell
infrared port, and is the type of the `protocol` field of
`dmi_dell_infrared_port_t`.

The `dmi_dell_infrared_proto_name` function returns the name of a value, as the
command line tool shows it. The name is in English, or in the language of the
locale the library is set to when it has a translation of the name.

=== Values

`DMI_DELL_INFRARED_PROTO_UNSPEC`::
Unspecified. The firmware does not define the value 0.

`DMI_DELL_INFRARED_PROTO_OTHER`::
Other protocol.

`DMI_DELL_INFRARED_PROTO_UNKNOWN`::
Unknown protocol.

`DMI_DELL_INFRARED_PROTO_SIR`::
Standard IR (SIR).

`DMI_DELL_INFRARED_PROTO_FIR`::
Fast IR (FIR).

`DMI_DELL_INFRARED_PROTO_MIR`::
Medium speed IR (MIR).

== Return value

`dmi_dell_infrared_proto_name` returns the name of the value, a constant string
which must not be modified or freed, or `nullptr` if the value has no name,
e.g. a value out of the range of the enumeration.

== Errors

None.

== See also

`dmi_dell_infrared_port`(3)

== Standards

Not part of the SMBIOS specification. Defined by Dell firmware, see the Dell
Infrared Port (Type 211) chapter of the reference manual.
