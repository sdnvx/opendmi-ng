== Name

dmi_entity_offset - get the offset the data of a structure begins at within its buffer.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/entity.h>

size_t dmi_entity_offset(const dmi_entity_t *entity);
----

== Description

The `dmi_entity_offset` function returns the offset the data of the
structure begins at within the buffer `dmi_entity_buffer`(3) gives, which is
where a reader of the structure starts.

=== Parameters

`entity`::
Entity descriptor.

== Return value

Offset of the data, or zero if `entity` is `nullptr`.
