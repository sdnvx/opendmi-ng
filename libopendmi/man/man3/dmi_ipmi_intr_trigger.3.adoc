== Name

dmi_ipmi_intr_trigger, dmi_ipmi_intr_trigger_name - IPMI interrupt trigger modes

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/ipmi-device.h>

typedef enum dmi_ipmi_intr_trigger {
    DMI_IPMI_INTR_TRIGGER_UNSPEC = 0x0,
    DMI_IPMI_INTR_TRIGGER_EDGE   = 0x1,
    DMI_IPMI_INTR_TRIGGER_LEVEL  = 0x2
} dmi_ipmi_intr_trigger_t;

const char *dmi_ipmi_intr_trigger_name(dmi_ipmi_intr_trigger_t value);
----

== Description

The `dmi_ipmi_intr_trigger_t` enumeration tells how the interrupt of the
system interface of an IPMI baseboard management controller is triggered,
and is the type of the `intr_trigger` field of `dmi_ipmi_device_t`.

The `dmi_ipmi_intr_trigger_name` function returns the name of a value, as
the command line tool shows it.

=== Values

`DMI_IPMI_INTR_TRIGGER_UNSPEC`::
Unspecified: the structure does not give the interrupt information.

`DMI_IPMI_INTR_TRIGGER_EDGE`::
Edge-triggered interrupt.

`DMI_IPMI_INTR_TRIGGER_LEVEL`::
Level-triggered interrupt.

== Return value

`dmi_ipmi_intr_trigger_name` returns the name of the value, or `nullptr` if
the value has no name. The name is translated to the language of the current
locale when the library is built with localization support and has a
translation for it, and is in English otherwise. The string is owned by the
library and must not be modified or freed.

== Errors

None.

== See also

`dmi_ipmi_device`(3), `dmi_ipmi_intr_polarity`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.3 or newer.
