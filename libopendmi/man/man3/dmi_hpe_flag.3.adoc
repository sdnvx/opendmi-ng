== Name

dmi_hpe_flag, dmi_hpe_flag_name - HP/HPE flags of undefined value

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/common.h>

typedef enum dmi_hpe_flag {
    DMI_HPE_FLAG_NO     = 0x00,
    DMI_HPE_FLAG_YES    = 0x01,
    DMI_HPE_FLAG_UNSPEC = 0xFF
} dmi_hpe_flag_t;

const char *dmi_hpe_flag_name(dmi_hpe_flag_t value);
----

== Description

The `dmi_hpe_flag_t` enumeration tells the value of a flag which the structure
may leave undefined, e.g. because the module or the firmware does not support
it. It is the type of the flags of `dmi_hpe_dimm_attrs_t` and of
`dmi_hpe_inventory_t`.

The `dmi_hpe_flag_name` function returns the name of a value, as the command
line tool shows it.

=== Values

`DMI_HPE_FLAG_NO`::
No.

`DMI_HPE_FLAG_YES`::
Yes.

`DMI_HPE_FLAG_UNSPEC`::
Not defined.

== Return value

`dmi_hpe_flag_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_dimm_attrs`(3),
`dmi_hpe_inventory`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
