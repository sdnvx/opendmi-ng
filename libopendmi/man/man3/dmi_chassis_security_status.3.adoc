== Name

dmi_chassis_security_status, dmi_chassis_security_status_name - physical
security statuses of system enclosures

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/chassis.h>

typedef enum dmi_chassis_security_status {
    DMI_CHASSIS_SECURITY_STATUS_UNSPEC         = 0x00,
    DMI_CHASSIS_SECURITY_STATUS_OTHER          = 0x01,
    DMI_CHASSIS_SECURITY_STATUS_UNKNOWN        = 0x02,
    DMI_CHASSIS_SECURITY_STATUS_NONE           = 0x03,
    DMI_CHASSIS_SECURITY_STATUS_EXT_IF_LOCKED  = 0x04,
    DMI_CHASSIS_SECURITY_STATUS_EXT_IF_ENABLED = 0x05,
} dmi_chassis_security_status_t;

const char *dmi_chassis_security_status_name(
        dmi_chassis_security_status_t value);
----

== Description

The `dmi_chassis_security_status_t` enumeration tells the physical security
status of a system enclosure at the last boot, and is the type of the
`security_status` field of `dmi_chassis_t`.

The `dmi_chassis_security_status_name` function returns the printable name of a
value, as the command line tool shows it. The name is translated to the locale
set with `dmi_set_locale`, when the library is built with ICU4C support and has
a translation of it.

=== Values

`DMI_CHASSIS_SECURITY_STATUS_UNSPEC`::
Unspecified.

`DMI_CHASSIS_SECURITY_STATUS_OTHER`::
Other status.

`DMI_CHASSIS_SECURITY_STATUS_UNKNOWN`::
Unknown status.

`DMI_CHASSIS_SECURITY_STATUS_NONE`::
No physical security.

`DMI_CHASSIS_SECURITY_STATUS_EXT_IF_LOCKED`::
External interfaces are locked out.

`DMI_CHASSIS_SECURITY_STATUS_EXT_IF_ENABLED`::
External interfaces are enabled.

== Return value

`dmi_chassis_security_status_name` returns the name of the value, or `nullptr`
if the value has no name. The name is a static string, which must not be
modified or freed.

== Errors

None.

== See also

`dmi_chassis`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.1 or newer.
