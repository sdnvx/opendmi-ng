== Name

dmi_intel_rsd_fpga_memory_tech, dmi_intel_rsd_fpga_memory_tech_name - Intel RSD
FPGA memory technologies

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/intel/rsd-fpga.h>

typedef enum dmi_intel_rsd_fpga_memory_tech {
    DMI_INTEL_RSD_FPGA_MEMORY_TECH_NONE  = 0x00,
    DMI_INTEL_RSD_FPGA_MEMORY_TECH_EDRAM = 0x01,
    DMI_INTEL_RSD_FPGA_MEMORY_TECH_HBM   = 0x02,
    DMI_INTEL_RSD_FPGA_MEMORY_TECH_HBM2  = 0x03
} dmi_intel_rsd_fpga_memory_tech_t;

const char *dmi_intel_rsd_fpga_memory_tech_name(
        dmi_intel_rsd_fpga_memory_tech_t value);
----

== Description

The `dmi_intel_rsd_fpga_memory_tech_t` enumeration tells the technology of the
memory attached to an FPGA, and is the type of the `memory_tech` field of
`dmi_intel_rsd_fpga_t`.

The `dmi_intel_rsd_fpga_memory_tech_name` function returns the printable name
of a value, as the command line tool shows it. The name is translated to the
locale set with `dmi_set_locale`, when the library is built with ICU4C support
and has a translation of it.

=== Values

`DMI_INTEL_RSD_FPGA_MEMORY_TECH_NONE`::
No memory is attached.

`DMI_INTEL_RSD_FPGA_MEMORY_TECH_EDRAM`::
Embedded DRAM (eDRAM).

`DMI_INTEL_RSD_FPGA_MEMORY_TECH_HBM`::
High Bandwidth Memory (HBM).

`DMI_INTEL_RSD_FPGA_MEMORY_TECH_HBM2`::
High Bandwidth Memory of the second generation (HBM2).

== Return value

`dmi_intel_rsd_fpga_memory_tech_name` returns the name of the value, or
`nullptr` if the value has no name. The name is a static string, which must not
be modified or freed.

== Errors

None.

== See also

`dmi_intel_rsd_fpga`(3)

== Standards

Not part of the SMBIOS specification. Defined by Intel Rack Scale Design (RSD)
firmware.
