== Name

dmi_hpe_fru_access, dmi_hpe_fru_access_name - HP/HPE power supply FRU access methods

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/power-supply.h>

typedef enum dmi_hpe_fru_access {
    DMI_HPE_FRU_ACCESS_NONE    = 0x00,
    DMI_HPE_FRU_ACCESS_IPMI    = 0x01,
    DMI_HPE_FRU_ACCESS_ILO     = 0x02,
    DMI_HPE_FRU_ACCESS_CHASSIS = 0x03
} dmi_hpe_fru_access_t;

const char *dmi_hpe_fru_access_name(dmi_hpe_fru_access_t value);
----

== Description

The `dmi_hpe_fru_access_t` enumeration tells the method the FRU of a power
supply is accessed by, and is the type of the `fru_access` field of
`dmi_hpe_power_supply_t`.

The `dmi_hpe_fru_access_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_HPE_FRU_ACCESS_NONE`::
Not available.

`DMI_HPE_FRU_ACCESS_IPMI`::
IPMI I2C.

`DMI_HPE_FRU_ACCESS_ILO`::
iLO.

`DMI_HPE_FRU_ACCESS_CHASSIS`::
Chassis manager.

== Return value

`dmi_hpe_fru_access_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_power_supply`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
