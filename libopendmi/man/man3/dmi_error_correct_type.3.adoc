== Name

dmi_error_correct_type, dmi_error_correct_type_name - error correction types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/common.h>

typedef enum dmi_error_correct_type {
    DMI_ERROR_CORRECT_TYPE_UNSPEC     = 0x00,
    DMI_ERROR_CORRECT_TYPE_OTHER      = 0x01,
    DMI_ERROR_CORRECT_TYPE_UNKNOWN    = 0x02,
    DMI_ERROR_CORRECT_TYPE_NONE       = 0x03,
    DMI_ERROR_CORRECT_TYPE_PARITY     = 0x04,
    DMI_ERROR_CORRECT_TYPE_SINGLE_BIT = 0x05,
    DMI_ERROR_CORRECT_TYPE_MULTI_BIT  = 0x06,
    DMI_ERROR_CORRECT_TYPE_CRC        = 0x07,
} dmi_error_correct_type_t;

const char *dmi_error_correct_type_name(dmi_error_correct_type_t value);
----

== Description

The `dmi_error_correct_type_t` enumeration tells how errors of a memory are
detected or corrected. It is shared by several structures: it is the type of
the `error_correction` fields of `dmi_cache_t` and `dmi_memory_array_t`.

The `dmi_error_correct_type_name` function returns the printable name of a
value, as the command line tool shows it. The name is translated to the locale
set with `dmi_set_locale`, when the library is built with ICU4C support and has
a translation of it.

=== Values

`DMI_ERROR_CORRECT_TYPE_UNSPEC`::
Unspecified: the data carries no error correction type.

`DMI_ERROR_CORRECT_TYPE_OTHER`::
Other error correction.

`DMI_ERROR_CORRECT_TYPE_UNKNOWN`::
Unknown error correction.

`DMI_ERROR_CORRECT_TYPE_NONE`::
No error detection or correction.

`DMI_ERROR_CORRECT_TYPE_PARITY`::
Parity checking.

`DMI_ERROR_CORRECT_TYPE_SINGLE_BIT`::
Error-correcting code correcting single-bit errors.

`DMI_ERROR_CORRECT_TYPE_MULTI_BIT`::
Error-correcting code correcting multi-bit errors.

`DMI_ERROR_CORRECT_TYPE_CRC`::
Cyclic redundancy check.

== Return value

`dmi_error_correct_type_name` returns the name of the value, or `nullptr` if
the value has no name. The name is a static string, which must not be modified
or freed.

== Errors

None.

== See also

`dmi_cache`(3), `dmi_memory_array`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.1 or newer.
