== Name

dmi_encoder_put - encode a value and write it at the current position.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/encoder.h>

dmi_encoder_put(encoder, type, value)
----

== Description

The `dmi_encoder_put` macro converts `value` into `type` in SMBIOS wire
format (little-endian) using `dmi_encode` and writes `sizeof(type)` bytes.
The cursor is advanced.

=== Parameters

`encoder`::
Encoder to write to.

`type`::
Wire-format type to write (e.g. `dmi_word_t`, `dmi_dword_t`).

`value`::
Value to write.

== Return value

`true` on success, `false` if the buffer cannot grow.
