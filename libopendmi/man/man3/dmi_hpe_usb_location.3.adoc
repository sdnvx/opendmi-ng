== Name

dmi_hpe_usb_location, dmi_hpe_usb_location_name - HP/HPE USB port locations

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/usb-port.h>

typedef enum dmi_hpe_usb_location {
    DMI_HPE_USB_LOCATION_INTERNAL = 0x00,
    DMI_HPE_USB_LOCATION_FRONT    = 0x01,
    DMI_HPE_USB_LOCATION_REAR     = 0x02,
    DMI_HPE_USB_LOCATION_SD_CARD  = 0x03,
    DMI_HPE_USB_LOCATION_ILO      = 0x04,
    DMI_HPE_USB_LOCATION_NAND_HUB = 0x05,
    DMI_HPE_USB_LOCATION_DEBUG    = 0x07,
    DMI_HPE_USB_LOCATION_OCP      = 0x09
} dmi_hpe_usb_location_t;

const char *dmi_hpe_usb_location_name(dmi_hpe_usb_location_t value);
----

== Description

The `dmi_hpe_usb_location_t` enumeration tells the location of a USB port, and
is the type of the `location` field of `dmi_hpe_usb_port_t`.

The `dmi_hpe_usb_location_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_HPE_USB_LOCATION_INTERNAL`::
Internal.

`DMI_HPE_USB_LOCATION_FRONT`::
Front of the server.

`DMI_HPE_USB_LOCATION_REAR`::
Rear of the server.

`DMI_HPE_USB_LOCATION_SD_CARD`::
Embedded internal SD card.

`DMI_HPE_USB_LOCATION_ILO`::
iLO USB.

`DMI_HPE_USB_LOCATION_NAND_HUB`::
USB hub of the NAND controller.

`DMI_HPE_USB_LOCATION_DEBUG`::
Debug port.

`DMI_HPE_USB_LOCATION_OCP`::
OCP USB.

== Return value

`dmi_hpe_usb_location_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_usb_port`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
