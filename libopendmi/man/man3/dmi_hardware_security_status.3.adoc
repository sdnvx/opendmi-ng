== Name

dmi_hardware_security_status, dmi_hardware_security_status_name - hardware
security setting states

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hardware-security.h>

typedef enum dmi_hardware_security_status {
    DMI_HARDWARE_SECURITY_STATUS_DISABLED        = 0x00,
    DMI_HARDWARE_SECURITY_STATUS_ENABLED         = 0x01,
    DMI_HARDWARE_SECURITY_STATUS_NOT_IMPLEMENTED = 0x02,
    DMI_HARDWARE_SECURITY_STATUS_UNKNOWN         = 0x03,
} dmi_hardware_security_status_t;

const char *dmi_hardware_security_status_name(
        dmi_hardware_security_status_t value);
----

== Description

The `dmi_hardware_security_status_t` enumeration tells the state of a hardware
security setting, and is the type of the fields of `dmi_hardware_security_t`.
The structure carries each state in two bits, so every value it can hold is
defined.

The `dmi_hardware_security_status_name` function returns the name of a value,
as the command line tool shows it. The name is in English, or in the language
of the locale the library is set to when it has a translation of the name.

=== Values

`DMI_HARDWARE_SECURITY_STATUS_DISABLED`::
Setting is disabled.

`DMI_HARDWARE_SECURITY_STATUS_ENABLED`::
Setting is enabled.

`DMI_HARDWARE_SECURITY_STATUS_NOT_IMPLEMENTED`::
System does not implement the setting.

`DMI_HARDWARE_SECURITY_STATUS_UNKNOWN`::
State of the setting is unknown.

== Return value

`dmi_hardware_security_status_name` returns the name of the value, a constant
string which must not be modified or freed, or `nullptr` if the value has no
name, e.g. a value out of the range of the enumeration.

== Errors

None.

== See also

`dmi_hardware_security`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.2 or newer.
