== Name

dmi_cooling_device_type, dmi_cooling_device_type_name - cooling device types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/cooling-device.h>

typedef enum dmi_cooling_device_type {
    DMI_COOLING_DEVICE_TYPE_UNSPEC                   = 0x00,
    DMI_COOLING_DEVICE_TYPE_OTHER                    = 0x01,
    DMI_COOLING_DEVICE_TYPE_UNKNOWN                  = 0x02,
    DMI_COOLING_DEVICE_TYPE_FAN                      = 0x03,
    DMI_COOLING_DEVICE_TYPE_CENTRIFUGAL_BLOWER       = 0x04,
    DMI_COOLING_DEVICE_TYPE_CHIP_FAN                 = 0x05,
    DMI_COOLING_DEVICE_TYPE_CABINET_FAN              = 0x06,
    DMI_COOLING_DEVICE_TYPE_POWER_SUPPLY_FAN         = 0x07,
    DMI_COOLING_DEVICE_TYPE_HEAT_PIPE                = 0x08,
    DMI_COOLING_DEVICE_TYPE_INTEGRATED_REFRIGERATION = 0x09,
    DMI_COOLING_DEVICE_TYPE_ACTIVE_COOLING           = 0x10,
    DMI_COOLING_DEVICE_TYPE_PASSIVE_COOLING          = 0x11,
} dmi_cooling_device_type_t;

const char *dmi_cooling_device_type_name(dmi_cooling_device_type_t value);
----

== Description

The `dmi_cooling_device_type_t` enumeration tells the kind of a cooling
device, and is the type of the `type` field of `dmi_cooling_device_t`. The
data carries it in 5 bits; values 0x0A to 0x0F and above 0x11 are not assigned
by the specification.

The `dmi_cooling_device_type_name` function returns the printable name of a
value, as the command line tool shows it. The name is translated to the locale
set with `dmi_set_locale`, when the library is built with ICU4C support and
has a translation of it.

=== Values

`DMI_COOLING_DEVICE_TYPE_UNSPEC`::
Unspecified.

`DMI_COOLING_DEVICE_TYPE_OTHER`::
Other type.

`DMI_COOLING_DEVICE_TYPE_UNKNOWN`::
Unknown type.

`DMI_COOLING_DEVICE_TYPE_FAN`::
Fan.

`DMI_COOLING_DEVICE_TYPE_CENTRIFUGAL_BLOWER`::
Centrifugal blower.

`DMI_COOLING_DEVICE_TYPE_CHIP_FAN`::
Chip fan.

`DMI_COOLING_DEVICE_TYPE_CABINET_FAN`::
Cabinet fan.

`DMI_COOLING_DEVICE_TYPE_POWER_SUPPLY_FAN`::
Power supply fan.

`DMI_COOLING_DEVICE_TYPE_HEAT_PIPE`::
Heat pipe.

`DMI_COOLING_DEVICE_TYPE_INTEGRATED_REFRIGERATION`::
Integrated refrigeration.

`DMI_COOLING_DEVICE_TYPE_ACTIVE_COOLING`::
Active cooling.

`DMI_COOLING_DEVICE_TYPE_PASSIVE_COOLING`::
Passive cooling.

== Return value

`dmi_cooling_device_type_name` returns the name of the value, or `nullptr` if
the value has no name. The name is a static string, which must not be modified
or freed.

== Errors

None.

== See also

`dmi_cooling_device`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.2 or newer.
