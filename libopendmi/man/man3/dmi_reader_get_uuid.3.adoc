== Name

dmi_reader_get_uuid - read and decode a UUID from the reader at the current position.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/reader.h>

dmi_reader_get_uuid(reader, pvalue)
----

== Description

The `dmi_reader_get_uuid` macro reads 16 bytes from the reader, converts
the UUID from SMBIOS byte order into RFC 4122 representation using
`dmi_uuid_decode`, and stores the result in the variable pointed to by
`pvalue`. The reader cursor is advanced.

=== Parameters

`reader`::
Reader to read from.

`pvalue`::
Pointer to a variable that receives the decoded UUID.

== Return value

Returns `true` on success, `false` if there are not enough bytes remaining.
