== Name

dmi_intel_vpro - Intel vPro information structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/intel/vpro.h>

typedef struct dmi_intel_vpro {
    uint32_t flags_1;
    dmi_intel_vpro_version_t mebx_version;
    uint16_t lpc_devfn;
    uint16_t lpc_device_id;
    uint32_t flags_2;
    dmi_intel_vpro_version_t me_version;
    uint16_t gbe_devfn;
    uint16_t gbe_device_id;
    uint32_t flags_3;
    dmi_binary_t signature;
} dmi_intel_vpro_t;
----

== Description

The `dmi_intel_vpro_t` structure holds the decoded Intel vPro information,
which describes the parts of the platform Intel vPro technology relies on:
the versions of the Management Engine firmware and of its BIOS extension
(MEBx), and the PCI functions of the chipset and of the network controller
the Management Engine uses. The structure is found on Intel platforms whether
they are of vPro or not.

The structure is returned by `dmi_entity_info`(3) for the structures decoded
by `dmi_intel_vpro_spec`, of type `DMI_TYPE(intel_vpro)`, declared in
`<opendmi/module/intel.h>`, once the Intel extension module
(`dmi_intel_module`) is enabled, which is done for any platform with Intel
processors when the context has `DMI_CONTEXT_FLAG_AUTO_MODULES`. It lives as
long as the context it has been decoded in.

The structures are told by the `vPro` signature at offset 0x38, since some
vendors give type 131 to structures of their own in the same table, e.g.
Lenovo ThinkVantage Technologies enablement, see `dmi_lenovo_tvt`(3). The
structures of type 131 without the signature are not decoded by this
specification.

PCI functions are given as their device and function numbers on bus 0,
`(device << 3) | function`, e.g. `0xF8` for 0:1F.0 and `0xFE` for 0:1F.6.

=== Fields

`flags_1`, `flags_2`, `flags_3`::
Capability flags of the platform, of the Management Engine and of the
features, as the structure holds them. The meaning of their bits is not
established.

`mebx_version`::
Version of the Management Engine BIOS extension, see
`dmi_intel_vpro_version`(3). All zeroes if not reported.

`lpc_devfn`, `lpc_device_id`::
PCI device and function of the LPC bridge of the chipset, and its device ID,
which tells the chipset, e.g. `0xA3C8` for Intel B460.

`me_version`::
Version of the Management Engine firmware, which matches the one of Intel
firmware version information, see `dmi_intel_fvi_item`(3). All zeroes if not
reported.

`gbe_devfn`, `gbe_device_id`::
PCI device and function of the Gigabit Ethernet controller the Management
Engine uses, and its device ID, `0xFFFF` if the controller is absent.

`signature`::
Signature of the structure, `vPro`.
