== Name

dmi_slot_height, dmi_slot_height_name - system slot heights

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/slot.h>

typedef enum dmi_slot_height {
    DMI_SLOT_HEIGHT_UNSPEC      = 0x00,
    DMI_SLOT_HEIGHT_OTHER       = 0x01,
    DMI_SLOT_HEIGHT_UNKNOWN     = 0x02,
    DMI_SLOT_HEIGHT_FULL        = 0x03,
    DMI_SLOT_HEIGHT_LOW_PROFILE = 0x04,
} dmi_slot_height_t;

const char *dmi_slot_height_name(dmi_slot_height_t value);
----

== Description

The `dmi_slot_height_t` enumeration tells the height of the tallest card a
system slot takes, and is the type of the `height` field of `dmi_slot_t`,
present since SMBIOS 3.5.

The `dmi_slot_height_name` function returns the name of a value, as the command
line tool shows it.

=== Values

`DMI_SLOT_HEIGHT_UNSPEC`::
Not applicable, or not given.

`DMI_SLOT_HEIGHT_OTHER`::
Other.

`DMI_SLOT_HEIGHT_UNKNOWN`::
Unknown.

`DMI_SLOT_HEIGHT_FULL`::
Full-height cards.

`DMI_SLOT_HEIGHT_LOW_PROFILE`::
Low-profile cards.

== Return value

`dmi_slot_height_name` returns the name of the value, or `nullptr` if the value
has no name. The name is in English, or translated to the locale set with
`dmi_set_locale` when the library is built with localization support and has a
translation of it. The string must not be modified or freed; a translated one
stays valid until the locale is changed.

== Errors

None.

== See also

`dmi_slot`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 3.5 or newer.
