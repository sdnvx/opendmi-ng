== Name

dmi_slot_usage, dmi_slot_usage_name - system slot usage values

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/slot.h>

typedef enum dmi_slot_usage {
    DMI_SLOT_USAGE_UNSPEC      = 0x00,
    DMI_SLOT_USAGE_OTHER       = 0x01,
    DMI_SLOT_USAGE_UNKNOWN     = 0x02,
    DMI_SLOT_USAGE_AVAILABLE   = 0x03,
    DMI_SLOT_USAGE_IN_USE      = 0x04,
    DMI_SLOT_USAGE_UNAVAILABLE = 0x05,
} dmi_slot_usage_t;

const char *dmi_slot_usage_name(dmi_slot_usage_t value);
----

== Description

The `dmi_slot_usage_t` enumeration tells whether a system slot is in use, and
is the type of the `usage` field of `dmi_slot_t`.

The `dmi_slot_usage_name` function returns the name of a value, as the command
line tool shows it.

=== Values

`DMI_SLOT_USAGE_UNSPEC`::
Unspecified.

`DMI_SLOT_USAGE_OTHER`::
Other.

`DMI_SLOT_USAGE_UNKNOWN`::
Unknown.

`DMI_SLOT_USAGE_AVAILABLE`::
Free.

`DMI_SLOT_USAGE_IN_USE`::
In use.

`DMI_SLOT_USAGE_UNAVAILABLE`::
Not usable, e.g. wired to a processor socket which is empty.

== Return value

`dmi_slot_usage_name` returns the name of the value, or `nullptr` if the value
has no name. The name is in English, or translated to the locale set with
`dmi_set_locale` when the library is built with localization support and has a
translation of it. The string must not be modified or freed; a translated one
stays valid until the locale is changed.

== Errors

None.

== See also

`dmi_slot`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.0 or newer.
