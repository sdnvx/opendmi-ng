== Name

dmi_encoder_entity - get the structure being encoded.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/encoder.h>

const dmi_entity_t *dmi_encoder_entity(const dmi_encoder_t *encoder);
----

== Description

The `dmi_encoder_entity` function returns the structure the encoder is
writing, so that an encoding handler reaches it without being handed it
separately.

=== Parameters

`encoder`::
Encoder to query.

== Return value

Structure being encoded, or `nullptr` if `encoder` is `nullptr`.
