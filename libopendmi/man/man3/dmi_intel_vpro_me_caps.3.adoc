== Name

dmi_intel_vpro_me_caps - Intel vPro capabilities of the Management Engine firmware

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/intel/vpro.h>

typedef union dmi_intel_vpro_me_caps {
    dmi_dword_t __value;
    struct {
        dmi_dword_t is_me_enabled    : 1;
        dmi_dword_t is_qst_supported : 1;
        dmi_dword_t is_asf_supported : 1;
        dmi_dword_t is_amt_supported : 1;
        dmi_dword_t __reserved_1     : 1;
        dmi_dword_t is_sbt_supported : 1;
        dmi_dword_t is_l3_supported  : 1;
        dmi_dword_t __reserved_2     : 25;
    };
} dmi_intel_vpro_me_caps_t;
----

== Description

The `dmi_intel_vpro_me_caps_t` union holds the capabilities of the Management Engine firmware, as Intel vPro information gives them. It is the type of the `me_capabilities` field of `dmi_intel_vpro_t`.

The union is packed into a double word: the bits can be read either one by
one, as bit fields, or all together, as `__value`.

=== Fields

`__value`::
All the bits, as the double word the structure carries them in,
`is_me_enabled` being bit 0.

`is_me_enabled`::
Set if the Management Engine is enabled.

`is_qst_supported`::
Set if the firmware supports Quiet System Technology (QST).

`is_asf_supported`::
Set if the firmware supports Alert Standard Format (ASF).

`is_amt_supported`::
Set if the firmware supports Active Management Technology (AMT).

`__reserved_1`::
Reserved bit, zero.

`is_sbt_supported`::
Set if the firmware supports Small Business Technology (SBT).

`is_l3_supported`::
Set if the firmware supports the level III manageability.

`__reserved_2`::
Bits Intel reserves. The newer firmware sets some of them, e.g. bits 13 to
15, whose meaning is not established.

== See also

`dmi_intel_vpro`(3)

== Standards

Not part of the SMBIOS specification. Defined by Intel, as the vPro
verification table of the Intel AMT implementation and reference guide.
