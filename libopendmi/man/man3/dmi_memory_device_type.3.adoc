== Synopsis

== Description

The `dmi_memory_device_type_t` enumeration tells the type of memory a memory
device is made of, and is the type of the `memory_type` field of
`dmi_memory_device_t`. The values 0x15 to 0x17 are reserved; the hidden
enumerators `__DMI_MEMORY_DEVICE_TYPE_UNASSIGNED_START` and
`__DMI_MEMORY_DEVICE_TYPE_UNASSIGNED_END` bound them.

The `dmi_memory_device_type_name` function returns the name of a value, as the
command line tool shows it.

== Return value

`dmi_memory_device_type_name` returns the name of the value, or `nullptr` if
the value has no name. The name is translated to the current locale when the
library is built with localization support and has a translation for it, and
is in English otherwise. The string is owned by the library and must not be
modified or freed.

== Errors

None.
