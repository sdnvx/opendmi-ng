== Name

dmi_cache_location, dmi_cache_location_name - cache locations

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/cache.h>

typedef enum dmi_cache_location {
    DMI_CACHE_LOCATION_INTERNAL = 0x00,
    DMI_CACHE_LOCATION_EXTERNAL = 0x01,
    DMI_CACHE_LOCATION_RESERVED = 0x02,
    DMI_CACHE_LOCATION_UNKNOWN  = 0x03,
} dmi_cache_location_t;

const char *dmi_cache_location_name(dmi_cache_location_t value);
----

== Description

The `dmi_cache_location_t` enumeration tells where a cache is, relative to the
processor module, and is the type of the `location` field of `dmi_cache_t`.

The `dmi_cache_location_name` function returns the printable name of a value,
as the command line tool shows it. The name is translated to the locale set
with `dmi_set_locale`, when the library is built with ICU4C support and has a
translation of it.

=== Values

`DMI_CACHE_LOCATION_INTERNAL`::
Internal to the processor module.

`DMI_CACHE_LOCATION_EXTERNAL`::
External to the processor module.

`DMI_CACHE_LOCATION_RESERVED`::
Reserved by the specification.

`DMI_CACHE_LOCATION_UNKNOWN`::
Unknown location.

== Return value

`dmi_cache_location_name` returns the name of the value, or `nullptr` if the
value has no name. The name is a static string, which must not be modified or
freed.

== Errors

None.

== See also

`dmi_cache`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.0 or newer.
