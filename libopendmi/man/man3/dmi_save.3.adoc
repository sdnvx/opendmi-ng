== Name

dmi_save - write the SMBIOS data of a context into a dump file.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/context.h>

bool dmi_save(dmi_context_t *context, const char *path, bool overwrite);
----

== Description

The `dmi_save` function writes the SMBIOS data of an open context into a
dump file, which `dmi_load`(3) reads back.

The dump is interchangeable with the ones `dmidecode --dump-bin` writes: the
entry point, padded with zeros to the largest size of an entry point,
followed by the table. The table is written the way it has been read, and
the address of the table the entry point holds is set to its offset within
the file. A context read on a platform which gives no access to the entry
point has none, and a 64-bit entry point is made up for it.

An existing file is replaced only when `overwrite` is `true`. A regular file
the dump has failed to be written into is removed, so that no incomplete
dump is left behind.

=== Parameters

`context`::
Open context to save.

`path`::
Path to the dump file.

`overwrite`::
Replace the file if it exists, rather than failing.

== Return value

Returns `true` if the dump has been written, and `false` otherwise.

== Errors

`DMI_ERROR_NULL_ARGUMENT`::
Path is `nullptr`.

`DMI_ERROR_INVALID_STATE`::
Context is not open.

`DMI_ERROR_INVALID_EPS_LENGTH`::
Entry point is longer than an entry point can be.

`DMI_ERROR_FILE_OPEN`::
File cannot be created, or exists and `overwrite` is `false`.

`DMI_ERROR_FILE_WRITE`::
File cannot be written.
