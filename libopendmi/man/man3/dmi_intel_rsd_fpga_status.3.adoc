== Name

dmi_intel_rsd_fpga_status, dmi_intel_rsd_fpga_status_name - Intel RSD FPGA
status values

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/intel/rsd-fpga.h>

typedef enum dmi_intel_rsd_fpga_status {
    DMI_INTEL_RSD_FPGA_STATUS_DISABLED = 0x00,
    DMI_INTEL_RSD_FPGA_STATUS_ENABLED  = 0x01,
} dmi_intel_rsd_fpga_status_t;

const char *dmi_intel_rsd_fpga_status_name(dmi_intel_rsd_fpga_status_t value);
----

== Description

The `dmi_intel_rsd_fpga_status_t` enumeration tells whether an FPGA is in use,
and is the type of the `status` field of `dmi_intel_rsd_fpga_t`.

The `dmi_intel_rsd_fpga_status_name` function returns the printable name of a
value, as the command line tool shows it. The name is translated to the locale
set with `dmi_set_locale`, when the library is built with ICU4C support and has
a translation of it.

=== Values

`DMI_INTEL_RSD_FPGA_STATUS_DISABLED`::
The FPGA is disabled.

`DMI_INTEL_RSD_FPGA_STATUS_ENABLED`::
The FPGA is enabled.

== Return value

`dmi_intel_rsd_fpga_status_name` returns the name of the value, or `nullptr` if
the value has no name. The name is a static string, which must not be modified
or freed.

== Errors

None.

== See also

`dmi_intel_rsd_fpga`(3)

== Standards

Not part of the SMBIOS specification. Defined by Intel Rack Scale Design (RSD)
firmware.
