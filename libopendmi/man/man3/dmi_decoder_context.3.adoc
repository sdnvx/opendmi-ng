== Name

dmi_decoder_context - get the context the structure being decoded belongs to.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/decoder.h>

dmi_context_t *dmi_decoder_context(const dmi_decoder_t *decoder);
----

== Description

The `dmi_decoder_context` function returns the context of the structure the
decoder is reading, which is where its errors are raised and its memory
comes from.

=== Parameters

`decoder`::
Decoder to query.

== Return value

Context of the structure, or `nullptr` if `decoder` is `nullptr`.
