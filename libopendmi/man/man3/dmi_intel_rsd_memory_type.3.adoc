== Name

dmi_intel_rsd_memory_type, dmi_intel_rsd_memory_type_name - Intel RSD memory
types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/intel/rsd-memory-device.h>

typedef enum dmi_intel_rsd_memory_type {
    DMI_INTEL_RSD_MEMORY_TYPE_DIMM     = 0x00,
    DMI_INTEL_RSD_MEMORY_TYPE_NVDIMM_N = 0x01,
    DMI_INTEL_RSD_MEMORY_TYPE_NVDIMM_F = 0x02,
    DMI_INTEL_RSD_MEMORY_TYPE_NVDIMM_P = 0x03
} dmi_intel_rsd_memory_type_t;

const char *dmi_intel_rsd_memory_type_name(dmi_intel_rsd_memory_type_t value);
----

== Description

The `dmi_intel_rsd_memory_type_t` enumeration tells the kind of a memory
module, volatile or persistent, and is the type of the `memory_type` field of
`dmi_intel_rsd_memory_device_t`.

The `dmi_intel_rsd_memory_type_name` function returns the name of a value, as
the command line tool shows it.

=== Values

`DMI_INTEL_RSD_MEMORY_TYPE_DIMM`::
Conventional volatile DIMM.

`DMI_INTEL_RSD_MEMORY_TYPE_NVDIMM_N`::
NVDIMM-N: persistent memory accessed by bytes.

`DMI_INTEL_RSD_MEMORY_TYPE_NVDIMM_F`::
NVDIMM-F: persistent memory accessed by blocks.

`DMI_INTEL_RSD_MEMORY_TYPE_NVDIMM_P`::
NVDIMM-P persistent memory.

== Return value

`dmi_intel_rsd_memory_type_name` returns the name of the value, translated to
the language of the current locale when a translation is available, or
`nullptr` if the value has no name. The returned string must not be modified or
freed.

== Errors

None.

== See also

`dmi_intel_rsd_memory_device`(3), `dmi_intel_rsd_memory_media`(3)

== Standards

Not part of the SMBIOS specification. Defined by Intel Rack Scale Design (RSD)
firmware.
