== Name

dmi_hpe_tm_presence, dmi_hpe_tm_presence_name - HP/HPE trusted module presence

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/trusted-module.h>

typedef enum dmi_hpe_tm_presence {
    DMI_HPE_TM_PRESENCE_ABSENT   = 0x00,
    DMI_HPE_TM_PRESENCE_ENABLED  = 0x01,
    DMI_HPE_TM_PRESENCE_DISABLED = 0x02
} dmi_hpe_tm_presence_t;

const char *dmi_hpe_tm_presence_name(dmi_hpe_tm_presence_t value);
----

== Description

The `dmi_hpe_tm_presence_t` enumeration tells whether a trusted module is
present and enabled, and is the type of the `presence` field of
`dmi_hpe_trusted_module_t`.

The `dmi_hpe_tm_presence_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_HPE_TM_PRESENCE_ABSENT`::
Not present.

`DMI_HPE_TM_PRESENCE_ENABLED`::
Present and enabled.

`DMI_HPE_TM_PRESENCE_DISABLED`::
Present and disabled.

== Return value

`dmi_hpe_tm_presence_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_trusted_module`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
