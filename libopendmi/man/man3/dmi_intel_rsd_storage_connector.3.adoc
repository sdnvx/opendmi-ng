== Name

dmi_intel_rsd_storage_connector, dmi_intel_rsd_storage_connector_name - Intel
RSD storage connector types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/intel/rsd-storage-device.h>

typedef enum dmi_intel_rsd_storage_connector {
    DMI_INTEL_RSD_STORAGE_CONNECTOR_UNKNOWN = 0x00,
    DMI_INTEL_RSD_STORAGE_CONNECTOR_SATA    = 0x01,
    DMI_INTEL_RSD_STORAGE_CONNECTOR_SAS     = 0x02,
    DMI_INTEL_RSD_STORAGE_CONNECTOR_PCIE    = 0x03,
    DMI_INTEL_RSD_STORAGE_CONNECTOR_M2      = 0x04,
    DMI_INTEL_RSD_STORAGE_CONNECTOR_USB     = 0x05,
    DMI_INTEL_RSD_STORAGE_CONNECTOR_U2      = 0x06
} dmi_intel_rsd_storage_connector_t;

const char *dmi_intel_rsd_storage_connector_name(
        dmi_intel_rsd_storage_connector_t value);
----

== Description

The `dmi_intel_rsd_storage_connector_t` enumeration tells the connector a
storage device is attached with, and is the type of the `connector` field of
`dmi_intel_rsd_storage_device_t`.

The `dmi_intel_rsd_storage_connector_name` function returns the name of a
value, as the command line tool shows it.

=== Values

`DMI_INTEL_RSD_STORAGE_CONNECTOR_UNKNOWN`::
Unknown.

`DMI_INTEL_RSD_STORAGE_CONNECTOR_SATA`::
SATA.

`DMI_INTEL_RSD_STORAGE_CONNECTOR_SAS`::
SAS.

`DMI_INTEL_RSD_STORAGE_CONNECTOR_PCIE`::
PCIe.

`DMI_INTEL_RSD_STORAGE_CONNECTOR_M2`::
M.2.

`DMI_INTEL_RSD_STORAGE_CONNECTOR_USB`::
USB.

`DMI_INTEL_RSD_STORAGE_CONNECTOR_U2`::
U.2.

== Return value

`dmi_intel_rsd_storage_connector_name` returns the name of the value,
translated to the language of the current locale when a translation is
available, or `nullptr` if the value has no name. The returned string must not
be modified or freed.

== Errors

None.

== See also

`dmi_intel_rsd_storage_device`(3), `dmi_intel_rsd_storage_proto`(3),
`dmi_intel_rsd_storage_device_type`(3)

== Standards

Not part of the SMBIOS specification. Defined by Intel Rack Scale Design (RSD)
firmware.
