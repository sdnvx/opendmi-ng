== Name

dmi_hpe_tm_fips, dmi_hpe_tm_fips_name - HP/HPE trusted module FIPS certifications

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/trusted-module.h>

typedef enum dmi_hpe_tm_fips {
    DMI_HPE_TM_FIPS_UNSPEC        = 0x00,
    DMI_HPE_TM_FIPS_NOT_CERTIFIED = 0x01,
    DMI_HPE_TM_FIPS_CERTIFIED     = 0x02
} dmi_hpe_tm_fips_t;

const char *dmi_hpe_tm_fips_name(dmi_hpe_tm_fips_t value);
----

== Description

The `dmi_hpe_tm_fips_t` enumeration tells whether a trusted module is FIPS
certified, and is the type of the `fips` field of `dmi_hpe_trusted_module_t`.

The `dmi_hpe_tm_fips_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_HPE_TM_FIPS_UNSPEC`::
Not specified.

`DMI_HPE_TM_FIPS_NOT_CERTIFIED`::
Not FIPS certified.

`DMI_HPE_TM_FIPS_CERTIFIED`::
FIPS certified.

== Return value

`dmi_hpe_tm_fips_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_trusted_module`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
