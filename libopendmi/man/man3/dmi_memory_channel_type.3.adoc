== Name

dmi_memory_channel_type, dmi_memory_channel_type_name - memory channel types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/memory-channel.h>

typedef enum dmi_memory_channel_type {
    DMI_MEMORY_CHANNEL_TYPE_UNSPEC   = 0x00,
    DMI_MEMORY_CHANNEL_TYPE_OTHER    = 0x01,
    DMI_MEMORY_CHANNEL_TYPE_UNKNOWN  = 0x02,
    DMI_MEMORY_CHANNEL_TYPE_RAMBUS   = 0x03,
    DMI_MEMORY_CHANNEL_TYPE_SYNCLINK = 0x04,
} dmi_memory_channel_type_t;

const char *dmi_memory_channel_type_name(dmi_memory_channel_type_t value);
----

== Description

The `dmi_memory_channel_type_t` enumeration tells the type of memory of a
memory channel, and is the type of the `type` field of
`dmi_memory_channel_t`. The specification leaves these values to the DMTF.

The `dmi_memory_channel_type_name` function returns the name of a value, as
the command line tool shows it.

=== Values

`DMI_MEMORY_CHANNEL_TYPE_UNSPEC`::
Unspecified. Not defined by the specification.

`DMI_MEMORY_CHANNEL_TYPE_OTHER`::
Other.

`DMI_MEMORY_CHANNEL_TYPE_UNKNOWN`::
Unknown.

`DMI_MEMORY_CHANNEL_TYPE_RAMBUS`::
Rambus.

`DMI_MEMORY_CHANNEL_TYPE_SYNCLINK`::
SyncLink.

== Return value

`dmi_memory_channel_type_name` returns the name of the value, or `nullptr` if
the value has no name. The name is translated to the language of the current
locale when the library is built with localization support and has a
translation for it, and is in English otherwise. The string is owned by the
library and must not be modified or freed.

== Errors

None.

== See also

`dmi_memory_channel`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.3 or newer.
