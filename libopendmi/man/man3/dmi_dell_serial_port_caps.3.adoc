== Name

dmi_dell_serial_port_caps, dmi_dell_serial_port_caps_name - Dell serial port
capabilities

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/dell/serial-port.h>

typedef enum dmi_dell_serial_port_caps {
    DMI_DELL_SERIAL_PORT_CAPS_UNSPEC    = 0x00,
    DMI_DELL_SERIAL_PORT_CAPS_OTHER     = 0x01,
    DMI_DELL_SERIAL_PORT_CAPS_UNKNOWN   = 0x02,
    DMI_DELL_SERIAL_PORT_CAPS_XT_AT     = 0x03,
    DMI_DELL_SERIAL_PORT_CAPS_16450     = 0x04,
    DMI_DELL_SERIAL_PORT_CAPS_16550     = 0x05,
    DMI_DELL_SERIAL_PORT_CAPS_16550A    = 0x06,
    DMI_DELL_SERIAL_PORT_CAPS_8251      = 0xA0,
    DMI_DELL_SERIAL_PORT_CAPS_8251_FIFO = 0xA1,
} dmi_dell_serial_port_caps_t;

const char *dmi_dell_serial_port_caps_name(dmi_dell_serial_port_caps_t value);
----

== Description

The `dmi_dell_serial_port_caps_t` enumeration tells which serial controller a
Dell serial port is compatible with, and is the type of the `capabilities`
field of `dmi_dell_serial_port_t`. Unlike the capabilities of a parallel port,
it is a single value, not a set of bits.

The `dmi_dell_serial_port_caps_name` function returns the name of a value, as
the command line tool shows it. The name is in English, or in the language of
the locale the library is set to when it has a translation of the name.

=== Values

`DMI_DELL_SERIAL_PORT_CAPS_UNSPEC`::
Unspecified. The firmware does not define the value 0.

`DMI_DELL_SERIAL_PORT_CAPS_OTHER`::
Other.

`DMI_DELL_SERIAL_PORT_CAPS_UNKNOWN`::
Unknown.

`DMI_DELL_SERIAL_PORT_CAPS_XT_AT`::
XT/AT compatible.

`DMI_DELL_SERIAL_PORT_CAPS_16450`::
16450 compatible.

`DMI_DELL_SERIAL_PORT_CAPS_16550`::
16550 compatible.

`DMI_DELL_SERIAL_PORT_CAPS_16550A`::
16550A compatible.

`DMI_DELL_SERIAL_PORT_CAPS_8251`::
8251 compatible.

`DMI_DELL_SERIAL_PORT_CAPS_8251_FIFO`::
8251 FIFO compatible.

== Return value

`dmi_dell_serial_port_caps_name` returns the name of the value, a constant
string which must not be modified or freed, or `nullptr` if the value has no
name, e.g. a value out of the range of the enumeration.

== Errors

None.

== See also

`dmi_dell_serial_port`(3), `dmi_dell_serial_port_connector_type`(3)

== Standards

Not part of the SMBIOS specification. Defined by Dell firmware, see the Dell
Serial Port (Type 210) chapter of the reference manual.
