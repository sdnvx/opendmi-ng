== Name

dmi_reader_is_done - check whether all data in a reader has been consumed.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/reader.h>

bool dmi_reader_is_done(const dmi_reader_t *reader);
----

== Description

The `dmi_reader_is_done` function checks whether the reader cursor has
reached the end of the range.

=== Parameters

`reader`::
Reader to check.

== Return value

`true` if there are no remaining bytes to read, `false` otherwise.

== Errors

None.

== See also

`dmi_reader_remaining`(3),
`dmi_reader_has`(3),
