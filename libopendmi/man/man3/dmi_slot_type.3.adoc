== Description

The `dmi_slot_type_t` enumeration tells the bus or the form factor of a system
slot, and is the type of the `type` field of `dmi_slot_t`. The specification
assigns no values from `0x29` to `0x2F`, from `0x31` to `0x9F`, `0xB7`, and
above `0xC6`.

PCI Express types which give a generation only are meant for slots whose
physical width is their electrical width, the `bus_width` field of `dmi_slot_t`
giving both. Types which also give a width are meant for slots wider than their
electrical width: the type gives the physical width, and `bus_width` the
electrical one.

The `dmi_slot_type_name` function returns the name of a value, as the command
line tool shows it.

== Return value

`dmi_slot_type_name` returns the name of the value, or `nullptr` if the value
has no name. The name is in English, or translated to the locale set with
`dmi_set_locale` when the library is built with localization support and has a
translation of it. The string must not be modified or freed; a translated one
stays valid until the locale is changed.

== Errors

None.
