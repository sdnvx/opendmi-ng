== Name

dmi_cache_type, dmi_cache_type_name - cache types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/cache.h>

typedef enum dmi_cache_type {
    DMI_CACHE_TYPE_UNSPEC      = 0x00,
    DMI_CACHE_TYPE_OTHER       = 0x01,
    DMI_CACHE_TYPE_UNKNOWN     = 0x02,
    DMI_CACHE_TYPE_INSTRUCTION = 0x03,
    DMI_CACHE_TYPE_DATA        = 0x04,
    DMI_CACHE_TYPE_UNIFIED     = 0x05,
} dmi_cache_type_t;

const char *dmi_cache_type_name(dmi_cache_type_t value);
----

== Description

The `dmi_cache_type_t` enumeration tells what a cache holds: instructions,
data, or both, and is the type of the `type` field of `dmi_cache_t`. A level
of cache is described as unified when its caches hold a mix of instructions
and data.

The `dmi_cache_type_name` function returns the printable name of a value, as
the command line tool shows it. The name is translated to the locale set with
`dmi_set_locale`, when the library is built with ICU4C support and has a
translation of it.

=== Values

`DMI_CACHE_TYPE_UNSPEC`::
Unspecified: the structure predates SMBIOS 2.1, or leaves the field at zero.

`DMI_CACHE_TYPE_OTHER`::
Other type.

`DMI_CACHE_TYPE_UNKNOWN`::
Unknown type.

`DMI_CACHE_TYPE_INSTRUCTION`::
Instruction cache.

`DMI_CACHE_TYPE_DATA`::
Data cache.

`DMI_CACHE_TYPE_UNIFIED`::
Unified cache, holding both instructions and data.

== Return value

`dmi_cache_type_name` returns the name of the value, or `nullptr` if the value
has no name. The name is a static string, which must not be modified or freed.

== Errors

None.

== See also

`dmi_cache`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.1 or newer.
