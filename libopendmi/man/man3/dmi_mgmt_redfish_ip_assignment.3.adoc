== Name

dmi_mgmt_redfish_ip_assignment, dmi_mgmt_redfish_ip_assignment_name - Redfish
IP address assignment and discovery types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/mgmt-controller.h>

typedef enum dmi_mgmt_redfish_ip_assignment {
    DMI_MGMT_REDFISH_IP_ASSIGNMENT_UNKNOWN        = 0x00,
    DMI_MGMT_REDFISH_IP_ASSIGNMENT_STATIC         = 0x01,
    DMI_MGMT_REDFISH_IP_ASSIGNMENT_DHCP           = 0x02,
    DMI_MGMT_REDFISH_IP_ASSIGNMENT_AUTO_CONFIGURE = 0x03,
    DMI_MGMT_REDFISH_IP_ASSIGNMENT_HOST_SELECTED  = 0x04
} dmi_mgmt_redfish_ip_assignment_t;

const char *dmi_mgmt_redfish_ip_assignment_name(
        dmi_mgmt_redfish_ip_assignment_t value);
----

== Description

The `dmi_mgmt_redfish_ip_assignment_t` enumeration tells how the host gets its
IP address on a Redfish host interface, and how it finds the IP address of the
Redfish service. It is the type of the `host_ip_assignment` and
`service_ip_discovery` fields of `dmi_mgmt_redfish_over_ip_t`. The values the
enumeration does not name are reserved.

The `dmi_mgmt_redfish_ip_assignment_name` function returns the printable name
of a value, as the command line tool shows it. The name is translated to the
locale set with `dmi_set_locale`, when the library is built with ICU4C support
and has a translation of it.

=== Values

`DMI_MGMT_REDFISH_IP_ASSIGNMENT_UNKNOWN`::
Unknown.

`DMI_MGMT_REDFISH_IP_ASSIGNMENT_STATIC`::
Static: the address is the one the record gives.

`DMI_MGMT_REDFISH_IP_ASSIGNMENT_DHCP`::
The address is obtained with DHCP.

`DMI_MGMT_REDFISH_IP_ASSIGNMENT_AUTO_CONFIGURE`::
The address is configured automatically.

`DMI_MGMT_REDFISH_IP_ASSIGNMENT_HOST_SELECTED`::
The address is selected by the host.

== Return value

`dmi_mgmt_redfish_ip_assignment_name` returns the name of the value, or
`nullptr` if the value has no name. The name is a static string, which must not
be modified or freed.

== Errors

None.

== See also

`dmi_mgmt_redfish_over_ip`(3)

== Standards

DMTF Redfish Host Interface Specification (DSP0270), which defines this data of
the management controller host interface structure (type 42) of the DMTF SMBIOS
Specification (DSP0134).
