== Name

dmi_hpe_usb_hub_proto, dmi_hpe_usb_hub_proto_name - USB hub protocols

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/usb-device.h>

typedef enum dmi_hpe_usb_hub_proto {
    DMI_HPE_USB_HUB_PROTO_FULL_SPEED = 0x00,
    DMI_HPE_USB_HUB_PROTO_SINGLE_TT  = 0x01,
    DMI_HPE_USB_HUB_PROTO_MULTI_TT   = 0x02
} dmi_hpe_usb_hub_proto_t;

const char *dmi_hpe_usb_hub_proto_name(
        dmi_hpe_usb_hub_proto_t value);
----

== Description

The `dmi_hpe_usb_hub_proto_t` enumeration tells the speed and the transaction
translators of a USB hub, and names the `usb_protocol` field of
`dmi_hpe_usb_device_t` for the devices of the hub class (0x09).

The `dmi_hpe_usb_hub_proto_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_HPE_USB_HUB_PROTO_FULL_SPEED`::
Full-speed hub.

`DMI_HPE_USB_HUB_PROTO_SINGLE_TT`::
Hi-speed hub with a single transaction translator.

`DMI_HPE_USB_HUB_PROTO_MULTI_TT`::
Hi-speed hub with multiple transaction translators.

== Return value

`dmi_hpe_usb_hub_proto_name` returns the name of the value, translated to the
language of the current locale when a translation is available, or `nullptr` if
the value has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_usb_device`(3)

== Standards

The codes are the ones the USB Implementers Forum defines for the class, as
dmidecode names them. The structure is not part of the SMBIOS specification: it
is defined by HP and HPE for their servers, and its layout is the one dmidecode
documents.
