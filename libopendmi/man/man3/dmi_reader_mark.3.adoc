== Name

dmi_reader_mark - take a mark of the current reader position.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/reader.h>

dmi_reader_mark_t dmi_reader_mark(const dmi_reader_t *reader);
----

== Description

The `dmi_reader_mark` function takes a mark of the current position of the
reader cursor, which names a place to come back to without counting the bytes
read in between.

Marks are values rather than handles: they are copied, they nest without any
bookkeeping, and they need no release. A mark stays valid for as long as the
reader reads the same entity, and a mark taken from another reader is rejected
by the functions which take one.

This is what records of a declared length need. The beginning of the record is
marked, the fields the record is known to hold are read, and the next record is
found by advancing the length of the record from the mark, so that the code
does not count the bytes it has read:

[source, c]
----
dmi_reader_mark_t start = dmi_reader_mark(reader);

bool status =
    dmi_reader_get(reader, dmi_byte_t, &record->type) and
    dmi_reader_get(reader, dmi_byte_t, &record->format) and
    dmi_reader_skip_ex(reader, start, record_length);
----

=== Parameters

`reader`::
Reader to mark.

== Return value

Returns a mark of the current position. A mark taken from a `nullptr` reader
is rejected by `dmi_reader_rewind`(3) and `dmi_reader_skip_ex`(3).
