== Name

dmi_mgmt_proto, dmi_mgmt_proto_name - management controller host interface
protocols

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/mgmt-controller.h>

typedef enum dmi_mgmt_proto {
    DMI_MGMT_PROTO_IPMI            = 0x02,
    DMI_MGMT_PROTO_MCTP            = 0x03,
    DMI_MGMT_PROTO_REDFISH_OVER_IP = 0x04,
    DMI_MGMT_PROTO_OEM             = 0xF0
} dmi_mgmt_proto_t;

const char *dmi_mgmt_proto_name(dmi_mgmt_proto_t value);
----

== Description

The `dmi_mgmt_proto_t` enumeration tells the protocol a protocol record of a
management controller host interface describes, and is the type of the `type`
field of `dmi_mgmt_proto_record_t`. Every value the enumeration does not name
is reserved, and the field holds it as the structure carries it.

The `dmi_mgmt_proto_name` function returns the printable name of a value, as
the command line tool shows it. The name is translated to the locale set with
`dmi_set_locale`, when the library is built with ICU4C support and has a
translation of it.

=== Values

`DMI_MGMT_PROTO_IPMI`::
Intelligent Platform Management Interface (IPMI).

`DMI_MGMT_PROTO_MCTP`::
Management Component Transport Protocol (MCTP), defined by DSP0236.

`DMI_MGMT_PROTO_REDFISH_OVER_IP`::
Redfish over IP, defined by the Redfish host interface specification (DSP0270).
Its data is decoded into `dmi_mgmt_redfish_over_ip_t`.

`DMI_MGMT_PROTO_OEM`::
OEM-defined protocol.

== Return value

`dmi_mgmt_proto_name` returns the name of the value, or `nullptr` if the value
has no name. The name is a static string, which must not be modified or freed.

== Errors

None.

== See also

`dmi_mgmt_proto_record`(3), `dmi_mgmt_redfish_over_ip`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 3.2 or newer.
