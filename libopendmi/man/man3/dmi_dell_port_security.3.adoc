ifdef::backend-manpage[]
== Name

dmi_dell_port_security, dmi_dell_port_security_name - Dell port security
settings

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/dell/common.h>

typedef enum dmi_dell_port_security {
    DMI_DELL_PORT_SECURITY_UNSPEC            = 0x00,
    DMI_DELL_PORT_SECURITY_OTHER             = 0x01,
    DMI_DELL_PORT_SECURITY_UNKNOWN           = 0x02,
    DMI_DELL_PORT_SECURITY_NONE              = 0x03,
    DMI_DELL_PORT_SECURITY_EXT_IFACE_LOCKED  = 0x04,
    DMI_DELL_PORT_SECURITY_EXT_IFACE_ENABLED = 0x05,
    DMI_DELL_PORT_SECURITY_BOOT_BYPASS       = 0x06,
} dmi_dell_port_security_t;

const char *dmi_dell_port_security_name(dmi_dell_port_security_t value);
----

== Description

The `dmi_dell_port_security_t` enumeration tells which security setting of the
firmware applies to a Dell port, and is the type of the `security` field of
`dmi_dell_parallel_port_t` and `dmi_dell_serial_port_t`.

The `dmi_dell_port_security_name` function returns the name of a value, as the
command line tool shows it. The name is in English, or in the language of the
locale the library is set to when it has a translation of the name.

=== Values

`DMI_DELL_PORT_SECURITY_UNSPEC`::
Unspecified. The firmware does not define the value 0.

`DMI_DELL_PORT_SECURITY_OTHER`::
Other setting.

`DMI_DELL_PORT_SECURITY_UNKNOWN`::
Unknown setting.

`DMI_DELL_PORT_SECURITY_NONE`::
No security setting applies to the port.

`DMI_DELL_PORT_SECURITY_EXT_IFACE_LOCKED`::
External interface of the port is locked out.

`DMI_DELL_PORT_SECURITY_EXT_IFACE_ENABLED`::
External interface of the port is enabled.

`DMI_DELL_PORT_SECURITY_BOOT_BYPASS`::
Boot-bypass.

== Return value

`dmi_dell_port_security_name` returns the name of the value, a constant string
which must not be modified or freed, or `nullptr` if the value has no name,
e.g. a value out of the range of the enumeration.

== Errors

None.

== See also

`dmi_dell_parallel_port`(3), `dmi_dell_serial_port`(3)

== Standards

Not part of the SMBIOS specification. Defined by Dell firmware, see the Dell
Parallel Port (Type 209) and Dell Serial Port (Type 210) chapters of the
reference manual.
