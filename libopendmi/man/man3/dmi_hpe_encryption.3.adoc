== Name

dmi_hpe_encryption, dmi_hpe_encryption_name - HP/HPE encryption statuses

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/common.h>

typedef enum dmi_hpe_encryption {
    DMI_HPE_ENCRYPTION_NONE        = 0x00,
    DMI_HPE_ENCRYPTION_ENCRYPTED   = 0x01,
    DMI_HPE_ENCRYPTION_UNKNOWN     = 0x02,
    DMI_HPE_ENCRYPTION_UNSUPPORTED = 0x03
} dmi_hpe_encryption_t;

const char *dmi_hpe_encryption_name(dmi_hpe_encryption_t value);
----

== Description

The `dmi_hpe_encryption_t` enumeration tells the encryption status of a memory
module or a drive, and is the type of the `encryption` field of
`dmi_hpe_dimm_attrs_t` and of `dmi_hpe_drive_t`.

The `dmi_hpe_encryption_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_HPE_ENCRYPTION_NONE`::
Not encrypted.

`DMI_HPE_ENCRYPTION_ENCRYPTED`::
Encrypted.

`DMI_HPE_ENCRYPTION_UNKNOWN`::
Unknown.

`DMI_HPE_ENCRYPTION_UNSUPPORTED`::
Not supported.

== Return value

`dmi_hpe_encryption_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_dimm_attrs`(3),
`dmi_hpe_drive`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
