== Name

dmi_writer_tell - return the current position of a writer cursor.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/writer.h>

size_t dmi_writer_tell(const dmi_writer_t *writer);
----

== Description

The `dmi_writer_tell` function returns the offset the next byte is written
at, counted from the beginning of the range, so marking a field right after
the call gives the offset of that field within the range.

=== Parameters

`writer`::
Writer to query.

== Return value

Offset the next byte is written at, counted from the beginning of the range,
or zero if `writer` is `nullptr`.

== Errors

None.
