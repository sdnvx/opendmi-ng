== Name

dmi_reader_tell - return the current position of a reader cursor.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/reader.h>

size_t dmi_reader_tell(const dmi_reader_t *reader);
----

== Description

The `dmi_reader_tell` function returns the offset of the next byte to be
read from the beginning of the range, so reading a field right after the
call gives the offset of that field within the range.

=== Parameters

`reader`::
Reader to query.

== Return value

Offset of the cursor from the beginning of the range, or zero if `reader` is
`nullptr`.
