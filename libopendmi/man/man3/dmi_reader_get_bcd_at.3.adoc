== Name

dmi_reader_get_bcd_at - read and decode a BCD-encoded value from the reader at a given offset.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/reader.h>

dmi_reader_get_bcd_at(reader, offset, type, pvalue)
----

== Description

The `dmi_reader_get_bcd_at` macro reads `sizeof(type)` bytes at `offset`
from the beginning of the entity body, decodes the value from BCD encoding
using `dmi_decode_bcd`, and stores the result in the variable pointed to by
`pvalue`. The reader cursor is not modified.

=== Parameters

`reader`::
Reader to read from.

`offset`::
Byte offset from the beginning of the entity body.

`type`::
Wire-format type to read (e.g., `dmi_byte_t`).

`pvalue`::
Pointer to the variable that receives the decoded value.

== Return value

Returns `true` on success, `false` if the requested range exceeds the reader
bounds.
