== Name

dmi_intel_rsd_tpm_status, dmi_intel_rsd_tpm_status_name - Intel RSD TPM status
values

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/intel-rsd/tpm.h>

typedef enum dmi_intel_rsd_tpm_status {
    DMI_INTEL_RSD_TPM_STATUS_DISABLED = 0x00,
    DMI_INTEL_RSD_TPM_STATUS_ENABLED  = 0x01,
} dmi_intel_rsd_tpm_status_t;

const char *dmi_intel_rsd_tpm_status_name(dmi_intel_rsd_tpm_status_t value);
----

== Description

The `dmi_intel_rsd_tpm_status_t` enumeration tells whether a Trusted Platform
Module (TPM) is enabled, and is the type of the `status` field of
`dmi_intel_rsd_tpm_t`.

The `dmi_intel_rsd_tpm_status_name` function returns the name of a value, as
the command line tool shows it.

=== Values

`DMI_INTEL_RSD_TPM_STATUS_DISABLED`::
The TPM is disabled.

`DMI_INTEL_RSD_TPM_STATUS_ENABLED`::
The TPM is enabled.

== Return value

`dmi_intel_rsd_tpm_status_name` returns the name of the value, translated to
the language of the current locale when a translation is available, or
`nullptr` if the value has no name. The returned string must not be modified or
freed.

== Errors

None.

== See also

`dmi_intel_rsd_tpm`(3)

== Standards

Not part of the SMBIOS specification. Defined by Intel Rack Scale Design (RSD)
firmware.
