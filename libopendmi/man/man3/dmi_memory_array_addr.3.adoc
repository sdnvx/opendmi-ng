== Name

dmi_memory_array_addr - memory array mapped address structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/memory-array-addr.h>

typedef struct dmi_memory_array_addr {
    uint64_t        start_addr;
    uint64_t        end_addr;
    uint64_t        range_size;
    dmi_handle_t    array_handle;
    dmi_entity_t   *array;
    unsigned short  partition_width;
} dmi_memory_array_addr_t;
----

== Description

The `dmi_memory_array_addr_t` structure holds the decoded memory array
mapped address structure (type 19) of SMBIOS: it maps one contiguous range
of physical addresses to a physical memory array. The table holds one such
structure for each range, and several ranges may map to the same array.
Since SMBIOS 2.3, a table must hold at least one of them.

The structure gives the addresses in kilobytes, or, since SMBIOS 2.7, in
bytes in extended fields for the ranges which do not fit; the decoder
converts both to bytes.

The structure is returned by `dmi_entity_info`(3) for the structures of type
`DMI_TYPE(MEMORY_ARRAY_ADDR)`, and lives as long as the context it has been
decoded in.

=== Fields

`start_addr`::
Physical address of the start of the range, in bytes.

`end_addr`::
Physical address of the last byte of the range. When the structure gives the
addresses in kilobytes, this is the last byte of the last kilobyte of the
range.

`range_size`::
Size of the range in bytes, computed from `start_addr` and `end_addr`,
whichever order they come in, both of which belong to the range.

`array_handle`::
Handle of the physical memory array structure (type 16) the range maps to.

`array`::
Entity of the physical memory array structure, set when the structures are
linked; `nullptr` if `array_handle` does not refer to a physical memory
array.

`partition_width`::
Number of memory devices which make up one row of memory for the partition
of addresses this structure defines.

== Examples

[source, c]
----
dmi_registry_t          *registry = dmi_get_registry(context);
dmi_entity_t            *entity   = dmi_registry_lookup_first(registry,
                                        DMI_TYPE(MEMORY_ARRAY_ADDR), false);
dmi_memory_array_addr_t *range    = dmi_entity_info(entity,
                                        DMI_TYPE(MEMORY_ARRAY_ADDR));

if (range != nullptr)
    printf("0x%llx-0x%llx, array 0x%04x\n",
           (unsigned long long)range->start_addr,
           (unsigned long long)range->end_addr,
           (unsigned)range->array_handle);
----
