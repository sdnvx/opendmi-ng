== Name

dmi_memory_device_tech, dmi_memory_device_tech_name - memory device technologies

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/memory-device.h>

typedef enum dmi_memory_device_tech {
    DMI_MEMORY_DEVICE_TECH_UNSPEC   = 0x00,
    DMI_MEMORY_DEVICE_TECH_OTHER    = 0x01,
    DMI_MEMORY_DEVICE_TECH_UNKNOWN  = 0x02,
    DMI_MEMORY_DEVICE_TECH_DRAM     = 0x03,
    DMI_MEMORY_DEVICE_TECH_NVDIMM_N = 0x04,
    DMI_MEMORY_DEVICE_TECH_NVDIMM_F = 0x05,
    DMI_MEMORY_DEVICE_TECH_NVDIMM_P = 0x06,
    DMI_MEMORY_DEVICE_TECH_OPTANE   = 0x07,
    DMI_MEMORY_DEVICE_TECH_MRDIMM   = 0x08
} dmi_memory_device_tech_t;

const char *dmi_memory_device_tech_name(dmi_memory_device_tech_t value);
----

== Description

The `dmi_memory_device_tech_t` enumeration tells the memory technology of a
memory device, volatile or persistent, and is the type of the `memory_tech`
field of `dmi_memory_device_t`, present since SMBIOS 3.2.

The `dmi_memory_device_tech_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_MEMORY_DEVICE_TECH_UNSPEC`::
Unspecified.

`DMI_MEMORY_DEVICE_TECH_OTHER`::
Other.

`DMI_MEMORY_DEVICE_TECH_UNKNOWN`::
Unknown.

`DMI_MEMORY_DEVICE_TECH_DRAM`::
DRAM.

`DMI_MEMORY_DEVICE_TECH_NVDIMM_N`::
NVDIMM-N.

`DMI_MEMORY_DEVICE_TECH_NVDIMM_F`::
NVDIMM-F.

`DMI_MEMORY_DEVICE_TECH_NVDIMM_P`::
NVDIMM-P.

`DMI_MEMORY_DEVICE_TECH_OPTANE`::
Intel Optane persistent memory.

`DMI_MEMORY_DEVICE_TECH_MRDIMM`::
MRDIMM. The specification deprecates this value in favour of
`DMI_MEMORY_DEVICE_TYPE_MRDIMM` of `dmi_memory_device_type`(3).

== Return value

`dmi_memory_device_tech_name` returns the name of the value, or `nullptr` if
the value has no name. The name is translated to the current locale when the
library is built with localization support and has a translation for it, and
is in English otherwise. The string is owned by the library and must not be
modified or freed.

== Errors

None.

== See also

`dmi_memory_device`(3), `dmi_memory_device_type`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 3.2 or newer.
