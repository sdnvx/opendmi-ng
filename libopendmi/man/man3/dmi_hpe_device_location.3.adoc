== Name

dmi_hpe_device_location, dmi_hpe_device_location_name - HP/HPE correlated device locations

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/device-correlation.h>

typedef enum dmi_hpe_device_location {
    DMI_HPE_DEVICE_LOCATION_UNKNOWN          = 0x00,
    DMI_HPE_DEVICE_LOCATION_EMBEDDED         = 0x01,
    DMI_HPE_DEVICE_LOCATION_ILO_MEDIA        = 0x02,
    DMI_HPE_DEVICE_LOCATION_FRONT_USB        = 0x03,
    DMI_HPE_DEVICE_LOCATION_REAR_USB         = 0x04,
    DMI_HPE_DEVICE_LOCATION_INTERNAL_USB     = 0x05,
    DMI_HPE_DEVICE_LOCATION_INTERNAL_SD      = 0x06,
    DMI_HPE_DEVICE_LOCATION_VIRTUAL_USB      = 0x07,
    DMI_HPE_DEVICE_LOCATION_EMBEDDED_SATA    = 0x08,
    DMI_HPE_DEVICE_LOCATION_EMBEDDED_ARRAY   = 0x09,
    DMI_HPE_DEVICE_LOCATION_PCI_SLOT         = 0x0A,
    DMI_HPE_DEVICE_LOCATION_RAM              = 0x0B,
    DMI_HPE_DEVICE_LOCATION_USB              = 0x0C,
    DMI_HPE_DEVICE_LOCATION_DYNAMIC_ARRAY    = 0x0D,
    DMI_HPE_DEVICE_LOCATION_URL              = 0x0E,
    DMI_HPE_DEVICE_LOCATION_NVME_BAY         = 0x0F,
    DMI_HPE_DEVICE_LOCATION_NVDIMM_PROCESSOR = 0x10,
    DMI_HPE_DEVICE_LOCATION_NVDIMM_BOARD     = 0x11,
    DMI_HPE_DEVICE_LOCATION_NVME_RISER       = 0x12,
    DMI_HPE_DEVICE_LOCATION_NVDIMM_NAMESPACE = 0x13,
    DMI_HPE_DEVICE_LOCATION_VROC_SATA        = 0x14,
    DMI_HPE_DEVICE_LOCATION_VROC_NVME        = 0x15
} dmi_hpe_device_location_t;

const char *dmi_hpe_device_location_name(dmi_hpe_device_location_t value);
----

== Description

The `dmi_hpe_device_location_t` enumeration tells the location of a device,
and is the type of the `device_location` field of
`dmi_hpe_device_correlation_t`. Other values may be found in the data, and are
kept as they are.

The `dmi_hpe_device_location_name` function returns the name of a value, as
the command line tool shows it.

=== Values

`DMI_HPE_DEVICE_LOCATION_UNKNOWN`::
Unknown.

`DMI_HPE_DEVICE_LOCATION_EMBEDDED`::
Embedded.

`DMI_HPE_DEVICE_LOCATION_ILO_MEDIA`::
iLO virtual media.

`DMI_HPE_DEVICE_LOCATION_FRONT_USB`::
Front USB port.

`DMI_HPE_DEVICE_LOCATION_REAR_USB`::
Rear USB port.

`DMI_HPE_DEVICE_LOCATION_INTERNAL_USB`::
Internal USB.

`DMI_HPE_DEVICE_LOCATION_INTERNAL_SD`::
Internal SD card.

`DMI_HPE_DEVICE_LOCATION_VIRTUAL_USB`::
Internal virtual USB (embedded NAND).

`DMI_HPE_DEVICE_LOCATION_EMBEDDED_SATA`::
Embedded SATA port.

`DMI_HPE_DEVICE_LOCATION_EMBEDDED_ARRAY`::
Embedded Smart Array.

`DMI_HPE_DEVICE_LOCATION_PCI_SLOT`::
PCI slot.

`DMI_HPE_DEVICE_LOCATION_RAM`::
RAM memory.

`DMI_HPE_DEVICE_LOCATION_USB`::
USB.

`DMI_HPE_DEVICE_LOCATION_DYNAMIC_ARRAY`::
Dynamic Smart Array controller.

`DMI_HPE_DEVICE_LOCATION_URL`::
URL.

`DMI_HPE_DEVICE_LOCATION_NVME_BAY`::
NVMe drive bay.

`DMI_HPE_DEVICE_LOCATION_NVDIMM_PROCESSOR`::
NVDIMM processor.

`DMI_HPE_DEVICE_LOCATION_NVDIMM_BOARD`::
NVDIMM board.

`DMI_HPE_DEVICE_LOCATION_NVME_RISER`::
NVMe riser.

`DMI_HPE_DEVICE_LOCATION_NVDIMM_NAMESPACE`::
NVDIMM namespace.

`DMI_HPE_DEVICE_LOCATION_VROC_SATA`::
VROC SATA.

`DMI_HPE_DEVICE_LOCATION_VROC_NVME`::
VROC NVMe.

== Return value

`dmi_hpe_device_location_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_device_correlation`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
