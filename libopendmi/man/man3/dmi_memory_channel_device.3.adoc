== Name

dmi_memory_channel_device - memory device of a memory channel

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/memory-channel.h>

typedef struct dmi_memory_channel_device {
    dmi_byte_t    load;
    dmi_handle_t  handle;
    dmi_entity_t *device;
} dmi_memory_channel_device_t;
----

== Description

The `dmi_memory_channel_device_t` structure describes one memory device
attached to a memory channel, and is the type of the elements of the
`devices` array of `dmi_memory_channel_t`.

=== Fields

`load`::
Load the memory device puts on the channel.

`handle`::
Handle of the memory device structure (type 17).

`device`::
Entity of the memory device structure, set when the structures are linked;
`nullptr` if `handle` does not refer to a memory device.

== See also

`dmi_memory_channel`(3), `dmi_memory_device`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.3 or newer.
