== Name

dmi_decoder_get - read and decode a value of a structure at the current position.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/decoder.h>

dmi_decoder_get(decoder, type, pvalue)
----

== Description

The `dmi_decoder_get` macro reads `sizeof(type)` bytes of the structure,
converts the value from SMBIOS wire format (little-endian) into host byte
order using `dmi_decode`, and stores the result in the variable pointed to by
`pvalue`. The cursor is advanced.

=== Parameters

`decoder`::
Decoder to read from.

`type`::
Wire-format type to read (e.g. `dmi_word_t`, `dmi_dword_t`).

`pvalue`::
Pointer to the variable that receives the decoded value.

== Return value

`true` on success, `false` if there are not enough bytes remaining.
