== Name

dmi_dell_value_format, dmi_dell_value_format_name - Dell protected value
formats

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/dell/common.h>

typedef enum dmi_dell_value_format {
    DMI_DELL_VALUE_FORMAT_SCAN_CODE    = 0x00,
    DMI_DELL_VALUE_FORMAT_ASCII        = 0x01,
    DMI_DELL_VALUE_FORMAT_SCAN_CODE_NS = 0x02,
    DMI_DELL_VALUE_FORMAT_ASCII_NS     = 0x03,
} dmi_dell_value_format_t;

const char *dmi_dell_value_format_name(dmi_dell_value_format_t value);
----

== Description

The `dmi_dell_value_format_t` enumeration tells how a protected value, such as
a password, is encoded in CMOS, and is the type of the `value_format` field of
`dmi_dell_protected_area_1_t` and `dmi_dell_protected_area_2_t`.

The `dmi_dell_value_format_name` function returns the printable name of a
value, as the command line tool shows it. The name is translated to the locale
set with `dmi_set_locale`, when the library is built with ICU4C support and has
a translation of it.

=== Values

`DMI_DELL_VALUE_FORMAT_SCAN_CODE`::
Alphanumeric value, stored as keyboard scan codes.

`DMI_DELL_VALUE_FORMAT_ASCII`::
Alphanumeric value, stored as ASCII characters.

`DMI_DELL_VALUE_FORMAT_SCAN_CODE_NS`::
Alphanumeric value, stored as keyboard scan codes, NS variant.

`DMI_DELL_VALUE_FORMAT_ASCII_NS`::
Alphanumeric value, stored as ASCII characters, NS variant.

== Return value

`dmi_dell_value_format_name` returns the name of the value, or `nullptr` if the
value has no name. The name is a static string, which must not be modified or
freed.

== Errors

None.

== See also

`dmi_dell_protected_area_1`(3), `dmi_dell_protected_area_2`(3)

== Standards

Not part of the SMBIOS specification. Defined by Dell firmware, see the Dell
Protected Area Type 2 (Type 214) chapter of the reference manual.
