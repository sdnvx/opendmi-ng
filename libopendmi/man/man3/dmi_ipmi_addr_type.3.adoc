== Name

dmi_ipmi_addr_type, dmi_ipmi_addr_type_name - IPMI BMC base address spaces

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/ipmi-device.h>

typedef enum dmi_ipmi_addr_type {
    DMI_IPMI_ADDR_TYPE_MEMORY = 0x0,
    DMI_IPMI_ADDR_TYPE_IO     = 0x1,
    DMI_IPMI_ADDR_TYPE_SMBUS  = 0x2
} dmi_ipmi_addr_type_t;

const char *dmi_ipmi_addr_type_name(dmi_ipmi_addr_type_t value);
----

== Description

The `dmi_ipmi_addr_type_t` enumeration tells in which address space the base
address of an IPMI baseboard management controller (BMC) lies, and is the
type of the `base_address_type` field of `dmi_ipmi_device_t`. The decoder
derives it from the interface type and from the least-significant bit of the
stored base address.

The `dmi_ipmi_addr_type_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_IPMI_ADDR_TYPE_MEMORY`::
Memory-mapped address.

`DMI_IPMI_ADDR_TYPE_IO`::
Address in the I/O space.

`DMI_IPMI_ADDR_TYPE_SMBUS`::
SMBus target address, used by the SSIF interface.

== Return value

`dmi_ipmi_addr_type_name` returns the name of the value, or `nullptr` if the
value has no name. The name is translated to the language of the current
locale when the library is built with localization support and has a
translation for it, and is in English otherwise. The string is owned by the
library and must not be modified or freed.

== Errors

None.

== See also

`dmi_ipmi_device`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 2.3 or newer.
