== Name

dmi_intel_me_sku, dmi_intel_me_sku_name - Intel Management Engine firmware SKUs

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/intel/mei.h>

typedef enum dmi_intel_me_sku {
    DMI_INTEL_ME_SKU_CONSUMER  = 0x02,
    DMI_INTEL_ME_SKU_CORPORATE = 0x03,
    DMI_INTEL_ME_SKU_LITE      = 0x05,
    DMI_INTEL_ME_SKU_UNSPEC    = 0xFF
} dmi_intel_me_sku_t;

const char *dmi_intel_me_sku_name(dmi_intel_me_sku_t value);
----

== Description

The `dmi_intel_me_sku_t` enumeration tells the SKU of the Intel Management
Engine firmware, as bits 4 to 6 of the third firmware status register
(HFSTS3) of the first interface tell it, and is the type of the `sku` field of
`dmi_intel_mei_t`. The SKU matches the version string of the `ME Firmware
Version` component of Intel firmware version information, see
`dmi_intel_fvi_item`(3). Other values may be found in the data, and are kept
as they are.

The `dmi_intel_me_sku_name` function returns the name of a value, as the command line
tool shows it.

=== Values

`DMI_INTEL_ME_SKU_CONSUMER`::
Consumer firmware.

`DMI_INTEL_ME_SKU_CORPORATE`::
Corporate firmware, which the platforms of Intel vPro have, with Intel Active Management Technology.

`DMI_INTEL_ME_SKU_LITE`::
Lite firmware, e.g. of the Chromebooks.

`DMI_INTEL_ME_SKU_UNSPEC`::
SKU is unknown, since the first interface is absent, or since the register
holds zero for it, as the firmware of Management Engine 11.0 may.

== Return value

`dmi_intel_me_sku_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_intel_mei`(3)

== Standards

Not part of the SMBIOS specification. Defined by the Intel reference code,
which gives the structures type 219 by default. The layouts of the firmware
status registers are the ones of the Intel Management Engine, as coreboot
describes them.
