== Name

dmi_dell_hotkey_entry - Dell hotkey mapping structure

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/dell/hotkeys.h>

typedef struct dmi_dell_hotkey_entry {
    uint16_t scancode;
    uint16_t keycode;
} dmi_dell_hotkey_entry_t;
----

== Description

The `dmi_dell_hotkey_entry_t` structure describes the mapping of a hotkey, as an
element of the `hotkeys` field of `dmi_dell_hotkeys_t`. Key code `0xFFFF` is
found for the keys of no known function, which the Dell WMI driver of Linux
takes for an unknown key, while key code `0x00FF` stands for a function of its
own, the third programmable key.

=== Fields

`scancode`::
Scan code of the key, as the firmware reports it in the WMI events of the
hotkeys.

`keycode`::
Code of the function of the key, as the Dell WMI driver of Linux numbers the
functions.

== See also

`dmi_dell_hotkeys`(3)

== Standards

Not part of the SMBIOS specification. Defined by Dell firmware, as the Dell
WMI driver of Linux and dmidecode describe it.
