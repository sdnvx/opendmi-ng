== Name

dmi_rack_type, dmi_rack_type_name - rack types of system enclosures

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/chassis.h>

typedef enum dmi_rack_type {
    DMI_RACK_TYPE_UNSPEC = 0x00,
    DMI_RACK_TYPE_OPEN   = 0x01,
} dmi_rack_type_t;

const char *dmi_rack_type_name(dmi_rack_type_t value);
----

== Description

The `dmi_rack_type_t` enumeration tells the kind of rack a system enclosure is
made for, which gives the unit of its rack height. It is the type of the
`rack_type` field of `dmi_chassis_t`, whose `rack_height` field holds the
height in that unit.

The `dmi_rack_type_name` function returns the printable name of a value, as the
command line tool shows it. The name is translated to the locale set with
`dmi_set_locale`, when the library is built with ICU4C support and has a
translation of it.

=== Values

`DMI_RACK_TYPE_UNSPEC`::
Unspecified.

`DMI_RACK_TYPE_OPEN`::
Open Rack, whose height unit is the OU (48 mm).

== Return value

`dmi_rack_type_name` returns the name of the value, or `nullptr` if the value
has no name. The name is a static string, which must not be modified or freed.

== Errors

None.

== See also

`dmi_chassis`(3)

== Standards

DMTF SMBIOS Specification (DSP0134), version 3.9 or newer.
