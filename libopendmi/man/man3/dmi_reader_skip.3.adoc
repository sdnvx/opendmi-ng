== Name

dmi_reader_skip - advance a reader cursor without reading data.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)

== Synopsis

[source, c]
----
#include <opendmi/reader.h>

bool dmi_reader_skip(dmi_reader_t *reader, size_t length);
----

== Description

The `dmi_reader_skip` function moves the reader cursor forward by `length`
bytes, effectively discarding that many bytes from the current position.

Stepping over a record by its declared length, rather than by the number of
bytes read from it, is what `dmi_reader_skip_ex`(3) does.

=== Parameters

`reader`::
Reader to advance.

`length`::
Number of bytes to skip.

== Return value

`true` on success, `false` if there are fewer than `length` bytes remaining
in the reader.
