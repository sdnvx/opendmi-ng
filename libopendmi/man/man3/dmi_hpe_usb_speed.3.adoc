== Name

dmi_hpe_usb_speed, dmi_hpe_usb_speed_name - HP/HPE USB port speeds

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/usb-port.h>

typedef enum dmi_hpe_usb_speed {
    DMI_HPE_USB_SPEED_FULL  = 0x01,
    DMI_HPE_USB_SPEED_HIGH  = 0x02,
    DMI_HPE_USB_SPEED_SUPER = 0x03
} dmi_hpe_usb_speed_t;

const char *dmi_hpe_usb_speed_name(dmi_hpe_usb_speed_t value);
----

== Description

The `dmi_hpe_usb_speed_t` enumeration tells the speed the firmware configures
a USB port for, and is the type of the `speed` field of `dmi_hpe_usb_port_t`.

The `dmi_hpe_usb_speed_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_HPE_USB_SPEED_FULL`::
USB 1.1 full speed.

`DMI_HPE_USB_SPEED_HIGH`::
USB 2.0 high speed.

`DMI_HPE_USB_SPEED_SUPER`::
USB 3.0 super speed.

== Return value

`dmi_hpe_usb_speed_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_usb_port`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
