== Name

dmi_hpe_tm_type, dmi_hpe_tm_type_name - HP/HPE trusted module types

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/hpe/trusted-module.h>

typedef enum dmi_hpe_tm_type {
    DMI_HPE_TM_TYPE_UNSPEC  = 0x00,
    DMI_HPE_TM_TYPE_TPM_1_2 = 0x01,
    DMI_HPE_TM_TYPE_TPM_2_0 = 0x02,
    DMI_HPE_TM_TYPE_PTT     = 0x03
} dmi_hpe_tm_type_t;

const char *dmi_hpe_tm_type_name(dmi_hpe_tm_type_t value);
----

== Description

The `dmi_hpe_tm_type_t` enumeration tells the type of a trusted module, and is
the type of the `type` field of `dmi_hpe_trusted_module_t`.

The `dmi_hpe_tm_type_name` function returns the name of a value, as the
command line tool shows it.

=== Values

`DMI_HPE_TM_TYPE_UNSPEC`::
Not specified.

`DMI_HPE_TM_TYPE_TPM_1_2`::
TPM 1.2.

`DMI_HPE_TM_TYPE_TPM_2_0`::
TPM 2.0.

`DMI_HPE_TM_TYPE_PTT`::
Intel PTT firmware TPM.

== Return value

`dmi_hpe_tm_type_name` returns the name of the value, translated to the language of the
current locale when a translation is available, or `nullptr` if the value
has no name. The returned string must not be modified or freed.

== Errors

None.

== See also

`dmi_hpe_trusted_module`(3)

== Standards

Not part of the SMBIOS specification. Defined by HP and HPE for their
servers; the layout is the one dmidecode documents.
