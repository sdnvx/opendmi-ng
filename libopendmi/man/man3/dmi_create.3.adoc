== Name

dmi_create - create an OpenDMI context.

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/context.h>

dmi_context_t *dmi_create(unsigned int flags);
----

== Description

The `dmi_create` function creates a context, which holds the SMBIOS data it
is given, read from the system with `dmi_open`(3) or from a dump file with
`dmi_load`(3), along with everything decoded from it, the errors raised
while doing so, and the logging handler.

A context is created closed: it holds no data until it is opened, and may be
opened again once it has been closed with `dmi_close`(3). The caller
destroys it with `dmi_destroy`(3).

The flags choose how the data is decoded, and are combined with the bitwise
OR:

`DMI_CONTEXT_FLAG_RELAXED`, which is zero, makes as much of the table
available as possible: malformed structures are left undecoded, broken
references and invalid additional information entries are skipped, and the
errors are left in the error queue. A structure of an invalid length ends
the table, and missing firmware information leaves the vendor unknown.

`DMI_CONTEXT_FLAG_STRICT` makes opening fail if the table has any error.
Decoding and linking still go on after the first error, so that all of the
errors are reported to the error queue.

`DMI_CONTEXT_FLAG_LINK` resolves the references between the structures once
they are decoded, and attaches string properties (type 46) to the structures
they describe.

`DMI_CONTEXT_FLAG_OVERLAY` decodes the structures with the values of
additional information entries (type 40) applied. Entries usually carry
annotations with placeholder values rather than the values of fields, so
this is not done by default.

A new context logs nothing, since it has no logging handler until
`dmi_set_logger`(3) gives it one. Its logging level is `DMI_LOG_DEBUG`.

=== Parameters

`flags`::
Flags of the context, `DMI_CONTEXT_FLAG_RELAXED` or a combination of the
other `DMI_CONTEXT_FLAG_*` values.

== Return value

On success, returns the context. On failure, returns `nullptr`, which
happens when memory is exhausted only, and is not reported to any error
queue, since there is no context to hold it.

== Errors

None.

== Examples

[source, c]
----
dmi_context_t *context = dmi_create(DMI_CONTEXT_FLAG_LINK);

if (context == nullptr)
    return false;

if (dmi_open(context, nullptr)) {
    ...
}

dmi_destroy(context);
----
