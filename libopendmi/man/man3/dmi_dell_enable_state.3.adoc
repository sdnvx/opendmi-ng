== Name

dmi_dell_enable_state, dmi_dell_enable_state_name - Dell enable states

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/dell/common.h>

typedef enum dmi_dell_enable_state {
    DMI_DELL_ENABLE_STATE_UNSPEC   = 0x00,
    DMI_DELL_ENABLE_STATE_OTHER    = 0x01,
    DMI_DELL_ENABLE_STATE_UNKNOWN  = 0x02,
    DMI_DELL_ENABLE_STATE_ENABLED  = 0x03,
    DMI_DELL_ENABLE_STATE_DISABLED = 0x04,
} dmi_dell_enable_state_t;

const char *dmi_dell_enable_state_name(dmi_dell_enable_state_t value);
----

== Description

The `dmi_dell_enable_state_t` enumeration tells whether a feature of a Dell
port is enabled, and is the type of the `state` and `speed_limit_state` fields
of `dmi_dell_infrared_port_t`.

The `dmi_dell_enable_state_name` function returns the name of a value, as the
command line tool shows it. The name is in English, or in the language of the
locale the library is set to when it has a translation of the name.

=== Values

`DMI_DELL_ENABLE_STATE_UNSPEC`::
Unspecified. The firmware does not define the value 0.

`DMI_DELL_ENABLE_STATE_OTHER`::
Other state.

`DMI_DELL_ENABLE_STATE_UNKNOWN`::
Unknown state.

`DMI_DELL_ENABLE_STATE_ENABLED`::
Enabled.

`DMI_DELL_ENABLE_STATE_DISABLED`::
Disabled.

== Return value

`dmi_dell_enable_state_name` returns the name of the value, a constant string
which must not be modified or freed, or `nullptr` if the value has no name,
e.g. a value out of the range of the enumeration.

== Errors

None.

== See also

`dmi_dell_infrared_port`(3)

== Standards

Not part of the SMBIOS specification. Defined by Dell firmware, see the Dell
Infrared Port (Type 211) chapter of the reference manual.
