== Name

dmi_dell_token_refs_1 - Dell token references structure, type 1

== Library

OpenDMI C library (`libopendmi`, `-lopendmi`)
endif::[]

== Synopsis

[source, c]
----
#include <opendmi/entity/dell/token-refs.h>

typedef struct dmi_dell_token_refs_1 {
    uint16_t tokens[9];
} dmi_dell_token_refs_1_t;
----

== Description

The `dmi_dell_token_refs_1_t` structure holds the decoded Dell token
references of type 220, which list tokens the calling interface (type 218) or
the indexed I/O access (type 212) defines, grouped by the device they belong
to. The meaning of the groups is not established.

The structure is returned by `dmi_entity_info`(3) for the structures decoded
by `dmi_dell_token_refs_1_spec`, of type `DMI_TYPE(DELL_TOKEN_REFS_1)`,
declared in `<opendmi/module/dell.h>`, once the Dell extension module
(`dmi_dell_module`) is enabled. It lives as long as the context it has been
decoded in.

The layout is reverse engineered from the dumps of the data corpus, since no
public source describes the structure, and the members whose meaning is not
established are named after their position.

=== Fields

`tokens`::
Tokens, zero for none.
