== Name

opendmi-import - import SMBIOS data from an external format.

== Synopsis

*opendmi* [_global options_] *import* [_command options_]

== Description

The *import* command is meant to read the data back from the formats
`opendmi-export`(1) writes, and to assemble a table out of it, so that SMBIOS
data can be authored rather than only observed.

*The command is not implemented yet* and fails with a message saying so. It is
described here because its shape is settled; see the roadmap of the project for
when it is due.

Until then, a table is produced by the firmware alone, and is read from a
platform or from a binary dump written by `opendmi-dump`(1). Data which is
being authored is checked with `opendmi-lint`(1), the *--producer* option of
which applies the rules the way a producer of the data has to follow them.

== Options

*-?*, *-h*, *--help*::
Print help and exit.

== Exit status

*1*::
Command is not implemented.

*2*::
Command line is invalid.
