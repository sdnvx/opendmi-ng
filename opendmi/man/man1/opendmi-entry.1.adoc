== Name

opendmi-entry - show the data of the SMBIOS entry point.

== Synopsis

*opendmi* [_global options_] *entry* [_command options_]

== Description

The *entry* command shows the entry point of the SMBIOS data: the anchor which
identifies it, the version of the specification the firmware follows, and where
the table is and how large it is.

The entry point comes in several formats, and the command shows the fields of
the one it has found. A 32-bit entry point (`_SM_` or `_DMI_`) declares the
number of the structures and the size of the largest one; a 64-bit entry point
(`_SM3_`) declares the maximum size of the table area instead, and leaves the
end of the table to be found by reading it.

The version shown here is the one the rest of the utility decodes the data
against, which is why a table that disagrees with its own entry point is worth
checking with `opendmi-lint`(1).

The command has no options of its own.

== Options

*-?*, *-h*, *--help*::
Print help and exit.

== Exit status

*0*::
Entry point has been shown.

*1*::
Data could not be read.

*2*::
Command line is invalid.

== Examples

Show the entry point of the local platform:

....
$ opendmi entry
....

Show the entry point a dump was saved with:

....
$ opendmi -i smbios.bin entry
....
